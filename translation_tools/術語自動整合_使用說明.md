# ML4T 方案 B：自動附帶術語的翻譯任務

## 安裝（一次即可）

把 ZIP 中 `translation_tools` 內的 **兩個新檔案**放到你現有的 `C:\code\ml4t\translation_tools\`。**不要覆蓋或刪除原有**的 `nb_zh.py`、`selftest.py` 等工具。`translations/glossary_zh_TW.md` 保留原位。

## 測試

在 VS Code 的 WSL Ubuntu 終端機，從專案根目錄執行：

```bash
cd /mnt/c/code/ml4t
python3 translation_tools/test_prepare_with_glossary.py
```

成功時顯示 `ALL GLOSSARY TESTS PASSED`。

## 從下一份「從未 prepare」的 Notebook 開始

例如下一份 `macro_regimes`：

```bash
python3 translation_tools/prepare_with_glossary.py 01_process_is_edge/macro_regimes.ipynb --max-chars 1800 --batch-chars 5000
```

新生成的 `translations/work/01_process_is_edge/macro_regimes/tasks/batch_001.md` 會**只包含該批英文出現的相關術語**，可單獨上傳到另一個 GPT 帳號。其他批次亦然。

**注意：** 這是原有 `nb_zh.py prepare` 的安全包裝，不改動現有翻譯資料格式，也**不會回頭修改** `factor_regimes` 的 28 個已完成翻譯。已執行過 prepare 的工作區會拒絕重新 prepare，保護既有進度。

## AI 回覆如何匯入

**完全沿用原有指令**：

```bash
python3 translation_tools/nb_zh.py ingest 01_process_is_edge/macro_regimes.ipynb --batch 1 --file translations/work/01_process_is_edge/macro_regimes/inbox/batch_001.txt
python3 translation_tools/nb_zh.py status 01_process_is_edge/macro_regimes.ipynb
```

全部完成後仍然使用原有的 `nb_zh.py build` 和 `nb_zh.py verify`。進度管理 `progress_dashboard.py` 不受影響。

## 邊界

- 術語為**候選**建議譯法，需依上下文使用；自動比對不能取代人工審查。
- 自動篩選只尋找 glossary 表格的英文詞條，會忽略無法匹配的詞，且部分複雜英文詞形可能未自動識別。
- 預設每批最多 25 條匹配詞彙；可使用 `--max-terms 15` 進一步節省 Token。
- 術語表會記錄 SHA-256 到新工作區的 `manifest.json`；日後修改 glossary，不會悄悄改寫**已送給 AI 的舊批次任務**。
- 若已 prepare 某 Notebook，請用原本 `status`/`ingest`/`build` 接續，不要刪除工作區重來。
