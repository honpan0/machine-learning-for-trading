## 重點摘要

1. **串流提升將一條序列變成許多樣本，排序就是核心計算。** 兩份大小相同的一維樣本之間的 Wasserstein 距離，是配對分位數的平均差異；其重心則是逐分位數的中位數或平均數，所以 k-means 不需原本沒有的其他最佳化器。
2. **讀取完整分布的方法勝過只讀取四個動差的方法，原因是幾何形狀。** 在相同四個動差上，高斯混合模型的結果接近分布方法，k-means 卻沒有；這表示落差主要來自 k-means 可形成的群集形狀，而非動差漏掉的內容。
3. **視窗標籤應標在視窗收盤時。** 將標籤寫回視窗涵蓋的每個交易日，是很自然的程式寫法，卻會把某交易日的未來資料放進其特徵。正確做法的代價，是開頭的預熱期，以及每次狀態轉換後，最多一個視窗加一個步距的延遲。
4. **以完整樣本擬合的群集中心也不能直接用作特徵。** 應在第一個區塊擬合，並只保留其後交易日的欄位；後期視窗落入各群集的比例，才有意義，因為群集不是為了容納它們而形成。要恢復擬合期間各年的特徵，不能只延後標記標籤，而須按時間順序重新擬合。
5. **無監督方法總能報告清楚的分界。** 此處每種方法都產生最大平均差異相距很遠的群集，包括恢復最少真值的那一種。若沒有真值欄位可供檢查，分界統計量只能說明演算法已執行，無法證明分法就是重要的那一種。
