# Wasserstein 市場狀態分群

**第 9 章 | 第 9.5 節**

**Docker 映像檔**：`ml4t`

上一份 Notebook 擬合模型，判斷每筆報酬率由兩種狀態中的哪一種產生。這份 Notebook 對相同資料提出不同問題：將報酬率序列切成視窗，把每個視窗視為一個獨立分布，並將樣貌相似的視窗分在一起。不預先假設市場狀態如何運作或轉換；預先指定的是如何衡量兩個分布之間的距離。

此測量方法是 **Wasserstein 距離**；在一維情況下，它就是分位數函數之間的距離。它讀取完整分布形狀，而非只看平均數與變異數，這也是額外計算值得付出的原因：兩個視窗的這兩項動差可以相同，損失分布的位置卻不同。

**學習目標**

- 將報酬率序列切成視窗，把每個視窗當作經驗分布。
- 計算一維 Wasserstein 距離及其對應的重心，並了解為何兩者都可化為對排序後報酬率的運算。
- 使用該距離對視窗分群，並與已知真值比較，衡量相同視窗的雙動差摘要會漏掉哪些資訊。
- 將結果轉成可由交易日自身歷史產生的欄位；為此，須在第一個區塊擬合群集中心，再向前指派其餘資料。
