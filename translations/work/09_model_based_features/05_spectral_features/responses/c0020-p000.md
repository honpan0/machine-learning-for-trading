# 第二部分：移動視窗的頻率內容

**離散傅立葉轉換**將有限長序列寫成若干正弦波之和；這些正弦波的頻率，在序列長度內恰好可容納整數個週期。轉換會回傳各頻率的含量。套用在移動視窗時，依其建構方式自然具有因果性：某交易日的數值只使用當下視窗，不使用其後資料。

每個視窗的**功率頻譜**，即各頻率的強度，會產生四個量：

- **頻譜能量**：所有頻率的總強度。
- **主導週期**：最強振盪的週期長度。
- **頻譜熵**：強度在不同頻率間分布的均勻程度。各頻率貢獻差不多時數值高，這是雜訊的樣貌；單一振盪占主導時數值低。
- **低頻比率**：視窗能分辨的兩個最慢振盪，在總強度中所占的比例。

熵會除以該視窗頻率數量下可能達到的最大值，使結果落在零到一之間，也可比較不同視窗長度。若不做此除法，較長視窗有更多頻率可供分散，僅因此就會得到較高分數。

加總功率時，還必須處理轉換的一項細節。實數序列的每個頻率都與其負頻率成對，而 `rfft` 每對只回傳一次；常數項沒有配對，在視窗長度為偶數時，最快的頻率也沒有配對。因此，偶數長度視窗的最快頻率箱只給予一半權重，才能讓總量無論視窗多長，都等於視窗本身的能量。
