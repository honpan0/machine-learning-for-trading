## 函式庫的頻譜輔助函式

`ml4t.engineer` 提供兩個相關的運算式，但它們回答的問題與上述特徵不同。

`rolling_entropy` 將視窗中的數值分箱，計算所得直方圖的 Shannon 熵，單位為**位元**。它衡量的是報酬率分布的熵，而非其頻譜的熵：前述頻譜熵詢問功率如何分布在各頻率，這裡詢問數值如何分布在某個範圍內。其最大值是分箱數量以二為底的對數，應以此對照列印出的平均值。

`fourier_features` 根本不是對序列的測量；由於名稱容易造成相反印象，這點值得說清楚。它根據呼叫者提供的基準週期之倍數，回傳**列索引**的正弦與餘弦配對。價格完全不參與計算。這是讓線性模型表示已知長度平滑週期的方法，是正當但不同的用途；預設基準週期為 390，即美國市場一個交易日的交易分鐘數，因此套用在每日資料時，必須指定真正想表示的週期。
