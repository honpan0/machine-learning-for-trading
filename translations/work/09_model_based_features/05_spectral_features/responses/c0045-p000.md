## 重點摘要

1. **小波分解是研究工具。** 它會讀取整段序列，因此任何成分都不能用作特徵。其輸出可幫助決定哪些時間尺度值得計算滾動特徵。
2. **小波族的影響小於分解層數。** 三種小波族產生幾乎相同的慢速成分，只在最快的細節上不同；層數則決定每個尺度涵蓋的範圍。
3. **檢查衍生特徵可化簡成什麼。** 總頻譜能量就是視窗變異數乘上一個常數；相關性為一及固定比率都證實這點。因此，同時把兩者交給模型，等於重複給予同一欄。
4. **比較不同視窗之前，先縮放會隨視窗長度改變的量。** 頻譜熵會隨視窗中的頻率數量增加，因此此處將它除以最大值；未縮放的版本會把長視窗排在短視窗之前，原因卻與資料無關。
5. **平坦頻譜也是研究發現。** 每日指數報酬率幾乎沒有週期結構，因此頻譜欄位反映的是偏離此狀態的情況，而非某個週期。真正變動的是整體頻譜水準，也就是波動率；`08_garch_volatility` 會直接對其建模。

**已知限制。** 此處每個頻譜量都假設其視窗來自單一不變的過程；包含波動率結構轉變的視窗不符合此假設，所得估計是兩種市場狀態的平均。資訊係數是在單一標的的重疊未來視窗上計算，不能據此推論顯著性。小波尺度與視窗長度的對應只是經驗法則，此處以相關性檢查，而非由理論推導。
