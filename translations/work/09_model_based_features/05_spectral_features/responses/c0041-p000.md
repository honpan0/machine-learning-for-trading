## 本 Notebook 產生的特徵

| 欄位 | 衡量內容 | 具因果性 |
|---|---|---|
| `spectral_entropy` | 功率在各頻率間分布的均勻程度，並依最大值縮放 | 是 |
| `dominant_period` | 視窗中最強振盪的週期 | 是 |
| `low_freq_ratio` | 視窗能分辨的兩個最慢振盪所占功率比例 | 是 |
| `energy_period_*` | 指定曆法週期周圍頻率箱的原始功率 | 是 |
| 小波成分 | 依時間尺度拆分的序列 | **否**，轉換會讀取整段序列 |

此處刻意未列出 `spectral_energy`。它只是重新縮放的視窗變異數；直接計算應使用滾動變異數。
