# 頻譜與小波特徵

**第 9 章 | 第 9.2 節**

**Docker 映像檔**：`ml4t`

到目前為止，所有方法都是依序列隨時間的表現來描述它。**頻譜**方法則描述序列由什麼組成：不同頻率、各有強度的振盪之和。問題從「水準往哪裡走」轉為「有多少變動發生在每週週期，又有多少發生在每季週期」；有些在價格圖上看不出的事，在這種分解下就很清楚。

**學習目標**

- 將報酬率序列拆成不同時間尺度的成分，並讀出哪些尺度承載最多變異。
- 說明為何標準的分解方式不能用作特徵，並將其揭示的內容轉化為可用的滾動計算。
- 計算移動視窗的頻率內容並轉成欄位：總變動量、最強振盪所處的週期、頻率內容的分散程度，以及最慢頻帶所占比例。
- 透過對重疊區段取平均，更穩定地估計同樣的頻率內容，並將結果讀成頻率隨時間變化的圖像。
- 辨識某個頻譜量何時只是既有量的尺度變換。
