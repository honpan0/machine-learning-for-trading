# 第一部分：小波，以及為何它只留在研究 Notebook 中

**小波分解**將序列拆成時間尺度逐次加倍的成分。第一個細節成分包含變化最快的部分，第二個包含速度減半的變化，依此類推；最後剩下的是最慢的變動。對每日資料使用五層分解，成分大致涵蓋二到四、四到八、八到十六、十六到三十二、三十二到六十四個交易日，以及更慢的一切變化。

之所以把它當作分析工具，而非特徵，原因在於成分的建構方式。離散小波轉換會在整段序列上向前、向後執行濾波器，因此任何交易日的成分值都依賴其後的交易日。每個成分都不是因果的；用它訓練的模型會讀到自己的未來。分解的用途，是決定哪些尺度值得建立因果特徵；本部分後半段正會這樣做。
