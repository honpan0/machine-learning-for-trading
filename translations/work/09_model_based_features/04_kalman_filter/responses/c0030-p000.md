先看正負號，再看數值大小。負的資訊係數表示估計值上升後，價格反而下跌；這代表短期反轉，而非動能，且對廣泛市場指數在此預測期間，這是預期中的方向。

但不要把任何一個數值當成顯著性檢定。未來報酬率視窗彼此重疊：連續兩個交易日的五日視窗，共有四天相同，因此計分的交易日遠非同等數量的獨立觀測值；若視為獨立樣本計算標準誤，結果會小上好幾倍。`01_visual_diagnostics` 的滾動平穩性欄位也面臨同一問題：它們同樣在重疊視窗上重新擬合，且具有同樣的相依性。

數值大小容易讓人想比較，但前一張圖已否定了這種比較。有界限擬合幾乎將所有狀態變動歸於水準，斜率只分到極少部分，因此濾波器的斜率變化遠慢於四週迴歸線的斜率：上方兩個圖表中，一個反覆穿越零，另一個則連續數月保持同一正負號。它們估計的是不同時間尺度的趨勢，卻都拿來對照五個交易日的未來報酬率；因此無論誰較好，這都是時間尺度之間的比較，而非估計器之間的比較。

若要比較估計器，必須先固定時間尺度：可以限制濾波器設定，使其水準估計值具有與滾動視窗相同的平滑程度；也可以將每個估計值，與涵蓋其自身時間尺度的未來視窗進行評分。兩者都比直接讀取表上的兩個數字費工，而這正是重點。
