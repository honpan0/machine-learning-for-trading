擬合結果明顯遠離平滑。概似值與收盤價差距都指出，手動設定對 SPY 的判斷朝同一方向出錯：在每日頻率下，收盤價接近一個本身大幅變動的水準之精確觀測值；換言之，這個序列看起來像隨機漫步。因此後續濾波器會緊跟收盤價，其斜率也接近上一個交易日的價格變動，而非跨越數週的趨勢。

至於是哪一個狀態變異數吸收這些變動，則遠不如「其中一個必須吸收」這件事明確。水準可能因自身有雜訊而變動，也可能因斜率有雜訊並拉動它；兩者都無法直接觀測，因此沒有觀測值能區分它們。概似值曲面沿著這項取捨幾乎是平坦的，從別處起始的無界限搜尋，會以相近的概似值抵達另一個角落。這種辨識力不足，是下方滾動向前擬合採用有界限最佳化器，而非此處最佳化器的原因。
