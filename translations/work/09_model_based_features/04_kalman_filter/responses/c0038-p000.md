## 重點摘要

1. **設定就是模型，其比率決定行為。** 狀態可變動多少，以及觀測值有多少雜訊，共同決定濾波器的所有行為；固定權重方法則以視窗長度作為設定。
2. **透過最大概似法擬合設定，才能使其成為估計值**；以移動視窗向前擬合，則可防止估計值讀取自身的未來資料。在這份樣本中，擬合結果完全推翻了手動設定的假設。
3. **沒有視窗的斜率，仍有自己的時間尺度**，由擬合設定決定。除非先固定時間尺度，否則將它與固定視窗斜率比較，實際上是在比較兩種時間尺度。
4. **只做濾波，不做平滑。** 此處每個量都只使用截至自身交易日的觀測值。各量的平滑版本雖能更好地估計過去，卻不是可用的特徵。
5. **隨時間變動的避險比率，在資產配對變動時才移動**；滾動迴歸則也會因舊觀測值離開視窗而移動。

**已知限制。** 局部線性趨勢模型假設每次重新擬合的視窗內，雜訊服從常態分布且變異數固定，但創新項圖表顯示變異數並不固定。觀測雜訊隨時間變動的濾波器，是自然的修正方式；本章後續的波動率模型正是估計這類雜訊。此處的資訊係數僅是單一標的、單一時間尺度的數值，沒有信賴區間。此外，在設定固定時，不確定性特徵會收斂成常數，因此只在重新擬合之間帶有資訊。
