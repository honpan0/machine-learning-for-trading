# 用於金融特徵擷取的 Kalman Filter

**第 9 章 | 第 9.2 節**

**Docker 映像檔**：`ml4t`

移動平均藉由以固定權重平均固定數量的過去觀測值，回答「忽略雜訊後的價格是多少」。**Kalman Filter** 以另一種方式回答同一問題：它明確建立價格如何變動、觀測有多少雜訊的模型，並根據這兩項資訊，而非視窗長度，決定多大程度上相信每筆新觀測值。移動平均只有一項設定；濾波器則有一個模型，每筆新觀測值都會同時更新估計值及其不確定程度。

**學習目標**

- 寫出價格序列的雙部分模型：一部分說明潛在水準及其變動速率如何演變，另一部分說明價格觀測有多少雜訊，並實作隨觀測值到來而更新兩者的遞迴程序。
- 將遞迴程序產生的四個量讀作特徵：估計水準、其變動速率、每筆新觀測帶來的意外，以及估計值的不確定程度。
- 透過最大概似法將兩項雜訊設定擬合至資料，而非手動選擇；並隨樣本向前推進而重新擬合，使任何特徵都不會讀取由其未來資料估計的設定。
- 估計兩項資產之間可隨時間變動的避險比率，並說明此濾波器能做到哪些滾動迴歸做不到的事。
