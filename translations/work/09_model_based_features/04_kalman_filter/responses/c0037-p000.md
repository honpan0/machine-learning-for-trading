## 本 Notebook 產生的特徵

| 欄位 | 內容 | 用途 |
|---|---|---|
| `level` | 經濾波的價格水準 | 平滑程度隨資料變動的平滑價格 |
| `slope` | 經濾波的變動速率 | 無須設定視窗長度的趨勢估計 |
| `innovation` | 每筆收盤價中預測未涵蓋的部分 | 衡量該交易日有多出乎意料 |
| `uncertainty` | 水準估計值的變異數 | 判斷其他三項特徵有多可信 |
| `beta` | 兩項資產間經濾波的避險比率 | 判斷應以何種資產對沖另一種資產，以及其價差 |

每項特徵都是經**濾波**，而非經平滑處理：某交易日的數值，只使用截至該日的觀測值，不使用之後的資料。平滑器會利用後期觀測值修訂先前狀態，雖能更準確估計過去，卻完全不能用作當時可得的特徵。
