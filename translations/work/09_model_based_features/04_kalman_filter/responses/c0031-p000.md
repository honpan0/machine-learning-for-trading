## 容許變動的避險比率

配對交易以一項資產對上另一項資產的一定倍數，而該倍數就是**避險比率**。若在固定視窗內以迴歸估計它，就必須做出難以妥善決定的選擇：短視窗雜訊多，長視窗反應慢；無論選哪一種，比率本身也不是常數。

同一濾波器可以用同一組方程式的另一種詮釋來估計比率。狀態是兩個迴歸係數；轉移方程表示它們遵循隨機漫步；觀測列則包含解釋變數資產的價格，因此模型是 $y_t = \beta_t x_t + \alpha_t + \varepsilon_t$，兩個係數都可以自由漂移。

兩項設定控制其行為。`DELTA` 透過 $\mathbf{Q} = \frac{\delta}{1-\delta}\mathbf{I}$ 設定係數每個交易日可變動多少：在此使用的數值下，每日變動很小，但一年累積變動很大。`PAIR_OBS_VAR` 是定價誤差的變異數，以美元平方表示；它由固定迴歸留下的殘差估計，而非直接假設。該迴歸在起始的暖機期間擬合，本節不報告該期間內的結果，因為若從完整配對樣本計算變異數，就會讓後期價格進入產生先前每個避險比率的增益。
