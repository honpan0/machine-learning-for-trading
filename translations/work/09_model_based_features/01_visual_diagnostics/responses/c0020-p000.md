## Ljung-Box：自相關是否聯合為零？

將各個 ACF 柱狀線與信賴區間帶比較，是一次檢驗一個落後期；有四十個落後期時，部分柱狀線可能僅因偶然越過區間帶。**Ljung-Box** 檢定將前 $m$ 個自相關彙整為單一統計量並聯合檢定，因此能回答相關圖提出的問題，而不必分別查看四十次。

此處檢定四種期間，涵蓋每日策略重視的區間：一週、兩週、一個月及兩個月的交易時段。

然後對報酬率的**平方**重複檢定。平方會去除正負號而保留幅度，因此平方報酬率有自相關，表示不論方向，大幅變動後仍容易出現大幅變動。這就是波動率群聚，也是 `08_garch_volatility` 中的 GARCH 模型所要描述的現象。
