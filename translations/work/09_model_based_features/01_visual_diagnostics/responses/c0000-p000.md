# 視覺診斷與定態性檢定

**第 9 章｜第 9.1 節**

**Docker 映像檔**：`ml4t`

在為序列建立模型之前，必須先了解其性質。本 Notebook 逐步進行診斷，以判斷價格序列屬於何種時間性資料：先以目測觀察，再檢驗其統計性質是否穩定，衡量今天的數值對明天有多少預測能力，最後將這些檢定轉換為隨樣本向前滾動而重新計算的特徵。

**學習目標**

- 解讀價格序列的四格診斷圖，說明每格可支持或排除哪些現象：趨勢、波動率群聚，或比常態分布更厚的尾部。
- 進行兩項虛無假設方向相反的檢定，並合併解讀，以判斷序列能否直接建模。
- 衡量序列過去的數值能否預測其未來，以及過去數值的*平方*能否預測未來變動幅度。
- 在移動視窗內重新計算這些檢定，使「此序列是否表現穩定」成為隨時間變動的欄位，而非整個樣本只有一個答案。
