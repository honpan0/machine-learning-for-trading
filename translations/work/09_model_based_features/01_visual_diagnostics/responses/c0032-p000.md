## 主要重點

1. **檢定前先觀察。** 四格圖提出檢定要回答的問題，而且只需一個儲存格。
2. **兩項檢定，虛無假設相反。** 單靠 ADF 無法區分「定態」與「樣本無法確定」，單靠 KPSS 也不行。合併解讀可區分四種情況，而 `analyze_stationarity` 加入第三項檢定後，也會傳回相同的解讀。
3. **差分是標準修正方法，但有代價。** 價格並非定態，報酬率則是；但一階差分會完全捨棄水準資訊。`03_fractional_differencing` 則在定態性允許的範圍內，盡量保留這些資訊。
4. **也要檢定平方值，而非只檢定原序列。** 平方報酬率的自相關，使波動率成為報酬率序列中最可預測的部分，也是 `08_garch_volatility` 建模的對象。
5. **在滾動視窗中重新計算的診斷，就是特徵。** 對完整樣本只提供一次答案的兩項檢定，可產生隨序列變化而變動的欄位，前提是每個視窗的結果都標記在當時確實能計算的日期。

**已知限制。** 兩項檢定都假設其視窗內只有一種資料生成過程，因此視窗內若發生斷裂，結果可能呈現拒絕，卻無法指出斷裂位置；`02_structural_breaks` 可加以定位。滾動迴圈會在重疊視窗中重新擬合，因此上方各欄位相鄰數值高度相依，其變化不能當作獨立抽樣的證據。此外，視窗長度必須在檢定力與反應速度之間取捨：較短的視窗會較早發現變化，但對真正已不再定態的序列，拒絕的頻率也較低。
