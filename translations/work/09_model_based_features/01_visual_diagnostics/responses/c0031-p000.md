## 本 Notebook 產生的特徵

| 欄位 | 計算依據 | 重新計算頻率 |
|---|---|---|
| `adf_statistic` | 回溯視窗內的 ADF | 每 `ROLLING_STEP` 個交易時段 |
| `adf_pvalue` | 回溯視窗內的 ADF | 每 `ROLLING_STEP` 個交易時段 |
| `kpss_statistic` | 回溯視窗內的 KPSS | 每 `ROLLING_STEP` 個交易時段 |
| `kpss_pvalue` | 回溯視窗內的 KPSS | 每 `ROLLING_STEP` 個交易時段 |
| `stationarity_regime` | 合併解讀兩項檢定 | 每 `ROLLING_STEP` 個交易時段 |

每個值都儲存在 `rolling_df` 中，並標記在視窗結束後的下一個交易時段；因此，模型在該日期讀取時，只會看到此前已可取得的資訊。
