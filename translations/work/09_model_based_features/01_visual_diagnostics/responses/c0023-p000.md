## 將檢定轉換為特徵

定態性並非序列永遠不變的性質；若把完整樣本的一次檢定當成定論，就會忽略其變化。在向前移動的視窗中重新擬合相同的兩項檢定，可將每項檢定變成一個欄位：一個序列多年來通過檢定，後來卻不再通過，正是模型需要知道的事件；同樣的建構方式，也能在價差停止均值回歸前，偵測共整合關係的弱化。

`ROLLING_WINDOW` 設定每次檢定讀取多少個交易時段。252 個時段約為一個交易年，足以讓兩項檢定具有檢定力，同時又短到能顯示持續數季的市場狀態，而不會將其平均掉。`ROLLING_STEP` 設定重新擬合的頻率：5 個交易時段約為一個交易週，符合每週再平衡模型更新特徵的頻率。

每個視窗都在其標記日期的前一個交易時段結束，因此標記在某日期的數值，可根據前一日收盤前可得的資料計算，作為該日期的特徵而不引入前瞻資訊。臨界值取自各檢定自身的輸出，而非手動填入，因為兩者都取決於樣本數，ADF 的臨界值還取決於 `autolag` 選擇的落後階數。
