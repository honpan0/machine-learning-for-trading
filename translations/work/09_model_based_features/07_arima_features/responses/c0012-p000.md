## 多步預測為何不能當作特徵

為測試期間產生預測，直覺做法是擬合一次，再要求與該期間同樣長的多步預測。對平穩模型而言，這會得到沒有用處的結果；原因是模型結構，而非擬合缺陷：沒有新觀測值可供條件化時，第 $h$ 步的預測，是模型在最後觀測值已知條件下的期望值；對平穩過程而言，該期望值會以幾何速度衰減到無條件平均值。短短幾步後，所有預測都是同一個數字。

收斂速度取決於擬合所得的持續性，而非僅取決於平穩性。因此，下方示範會列印第一筆與最後一筆預測，以及整段測試期間預測值的分散程度，並與該欄要追蹤的報酬率分散程度比較。單看尺度不足以定論：即使預測值只是目標值的千分之一，交易日的排序仍可與目標完全一致。關鍵在於變異出現在哪裡。幾步之後，預測便重複同一個數字，因此僅有的少量變化都集中在區塊最初幾個交易日；它對整個區塊提供的任何排序，也由這幾日決定。
