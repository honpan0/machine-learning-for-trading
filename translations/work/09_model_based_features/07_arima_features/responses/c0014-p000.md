## 會隨時間變動的預測

可行版本是每次只預測一步：在每個交易日，模型以截至該日的所有觀測值為條件，預測下一日。有兩種方法，都具有因果性。**濾波**將參數固定在訓練區塊所得的值，並向前執行狀態遞迴，因此測試觀測值不會影響參數，成本僅為一次擬合。**以擴展視窗重新擬合**則在每一步使用其前的觀測值重新估計，成本是每個交易日擬合一次，但參數可跟隨資料變動。本 Notebook 採用濾波，因為每天對一百個標的重新擬合確實有成本，而這種小模型的參數幾乎不變；若序列的動態確實改變，才有理由支付該成本。

`arima_one_step_forecast` 是共用實作；之所以需要它，是因為相鄰的兩個呼叫執行的是別的工作。`apply(endog, refit=True)` 會在收到的陣列上重新估計，使每筆預測都擬合於其輸出的同一區塊；`forecast(h)` 則從資料末端向後續推，而非沿資料濾波，所以它回傳的是指定數量的數值，不是每列一個。輔助函式明確傳入 `refit=False`（也是目前安裝版本的預設值），並檢查參數確實沒有變動。因此，若上游更改預設值，程序會明確失敗，而非悄悄將欄位變成樣本內擬合結果。
