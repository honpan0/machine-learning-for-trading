# 將 ARIMA 用作特徵擷取器

**第 9 章 | 第 9.3 節**

**Docker 映像檔**：`ml4t`

ARIMA 通常被介紹為預測模型，並以預測是否準確來評價。本 Notebook 的用法不同：預測本身不是答案，而是一個**欄位**；每個交易日一個數字，供後續模型與其他特徵一起讀取。這改變了需要檢查的事項。預測不必準確，但欄位必須能在標記的交易日當下計算、隨時間變化，而且承載其他欄位尚未包含的資訊。

**學習目標**

- 解讀自相關函數（ACF）與偏自相關函數（PACF），提出此模型家族的階數，並在階數網格上以資訊準則檢查該提議。
- 說明為何多步預測會收斂成常數，以及無論模型多好，這為何使它不能當作欄位。
- 透過在較早資料區塊擬合參數，再以該參數對序列濾波，建立會隨時間變化的單步預測版本，並說明其因果性來自何處。
- 先在單一資產、再在一百項資產上衡量欄位的價值，解讀結果分布，而非單一數字。
