兩種準則不一定一致；在這次切分中，即使不同，也有值得說明的原因。資訊準則在訓練區塊以概似值評估擬合；資訊係數則在測試區塊評估欄位的排序一致性。某模型可能因更貼近訓練區塊的雜訊而贏得前者，卻在未曾見過的區塊輸掉後者。如此處一樣，依資訊準則選擇，再報告資訊係數，便能清楚保留兩者分界；若依資訊係數選擇，就等於在被報告的區塊上選擇。

RMSE 欄是第三個值得注意的量，也是三者中最鮮明的一個。此處每個預測值相對於所預測的報酬率都很小，因此平方誤差主要由報酬率本身主導，幾乎不受產生預測的模型影響。RMSE 最低的階數完全沒有動態，其預測是常數：當預測對象幾乎全是雜訊時，什麼都不預測反而錯得最少。該階數也沒有資訊係數，因為常數的等級相關性無法定義。若以 RMSE 排列這些模型，實際上就是按測試區塊的變異數排序。
