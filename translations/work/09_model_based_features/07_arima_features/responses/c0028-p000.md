## 重點摘要

1. **預測是一個欄位，而欄位必須在評分期間有所變化。** 平穩模型的多步預測在幾步內衰減到無條件平均值，因此無論模型準確程度如何，它涵蓋的幾乎每個交易日都是同一個數字。
2. **向前一步是預測期間，不是參數政策。** 以固定參數濾波，以及在擴展視窗上重新擬合，都具有因果性，差異在成本及參數是否跟隨資料。不具因果性的是在包含待預測值的視窗上重新擬合；對預測區塊使用 `apply(endog, refit=True)`，或在整份樣本上擬合，就會如此。
3. **資訊準則與資訊係數在不同區塊衡量不同事物**，模型可能在一項領先、另一項落後。應依讀取訓練區塊的資訊準則選擇，再報告資訊係數。
4. **不要隱藏收斂警告。** 未收斂擬合的準則值，無法與已收斂的結果相比；捕捉警告，就能把它變成網格的一欄，而非讀者看不見的雜訊。
5. **一個標的只是一筆抽樣。** 整組資產的資訊係數分布跨越零，這才是研究發現；單一標的的數值落在該分布之內。
