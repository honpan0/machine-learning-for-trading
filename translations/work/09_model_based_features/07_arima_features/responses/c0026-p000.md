分布才是答案，也比單一標的的數值更有用。它的四分位數跨越零，中位數則略高於零，表示欄位對方向只有微弱且不穩定的資訊；它既非完全無用，也尚不能可靠使用。先前的單一標的結果落在整組資產的分布範圍內，而非獨立於其他標的之外。

不要把高於零的比例讀成一百票。這些 ETF 的投資範圍彼此重疊，因此報酬率高度相關，預測誤差也是如此；該比例背後的獨立觀測值數量遠小於標的數量，而此處沒有檢定能說明究竟少了多少。

相信這個分布之前，還要看收斂情況的切分。這些擬合中有六分之一在最佳化器回報收斂之前就停止，其參數只是停下時的數值，而非最大值。它們仍包含在上述分布中；把兩組的中位數並列印出，是檢查這點是否有影響的低成本方法。結果確實有影響：兩個中位數不同，未收斂擬合的標的更接近零，因此整組資產的主要數值受到尚未達到最大值的擬合拉動。即便如此，它們仍被保留，因為移除它們等於依各標的擬合難易程度篩選資產組；那是最佳化器的性質，不是市場的性質。誠實的報告應同時呈現兩個中位數。
