# GARCH 波動率特徵

**第 9 章 | 第 9.3 節**

**Docker 映像檔**：`ml4t`

上一份 Notebook 對報酬率的平均數擬合模型，發現幾乎沒有可預測的內容。變異數則不同：大幅波動會成群出現，因此今日波動的幅度，能在很大程度上提示明日波動的幅度。**GARCH** 就是對此建模的模型；它每個交易日產生一個數字，估計下一個交易日預期會有多大的波動率，恰好具有特徵應有的形式。

**學習目標**

- 在擬合波動率模型之前，檢定序列是否具備模型所假設的性質。
- 將兩個 GARCH 參數解讀為其決定的行為：新變動會使估計值改變多少，以及估計值會記住多久。
- 擷取條件波動率作為欄位，並檢查模型是否捕捉到擬合時要捕捉的現象。
- 擴展模型，使下跌比相同幅度的上漲更大幅提高估計值，並衡量額外參數是否值得。
- 將估計值轉成風險數值，並以實際發生的情況檢查該數值。
