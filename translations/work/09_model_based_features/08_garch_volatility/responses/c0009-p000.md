## 模型

GARCH(1,1) 表示下一個交易日的變異數，是三項數值的加權和：常數、上次變動的幅度，以及上次變異數估計值。

$$\sigma^2_t = \omega + \alpha\,\varepsilon^2_{t-1} + \beta\,\sigma^2_{t-1}$$

這兩個權重就是模型的核心。$\alpha$ 決定新變動使估計值改變多少，因此 $\alpha$ 大時，估計序列會跳動較劇烈。$\beta$ 決定昨天估計值有多少延續至今天，因此 $\beta$ 大時，估計序列較平滑，且需要很久才能回落。兩者總和是**持續性**；必須低於一，變異數才會有長期平均值：恰好等於一時，衝擊永遠不會衰減。

展開後，估計值是過去報酬率平方的指數加權平均，衰減率為 $\beta$，再加上由 $\omega$ 決定的下限。這點值得記住，因為它說明模型能與不能做什麼：模型能追蹤近期有多大波動，卻沒有機制預見過去尚未顯示的事。
