## 重點摘要

1. **波動率是報酬率序列中可預測的部分**，而 GARCH 擬合是把它轉成每交易日一個數字的標準方法。平均數並非如此，這是上一份 Notebook 的發現。
2. **兩個參數就是模型。** 一個決定新變動使估計值改變多少，另一個決定舊估計值有多少延續至下一日。兩者總和決定衝擊衰減所需時間；幾乎每項流動性高的資產都略低於一。
3. **檢查標準化殘差，並預期得到兩種不同答案。** 群聚消失，表示變異數模型有效；厚尾仍在，表示創新項分布錯誤，需要另行修正。
4. **風險數值是一項可透過計數檢驗的主張。** 在每個交易日套用風險值規則並計算超越次數，就是檢查方法；在厚尾資料上使用常態分布假設，結果會低估風險。
5. **特徵必須以濾波產生，而非在原位置擬合。** 在訓練區塊估計參數，再向前執行遞迴，可得到未受後期報酬率影響的欄位；而在此資料上，它與樣本內版本本來就十分接近。

**已知限制。** 此處每次擬合都假設創新項服從常態分布，但殘差診斷否定這項假設；改用 Student-t 擬合主要會改變風險值數字，對其他結果影響較小。超越次數是針對完整樣本擬合的樣本內結果。整組資產的標的高度重疊，因此其持續性分布並非一百筆獨立抽樣。此外，這裡的預測期間都不超過一個交易日；若更長，變異數朝長期水準均值回歸的作用就會開始主導。
