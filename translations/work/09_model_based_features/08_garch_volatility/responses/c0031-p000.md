## 本 Notebook 產生的特徵

| 欄位 | 內容 | 時間順序保證適用範圍 |
|---|---|---|
| 濾波後的條件波動率 | 以訓練區塊擬合的參數向前執行遞迴 | 僅保留區塊 |
| 標準化殘差 | 報酬率除以該交易日估計值 | 與作為分母的估計值相同 |
| 波動率百分位排名 | 目前估計值在尾隨視窗中的位置 | 全程 |
| 波動率的波動率 | 估計值本身過去有多不穩定 | 全程 |
| 持續性 | 擬合參數，每個標的一個值，而非逐交易日欄位 | 僅在擬合區塊之後的區塊 |

應特別閱讀右欄，因為「具因果性」取決於數值所處的位置，而非產生它的建構方式。濾波序列只有在參數先於資料時，才具有此保證，也就是訓練切分之後的區塊；在訓練區塊內，相同數值所用的參數，部分由它們自身估計而來。先前繪出的標準化殘差來自完整樣本擬合，是診斷而非特徵；同理，整組資產的持續性是以各標的完整歷史估計，只有描述用途。下方儲存格會標記濾波序列中具有時間順序保證的部分。
