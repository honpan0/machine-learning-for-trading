數值集中在略低於一的位置，這是主要發現，也說明持續性通常不值得作為橫斷面特徵：幾乎每個標的都有相同數值，因此該欄位幾乎無法區分標的。真正隨標的與時間變動的是條件波動率的*水準*，應保留這一欄。

位於一的邊界則是另一回事，而這組資產確實達到該邊界。應精確說明失效的是什麼，因為範圍比聽起來窄。無論持續性為何，條件變異數的遞迴都有定義：給定起始值，每個交易日都能產生一個數字；向前 $h$ 步的預測，對每個有限的 $h$ 也都是有限值。$\omega/(1-\alpha-\beta)$ 是這些預測在期間增加時趨近的極限，而只有持續性低於一時，該極限才存在。恰好等於一時，預期預測值持續成長、無法收斂：每多一步就加上 $\omega$，卻沒有力量將它拉回。

因此，在邊界上擬合，不會使條件波動率欄位失效，也不會使單步預測失效。失效的是關於長期水準的所有陳述，包括本 Notebook 自身的長期波動率數值與半衰期；以及預測期間長到須仰賴均值回歸的預測。
