# 偵測結構性斷裂

**第 9 章｜第 9.1 節**

**Docker 映像檔**：`ml4t`

**結構性斷裂**是指某日期之後，產生序列的過程不再與之前相同：平均水準移動、典型變動幅度改變，或一筆觀測值依賴前一筆觀測值的方式改變。在較早期間擬合的每個模型，描述的都是已不再發生的過程。因此，在擬合任何模型前找出斷裂位置，以及之後持續監測，都值得投入。

本 Notebook 依一般化程度遞增，介紹三種方法：允許恰好一個斷裂的檢定、找出數個斷裂的分段方法，以及從一組統計量學習斷裂型態的分類器；這些統計量比較候選日期前後的期間。

**學習目標**

- 使用可估計斷裂日期、而不需事先指定日期的檢定，檢驗價格序列是否發生斷裂。
- 將長序列分為數段，使各段內的平均水準穩定，並解讀分段產生的日期。
- 將偵測到的斷裂轉換為模型可在指定日期讀取的欄位，且不使用該日期之後發生的事。
- 隨新觀測值到來持續監測斷裂，分別使用累積證據的統計量及只查看近期視窗的統計量，並說明各自的用途。
- 建立比較兩個相鄰視窗的統計量，包括平均值、分散程度、完整分布及相依性，再將其組合為單一偵測器。
