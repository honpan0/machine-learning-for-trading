# 不確定性特徵

**第 9 章 | 第 9.4 節**

**Docker 映像檔**：`ml4t`

本章每個模型都產生估計值。若模型還能說明對該估計值有多大把握，就會產生兩項特徵，而第二項往往更有用：模型有信心的訊號，與它只是在猜測的訊號，不應使用相同交易規模；只有第二項特徵能區分兩者。

**學習目標**

- 擬合能回傳估計值分布，而非單一數字的波動率模型，並擷取分布寬度作為欄位。
- 沿樣本向前重新擬合，使任何後驗分布都不讀取自身的未來資料；並說明每次擬合需數分鐘時的成本。
- 確認產生後驗分布的抽樣器確實收斂，而非直接假設，並了解可用來判斷的兩項數值。
- 將預測區間轉成特徵，辨識區間反映的是資料，還是模型本身。
