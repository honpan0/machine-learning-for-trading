## 向前重新擬合，以及其成本

每次擬合都需要數分鐘，這決定了下方所有設計。模型每季以之前一年的報酬率重新擬合，每次產生兩類特徵。

**參數**按定義每次擬合只得到一個數字：波動率的持續程度，以及波動率過程變動的幅度，是整個視窗的性質，而非單一交易日的性質。因此，承載它們的欄位在重新擬合之間確實為常數，並未損失資訊。

**水準**則不同。此處擷取的是訓練視窗最後一個交易日的後驗分布，屬於只以截至該日資料為條件的濾波量，因此具有因果性。但若將它沿用一整季，就不再是當前波動率估計值：到季末時，它描述的是三個月前的交易日。參數欄位可照此使用；水準則應參閱 `08_garch_volatility`，其低成本遞迴可在重新擬合之間免費向前濾波。若要在此達到同樣效果，需要粒子濾波器；這是標準做法，但超出本 Notebook 範圍。
