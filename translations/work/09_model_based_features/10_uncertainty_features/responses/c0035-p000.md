## 重點摘要

1. **後驗分布寬度是伴隨第一項特徵而來的第二項特徵。** 透過抽樣擬合的模型，在每個交易日產生一個分布；其寬度能說明點估計值未揭示的資訊。
2. **成本決定更新頻率，更新頻率決定哪些特徵仍有用。** 若模型每次擬合需要數分鐘，就只能每季重新擬合；對描述整個視窗的參數，這樣做可以接受，對描述單一交易日的水準則毫無用處。
3. **先檢查抽樣器是否收斂，再檢查這是否影響結果。** 發散、鏈間與鏈內變異數比率，以及有效樣本數，指出後驗分布是否獲得充分探索。參數能否作為特徵，還取決於下一項比較：其蒙地卡羅標準誤，相對於重新擬合之間的變動幅度。此模型的幾何形狀，使原本最適合當特徵的兩個參數，在這兩項數值上恰好表現不佳。
4. **在對數尺度上，預測標準差確實是標準差；反向轉換後則不再如此。** 保留估計時所用尺度上的不確定性，只對區間端點取指數；這是精確轉換。
5. **檢查不確定性特徵是否變動。** 固定階數模型的區間寬度會跟隨其中心水準，因此它其實是名稱具有誤導性的波動率特徵；涵蓋率檢查與比率的分散程度可揭示這點。
