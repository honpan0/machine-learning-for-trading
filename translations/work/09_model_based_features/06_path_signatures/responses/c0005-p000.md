## 何謂簽章

取一條在某區間上延伸的路徑 $X$，它具有 $d$ 個座標。其**簽章**是沿著路徑計算的所有反覆積分之集合：

$$S(X)^{i_1, \ldots, i_k} = \int_{0 < t_1 < \cdots < t_k < T} dX_{t_1}^{i_1} \cdots dX_{t_k}^{i_k}$$

定義雖短，但即使不依賴定義，也能理解前兩層。

**第一層**有 $d$ 項，每個座標一項，代表該座標在視窗內的總變化。對價格座標而言，就是視窗報酬率。

**第二層**有 $d^2$ 項。$S^{i,j}$ 與其鏡像 $S^{j,i}$ 這一對，相差路徑在座標 $i$ 與 $j$ 所構成平面中掃過的有向面積之兩倍；該面積的正負號表示路徑繞行迴圈的方向。這一層帶有摘要統計量所沒有的資訊，因為分別計算每個座標的摘要統計量，完全看不見迴圈。

**第三層及以上**承載更細緻的路徑幾何資訊，但成本依 $d^k$ 成長。

將簽章當作特徵時，有兩項性質很重要。只要路徑形狀不變，走得快或慢都不會改變簽章，因此特徵不取決於視窗碰巧包含多少觀測值。此外，不同路徑會產生不同簽章，因此就完整簽章的構造而言不會遺失資訊；遺失的是截斷所捨棄的部分。
