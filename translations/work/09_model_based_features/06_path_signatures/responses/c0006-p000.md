## 深度與兩種形式

| 深度 | $d$ 維路徑的項數 | 該層新增的資訊 |
|---|---|---|
| 1 | $d$ | 每個座標的總變化 |
| 2 | $d^2$ | 哪個座標先移動，以及移動幅度 |
| 3 | $d^3$ | 三次移動的順序，因而反映反轉與加速 |

`esig` 也會回傳第 0 層的常數項，因此深度 $K$ 的 $d$ 維路徑簽章共有 $1 + \sum_{k=1}^{K} d^k$ 個項目。當 $d = 3$ 且深度為 3 時，項數是 40；當 $d = 5$ 時則是 156。

**對數簽章**以更少的項目承載相同資訊。完整簽章遵循一些代數恆等式，因此許多項可由其他項決定；對數簽章只保留每個獨立方向的一項，其餘捨棄。模型應採用這種形式，因為冗餘項只增加欄位，並未增加可學習的資訊。
