## 何時值得使用簽章

**路徑形狀必須重要。** 簽章依幾何形狀區分視窗，因此在幾何形狀就是訊號時才有價值：一個交易日內的執行時機、形成特定日內形狀的避險資金流，以及終點相同、但緩慢趨勢與急劇反轉之間的差別。

**視窗必須長到能形成形狀，也要短到只包含一種形狀。** 二十個每日交易日已接近適用長度的下限。此方法通常用於日內視窗。

**成本在維度，不在長度。** 簽章項數會隨座標數量依 $d^K$ 成長，但幾乎不隨觀測值數量增加。路徑多加入一項資產成本很高；多加入觀測值幾乎不花成本，而重參數化不變性也表示觀測值間距不均不是問題。

**先從深度二的對數形式開始。** 深度三會為意義難以說明的項大量增加欄位，常見結果是模型拿到超過它能有效使用的欄位。

**簽章無法解決的事。** 若訊號只存在於水準或總報酬率，簽章不過是以更繁複的方式重寫已有的數字；而其個別項目也遠比移動平均難以向人解釋。
