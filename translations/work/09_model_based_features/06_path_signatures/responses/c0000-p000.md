一段價格視窗是序列，但多數特徵會捨棄順序：不論交易日以何種順序出現，平均數、標準差與總報酬率都相同。**路徑簽章**是保留順序的序列摘要方法。它可從任意長度的視窗產生固定長度的向量；兩個摘要統計量相同、形狀不同的視窗，會得到不同向量。

**學習目標**

- 描述路徑簽章的計算內容，並說明為何第一層代表總變化，第二層則記錄哪個座標先移動。
- 建立用於計算簽章的路徑，包括使先漲後跌與先跌後漲得以區分的時間座標。
- 選擇截斷深度與簽章形式，並說明各自帶來的特徵數量成本。
- 在相同視窗、數項資產之間，比較簽章特徵與手工建立的形狀特徵，並避免過度解讀單一次資料切分的比較結果。
