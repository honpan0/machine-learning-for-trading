## 路徑為何需要時間座標

沒有時間座標時，一個先漲到高點、再跌回起點的視窗，與完全未移動的視窗有相同的第一層簽章：每個座標的總變化都是零。在視窗內加入從零穩定增加到一的座標，就能解決這個問題。時間與價格配對的兩個第二層項，相差價格路徑與起終點之間直線所夾有向面積的兩倍。這是相對於該弦線的累積位移，因此能區分大部分時間位於線上方或下方的視窗；面積大小也反映偏離多遠、持續多久。

但它無法指出變動發生的時間。相同高度、從起點出發並回到起點的三角形路徑，不論早早達到高點或晚些才達到，所圍面積都相同，因此此項也相同。時間位置會顯現在第三層，這也是深度超過二有時值得增加欄位的原因。

下方建立的路徑有三個座標：時間、相對於視窗開盤時的價格，以及相對於視窗開盤時的成交量。後兩者都在視窗內正規化，因此不會引入視窗外資料；它們之間的第二層項則指出成交量是否先於價格變動。
