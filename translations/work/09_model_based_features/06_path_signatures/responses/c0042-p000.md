## 重點摘要

1. **簽章保留摘要統計量捨棄的聯合幾何資訊。** 第一層是每個座標的總變化，任何特徵集原本就有；第二層是座標配對之間的有向面積，單獨逐座標計算的方法無法取得。
2. **時間座標不可省略。** 沒有它，先漲後跌回原點的視窗，與完全未移動的視窗無法區分。
3. **使用對數形式。** 它以少得多的欄位承載相同資訊，因為完整簽章的項目滿足一些恆等式，使多數項目成為冗餘。
4. **深度會使欄位成本隨座標數量呈指數成長。** 兩個座標、深度三的成本很低；五個座標、深度三則每個視窗有 156 個欄位。
5. **單一標的的一次切分無法替兩組特徵排名。** 四個標的提供四個配對差值及其分散程度，足以說明一組特徵有多常帶來幫助，卻不足以斷定它一定有幫助。

**已知限制。** 此比較使用一個設定固定的學習器，因此衡量的是該學習器能擷取的內容，而非特徵所包含的全部資訊。同一資產類別的四個標的，每個只切分一次，是既小又相互關聯的樣本。視窗彼此重疊，因此無論擬合統計量或排序一致性，都不具備顯著性檢定所需的獨立性。比較也未納入成本、周轉率或容量，所以這裡無法判斷排序一致性的差異是否值得用來交易。
