# 跨案例研究的時間序列特徵清單

**第 9 章｜第 9.7 節**

**Docker 映像檔**：`ml4t`

九個案例研究各自執行一個模型特徵階段，並各自寫出一份產出檔：`features/model_based.parquet`。這份 Notebook 讀取這些產出檔的**結構描述**，因此能集中報告九個市場中有哪些欄位，以及它們叫什麼名稱。

明確界定這項範圍正是本篇的重點。欄位名稱不是擬合後的模型，欄位數量也不代表貢獻。這些特徵是否具有預測力，是在各案例研究的模型階段，對照結果登錄資料並在保留的測試折疊中衡量的；這裡的任何內容都無法取代該評估。清單回答的是較窄、但仍值得問的問題：哪些市場取得了哪些類型的特徵、本章建立的命名慣例是否獲得遵循，以及哪些階段完全沒有產出。

**學習目標**

- 透過特徵階段輸出的結構描述，而非載入完整資料，讀取其成果，並了解這限制了可作出的結論。
- 比較九個市場出現哪些模型特徵類別，並觀察覆蓋情況因各市場特定原因而不均。
- 辨識命名慣例檢查與模型清單之間的差別；對欄位名稱進行子字串比對，實際得到的是前者。
