## 各市場建立了什麼

表格按案例研究計算欄位數量，再依欄位名稱所含的關鍵字，將欄位歸入特徵類別。這種歸類有兩個特性，決定了表格應如何解讀。

它是**名稱檢查**，不是模型偵測。某個案例研究即使擬合了隱馬可夫模型，但若將輸出命名為 `state_probability`，這張表也看不出來。仍值得檢查，是因為命名慣例的目的，就是讓下游讀者不用打開產生欄位的 Notebook，也能知道欄位代表什麼；缺少關鍵字表示慣例未獲遵循。

一個欄位也可能被**重複計算**：若名稱同時包含 `regime` 與 `hmm`，就會符合兩種關鍵字。因此，各類別的計數相加不會等於欄位總數；表格同時呈現兩者，讓差異清楚可見，而非強行調整成相等。
