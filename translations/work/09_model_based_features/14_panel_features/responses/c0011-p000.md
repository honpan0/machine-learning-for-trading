## 價差回歸的速度

對價差擬合一階自我迴歸，係數就表示偏離在下一個交易日還剩下多少。若寫成變化量：

$$\Delta s_t = \alpha + \phi\, s_{t-1} + \varepsilon_t$$

負的 $\phi$ 表示價差被拉回原本水準；**半衰期**是預期偏離量減少一半所需的交易日數：$-\ln 2 / \ln(1 + \phi)$。若 $\phi$ 非負，表示價差不會被拉向任何水準，也就沒有可報告的半衰期。

下方會利用半衰期，決定計算交易訊號平均值與標準差所用的視窗。因此，半衰期只根據樣本最初的 `TRAIN_FRACTION` 估計。使用完整樣本選出的視窗長度會造成輕微的資料洩漏，而且容易被忽略，因為長度看起來不像參數。
