這組配對本身就是教訓，而不是成功示範。能源類股基金與原油基金之間的關係，可以用一句話說明，但在此樣本中，兩種檢定都不認為它們共整合。原因可從基金本身看出：前者持有獲利受油價影響的公司股票，後者持有期貨並支付轉倉成本；轉倉成本持續累積成漂移，任何固定組合都無法消除。

上方印出的隱含避險比率，很適合用來理解檢定遭否決的意義。它與迴歸估得的比率相差甚遠。對於找不到定態組合的配對，首要特徵向量並沒有在估計定態組合；它只是在沒有任何良好方向的系統中，找出表現最不糟的方向。其比率不應作為建立部位的依據。

下方的方法仍值得逐步研究，因為每一步都能計算，而每一步的輸出都能透露這組未通過檢定的配對有何特性。
