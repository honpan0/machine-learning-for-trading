## 以相對位置取代絕對水準

Notebook 的後半部改變了特徵的計算範圍。這裡沒有滾動視窗：運算在同一日期讀取多項資產，回傳每項資產當天在這些資產中的位置。

同一概念有三種版本，而且不可互換。**排名**是整數位置，受資產數量限制，因此無法說明資產間相距多遠。**百分位數**將排名除以資產數，使十項資產的資產池可以與五百項資產的資產池比較。**z 分數**減去橫斷面平均值，再除以橫斷面標準差；它保留距離，也因此保留離群值。若某天一項資產的變動幅度是其餘資產的五倍，三者之中只有 z 分數能表達這一點。

三者都不使用未來日期。這值得明說，因為因果性問題表面上與本章其他地方相同，答案卻不同：橫斷面運算只讀取某一日期的不同資產，無論如何運算，都不會沿時間向前看。
