1. **共整合關乎漂移，而非同步變動。** 兩檔基金即使每天同步變動，也可能無法通過兩種檢定；其中一檔承擔轉倉成本，就足以造成這種結果。明確的經濟理由是篩選的起點，不是證據：六組都有充分理由的配對，在此處採用的顯著水準下，沒有一組被 Engle-Granger 拒絕虛無假設。
2. **Engle-Granger 與 Johansen 的結果可能不同，而這種差異本身就是資訊。** 前者指定依變數，後者將配對視為系統。若只有其中一種檢定拒絕虛無假設，表示配對關係的結論取決於提問方式。
3. **用於持有部位的避險比率必須經過濾波。** 完整樣本的迴歸只給出一個數字，而該數字除了最後一個日期，在其他日期都無法取得。卡爾曼遞迴提供一個序列；其過程雜訊的設定，決定是在追蹤真實變化，還是在追逐雜訊。
4. **視窗長度也是參數，同樣會造成資料洩漏。** 決定訊號視窗大小的半衰期只在第一個區塊估計，因為以完整樣本選出的長度會造成不易察覺的洩漏。
5. **計算實際持有部位的價值，而非繪製欄位的差分。** 損益是兩項價格變動按前一交易日持股加權的結果。若對比率會變動的價差取差分，就會把比率自身的變動加入；若對兩檔基金報酬率取差，計算的則是兩腿投入等額資金的部位，即金額避險，而非估計出的股數比率。
6. **排名、百分位數與 z 分數各自捨棄不同資訊。** 排名與百分位數捨棄資產間的距離，因此更穩健，卻也會在人為製造幾乎相同的資產之間的區別。
7. **橫斷面運算不會向前看，但依資產自身歷史計算的排名可能會。** 前者跨資產讀取同一日期的資料；後者雖也稱為排名，卻沿時間軸運算，因此和其他時間序列特徵一樣，需要使用向後看的視窗。
