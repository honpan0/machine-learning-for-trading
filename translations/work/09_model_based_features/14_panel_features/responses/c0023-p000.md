## 以函式庫表達式表示相同特徵

上方的成對分析以 statsmodels 與 numpy 逐組配對寫出。`ml4t-engineer` 提供以 Polars 表達式表示的滾動版本，適合處理大量配對的流程：`rolling_correlation` 與 `beta_to_market` 讀取報酬率欄位，`co_integration_score` 讀取價格欄位，`correlation_regime_indicator` 則讀取相關性欄位，並根據其水準輸出旗標。

這些表達式不能取代上方的檢定。某個視窗內計算的滾動分數，只描述該視窗；共整合則主張一段長樣本中的關係成立。兩者回答的是不同問題。
