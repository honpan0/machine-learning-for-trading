## 針對同一問題的兩種檢定

兩個價格序列各自都不是定態序列，但其某種固定組合是定態的，就稱兩者**共整合**。這比相關性更強，意義也不同：兩個序列可以每天同步變動，卻在多年之間無限漂離；決定兩者價差是否會回歸的，正是這種漂離。

兩種標準檢定以不同方式處理此問題。**Engle-Granger** 將一個序列對另一個序列進行迴歸，再檢驗殘差是否有單根。因此，它將其中一個序列視為依變數；若交換角色，結果也會不同。**Johansen** 將兩者視為一個系統，檢驗存在多少個定態組合。它對兩個序列是對稱的，也能擴展至兩個以上的序列。

此處兩種檢定都在完整樣本上執行；就其用途而言，這是正確做法。某個配對是否值得交易，是在交易前根據當時可用的歷史資料提出的問題；答案不是特徵，也不會進入設計矩陣。下方交易訊號讀取的任何資訊，才是不能使用完整樣本的部分。
