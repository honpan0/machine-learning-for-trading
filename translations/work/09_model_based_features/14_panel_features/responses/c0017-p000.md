## 實際持有部位會產生的報酬率

在交易日 $t$ 期間持有的是依變數基金的一股，對應另一基金的 $\beta_{t-1}$ 股，因為 $\beta_{t-1}$ 是濾波器在前一日收盤時算出的比率。以美元計算的損益，是兩項價格變動依持有股數加權的結果：

$$\Delta P_t - \beta_{t-1}\, \Delta Q_t$$

若要表示為報酬率，就除以兩腿部位所占用的價值，也就是第一檔基金一股的價值，加上第二檔基金 $|\beta_{t-1}|$ 股的價值。

這裡刻意不計算 `spread` 欄位的一階差分。交易日 $t$ 的價差是以 $\beta_t$ 定義的，因此取差分會把當日價格變動與比率本身的變動混在一起；持有者無法按照當日收盤後才得知的比率重新平衡。只有在濾波後的比率不變時，兩者才會一致。

這也不是兩檔基金報酬率之差。後者對應兩腿投入相等美元金額時的損益，屬於金額上的避險，而非股數上的避險，完全不使用估計出的比率。策略要採用哪一種是可以選擇的；但若估計一種比率，卻報告另一種部位的結果，就不合理。

這裡有三項結構性限制，無法在此修補。計算未扣除交易成本與滑價，而價差策略交易頻繁，對兩者都相當敏感。假設放空的一腿可以借到，且無借券成本。此外，配對是看過同一段歷史資料後選出的，後續篩選一節會討論這點。
