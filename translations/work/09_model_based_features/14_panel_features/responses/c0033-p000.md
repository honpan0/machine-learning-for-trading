## 將一項指標彙總至整個資產池

最後一項建構將各資產的市場狀態指標轉為資產池層級的特徵。有三種彙總值，分別回答同一日期的不同問題：

- 資產間的**平均**壓力，表示整體水準。
- **廣度**，即高於門檻的資產比例，用來區分只有少數資產出問題，還是全部資產都有問題。
- **離散程度**，即資產間的標準差；所有資產同步變動時偏低，資產池分化時偏高。

這裡各資產的指標，是其波動率在過去 `REGIME_WINDOW` 個交易日視窗內的排名，用來替代 `11_hmm_regimes` 產生的濾波市場狀態機率。`rolling_rank` 使它成為替代指標，而非資料洩漏：若按每項資產的完整歷史排列波動率，今天的數值就會與尚未發生的未來年份數值比較；所得序列看似市場狀態指標，卻只有最後一個日期能實際取得。
