# 面板特徵

**第 9 章｜第 9.6 節**

**Docker 映像檔**：`ml4t`

到目前為止，每項特徵都從單一序列計算而來。本篇 Notebook 計算需要兩個或更多序列的特徵。它們分為兩類，除了都需要面板資料之外，幾乎沒有共同之處。

**成對**特徵讀取兩個價格序列，詢問當兩者本身都不具定態性時，其某種組合是否為定態。這是共整合問題，輸出包括價差、避險比率與均值回歸速度。

**橫斷面**特徵在同一日期讀取多項資產的某個數值，並以該數值在這些資產之間的相對位置取代其絕對水準。年化波動率為四分之一，對公債基金與能源基金的意義不同；排名則不必知道個別水準，就能指出讀者看到的是哪一類。

**學習目標**

- 以兩種方法檢定一對資產是否共整合，並解讀兩種結果不一致時的意義。
- 使用卡爾曼濾波器估計隨時間變動的避險比率，觀察它與全樣本迴歸所得的單一數值有何不同。
- 在第一個資料區塊估計均值回歸半衰期，並據此決定交易訊號的計算視窗大小，避免以未來資料選擇視窗長度。
- 將時間序列特徵轉為橫斷面排名與相對基準值，說明下游模型需要哪一種。
- 在整個資產池彙總各資產的市場狀態指標，同時避免用每項資產未來的資料評定其排名。
