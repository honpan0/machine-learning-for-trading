# 分數差分

**第 9 章 | 第 9.1 節**

**Docker 映像檔**：`ml4t`

對價格序列做一次差分，可以使其平穩，卻也會捨棄價格水準。這是真實的資訊損失：價格接近近期區間的頂部或底部，本身就是資訊；報酬率序列卻完全沒有這項資訊。**分數差分**以分數階數進行差分，足以使序列平穩，同時保留部分價格水準資訊。

**學習目標**

- 說明對序列進行分數階差分的意義，並理解實現這項運算的權重。
- 在一系列分數階數上套用轉換，解讀其中的取捨：原始水準保留了多少，以及結果在平穩性檢定中有多強的表現。
- 說明轉換會損失樣本開頭的多少筆觀測值，以及為何答案取決於所選慣例，而非資料本身。
- 選擇分數階數時，不搜尋將用來測試的樣本。
