## 重點摘要

1. **階數控制一項取捨，卻要付出兩次代價。** 較低階數保留更多水準資訊，通過平穩性檢定的強度也較弱；它還需要較寬的視窗，因此損失更多預熱期觀測值。
2. **邊界慣例是一項會改變答案的選擇。** 邊界部分視窗形式保留每一列，並以較短的濾波器計算開頭各列；完整視窗形式則捨棄它們。在一種慣例下計算的診斷，不能直接套用到另一種慣例；因此，此處的函式庫輔助函式會選出完整視窗慣例根本無法使用的階數。
3. **將樣本損失與特徵一併報告。** 它是每個序列開頭模型不得讀取的列數，並會隨階數與截斷門檻改變。
4. **固定階數，而非搜尋階數。** 依資產類別固定的階數對任何地方都不是最佳值，也不是從資料估計的。若無法避免搜尋，應只在訓練資料截止點之前搜尋，並採用能通過檢定的最小階數。
5. **轉換結果並非完全平穩。** 截斷使權重總和留下小幅正值，因此輸出帶有該比例的水準資訊，並隨之漂移。它通過檢定，但並未完全去除水準。

**已知限制。** 此處以 ADF 檢定判斷平穩性；這只是一種檢定，對緩慢均值回歸的替代情況已知檢定力偏低，因此它接受某個階數，並不能證明該階數已足夠。各資產類別的階數是慣例，不是測量結果。此外，整組資產一節在一段九年期間內，對每個類別套用單一階數；若樣本更長且包含不同的波動率狀態，通過檢定的標的可能改變。
