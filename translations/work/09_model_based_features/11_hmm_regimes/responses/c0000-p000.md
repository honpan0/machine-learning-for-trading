# 使用隱藏馬可夫模型偵測市場狀態

**第 9 章 | 第 9.5 節**

**Docker 映像檔**：`ml4t`

**市場狀態**是市場以某種方式而非另一種方式運作的期間，例如平靜或緊繃、趨勢延續或均值回歸。沒有人能直接觀察到它。市場狀態模型的工作，是從可觀測資料推斷市場目前最可能處於少數幾種隱藏狀態中的哪一種，以及明日轉入另一狀態的機率。

比模型本身更重要的區別，是某項推斷只使用截至特定交易日已發生的事，還是使用整份樣本。第二種做法在各方面都較好，唯獨在最重要的時間順序要求上不行。

**學習目標**

- 僅以可觀測的量建立兩個市場狀態指標，並將它們視為任何估計模型都必須超越的基準。
- 透過小到可以手動檢查的例子，逐步理解如何每次使用一筆觀測值來推斷隱藏狀態。
- 說明這種遞迴結果與讀取完整樣本的結果有何不同，並在真實資料上衡量差異。
- 將模型擬合於報酬率，處理擬合時會出現的三個問題，再將結果轉成欄位。
