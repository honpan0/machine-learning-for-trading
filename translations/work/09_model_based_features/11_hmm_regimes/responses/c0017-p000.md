# 第三部分：擬合於報酬率

若此模型的參數不是事先給定，而須從資料估計，會出現三個問題；每個問題都有標準解法。

**最佳化器找到局部最大值。** 期望最大化演算法會從起點向上爬升，到達第一個峰值就停止，因此不同起點會得到不同模型。解法是從多個位置起始，保留概似值最高者；或從合理位置開始：對觀測值分群，可讓初始發射參數接近最終位置。

**狀態數量必須選擇。** 狀態越多，擬合程度總會越好，所以選擇準則必須對狀態數施加成本。

**狀態沒有固定順序。** 模型本身未規定哪個狀態是哪個，因此同一次擬合重新執行，可能以交換順序回傳；若特徵依狀態標籤建立，便會在不同視窗代表相反意義。解法是依模型確實有定義的量排序，此處使用各狀態的變異數大小。

下方四個輔助函式都放在 `case_studies.utils.temporal`，而非此 Notebook；特別是濾波推斷需要呼叫 hmmlearn 的私有方法，值得集中管理：`predict_proba` 回傳平滑後驗機率，卻沒有公開方法可回傳前向遞迴所需的發射項。
