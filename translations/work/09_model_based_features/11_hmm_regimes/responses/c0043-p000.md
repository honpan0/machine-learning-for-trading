## 本 Notebook 產生的特徵

| 欄位 | 內容 | 具因果性 |
|---|---|---|
| `filtered_stressed` | 由前向遞迴所得的高變異數狀態機率 | 推斷過程有，參數沒有 |
| `state` | 該機率較支持哪個狀態 | 同上 |
| `state_entropy` | 模型在各狀態之間有多猶豫 | 同上 |
| `expected_duration` | 模型預期目前狀態持續多久 | 擬合結果的性質 |
| `switching_stressed` | 轉換模型所得的相同機率 | 同上 |
| `stressed_by_index`、`below_average` | 第一部分的兩項規則 | 完全具備，不需估計任何參數 |

表格中間欄的限制必須仔細解讀。此處每項機率都經過濾波，因此其**推斷**只使用截至自身交易日的觀測值。但**參數**是以完整樣本擬合模型而得，所以某日的機率，是由已看過所有後續交易日的轉移矩陣產生。嚴格遵守時點資訊的流程，會在每個摺疊的訓練區塊重新擬合模型，再逐摺疊擷取濾波機率；`case_studies/etfs/04_model_based_features.py` 正是這樣做，回測也應讀取該結果。

本 Notebook 保留單次擬合，因為教學重點是濾波推斷與平滑推斷的差別；若逐摺疊重新擬合，同一張圖便會混入第二個議題。此處沒有將任何結果寫入磁碟，因此後續流程不會讀到參數曾看過自身未來資料的欄位。
