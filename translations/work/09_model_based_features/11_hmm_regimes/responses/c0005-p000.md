## 資料

使用 SPY 每日價格資料，並衍生三條序列：對數報酬率、其滾動標準差，以及價格的長期移動平均。前兩者供模型讀取，移動平均則用於第一部分的兩項規則之一。

只讀取報酬率的高斯模型，本來就能區分僅變異數不同的狀態，因為平均數相同、變異數不同的兩個發射分布，仍是兩個不同分布。因此，加入波動率欄位不是為了讓模型取得此能力；加入它是因為它代表過去一個月的摘要，而非單一交易日。這使每個交易日推斷的狀態，反映近期歷史而不只反映最新報酬率。

資料框只保留三者皆有定義的交易日，因此第一筆資料位於原始資料開始後一個移動平均視窗。這個視窗是第一部分規則的代價：期間內移動平均缺失，而與缺失值比較的結果為假，並非缺失；若保留那些列，會把它們報告成價格未低於自身平均值的交易日。
