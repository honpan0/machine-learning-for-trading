## 重點摘要

1. **兩項不需擬合的規則設下基準。** 指數門檻與長期移動平均透明、即時，也沒有估計風險。擬合模型必須在某方面勝過它們，才值得使用。
2. **使用濾波，不使用平滑。** 前向遞迴只以過去資料為條件；平滑後驗分布則以所有資料為條件。兩者恰好在市場狀態特徵要捕捉的轉換點出現分歧，本 Notebook 也測量出分歧交易日的比例。
3. **硬性標籤也需要與機率相同的謹慎處理。** 模型自身的 `predict` 會在整段序列上解碼，因此取自它的狀態標籤會讀取未來，即使旁邊的機率沒有。
4. **擬合後的市場狀態模型有三個常見問題，各有解法。** 局部最佳值可用分群起點或多次起始處理；狀態數量先用施加成本的準則，再按特徵用途判斷；狀態的任意排序則依模型有定義的量排序。
5. **濾波推斷不等於嚴格遵守時點資訊的特徵。** 參數也經過擬合；若使用完整樣本，後期每個交易日都會進入早期每項機率。逐摺疊重新擬合可消除此問題，代價是每摺疊擬合一次；`case_studies/etfs/04_model_based_features.py` 展示了這種做法。
