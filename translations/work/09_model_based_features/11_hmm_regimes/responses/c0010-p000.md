# 第二部分：推斷看不見的狀態

**隱藏馬可夫模型**有三個部分：少數幾個隱藏狀態；表示從每個狀態轉到其他狀態之機率的**轉移矩陣**；以及每個狀態的**發射分布**，說明它傾向產生哪些觀測值。狀態從未被直接觀察；可觀測的是一連串數字，而模型要判斷每個數字最可能來自哪個狀態。

**前向演算法**每次處理一筆觀測值。它保留各狀態的機率，先透過轉移矩陣向前推進，再乘以新觀測值在各狀態下的可能程度，最後重新正規化。每一步得到 $P(\text{state}_t \mid \text{observations up to } t)$，稱為**濾波機率**，也是可用作特徵的量。
