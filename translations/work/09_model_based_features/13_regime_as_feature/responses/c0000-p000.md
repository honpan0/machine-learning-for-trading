# 將市場狀態作為特徵

**第 9 章｜第 9.5 節**

**Docker 映像檔**：`ml4t`

前三份 Notebook 建立了市場狀態標籤與機率。本篇要使用它們；問題不在於市場狀態是否真實存在，而在於預測模型應如何接收這些資訊。有兩種設計可選，差別在於市場狀態判定錯誤時會發生什麼事。

若將市場狀態機率當作另一個欄位提供給模型，仍只需一個以所有交易日資料擬合的模型，且模型可以使用或忽略該欄位。若依市場狀態拆分訓練資料，為每種狀態分別擬合模型，每個模型就只能看到所屬狀態的交易日；預測時遭誤分類的交易日，則會被送進從未見過同類資料的模型。

只有以正式環境會採用的方式建立市場狀態特徵，這項比較才有意義。這項限制貫穿整份 Notebook：每個折疊內都只用訓練區塊重新擬合隱馬可夫模型，並以僅依據過去資訊的前向遞迴計算機率。

**學習目標**

- 在滾動向前迴圈內建立市場狀態特徵，確保每個折疊的特徵都未以該折疊的測試區塊擬合。
- 使用及不使用該特徵來擬合相同的預測模型，並參照各折疊結果的離散程度解讀差異，而非只看單一數字。
- 建立專家混合模型這項替代方案，觀察拆分訓練資料的代價。
- 解讀接近零的特徵重要性，說明它對該特徵能與不能透露什麼。
