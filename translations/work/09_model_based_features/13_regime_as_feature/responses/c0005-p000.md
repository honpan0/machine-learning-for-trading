## 資料與目標

將 SPY 的每日收盤價與波動率指數依交易日合併。這些特徵都是讀者先前見過的：報酬率、報酬率的滾動標準差、兩種不同期間的動能加總，以及相對於自身近期水準衡量的波動率指數。最後一項使該欄位在指數平均值曾變動的二十年間仍可比較。

目標是接下來 `FORECAST_HORIZON` 期報酬率之和。它涵蓋未來這麼多個交易日，因此下方折疊必須設置間隔：在交易日 $t$ 結束的訓練區塊，包含由截至 $t + 5$ 的報酬率建立的目標（在 $t+5$ 的滾動總和，往前平移預測期間後，就是 $r_{t+1}+\ldots+r_{t+5}$）。因此，若測試區塊從 $t + 1$ 開始，所預測的交易日就已出現在訓練標籤中。
