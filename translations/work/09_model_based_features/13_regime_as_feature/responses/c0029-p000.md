## 重點整理

1. **市場狀態特徵必須在使用它的折疊內重新擬合。** 若先在整個樣本上擬合一次隱馬可夫模型，再切分折疊，每個折疊的測試區塊資訊都會進入其特徵參數。正確做法的代價是每個折疊都要擬合一次，而且對於折疊之間共有的交易日，特徵值會彼此不同。
2. **使用濾波機率，而非平滑機率。** `predict_proba` 與 Viterbi 解碼都以整個序列為條件。前向遞迴則只以過去為條件，符合當天可取得的資訊。
3. **先看折疊間的離散程度，再看平均值。** 此處的誤差在折疊之間的變動，比在設計之間更大；若只列平均數而不列離散程度，便會掩蓋這點。無論如何配對，五個巢狀折疊都不足以支持差異具有顯著性的主張。
4. **專家混合模型以樣本量換取明確分工。** 每位專家只能看到所屬市場狀態的訓練資料列，分配錯誤的測試交易日則會進入從未見過同類資料的模型。只有一個模型並加入市場狀態欄位時，模型表現會逐漸變差，而不是切換到另一個模型。
5. **市場狀態欄位的不純度重要性偏低，也反映了其他欄位的資訊。** 若 `volatility` 已是特徵，根據波動率擬合出的機率所增加的資訊，大多可由樹直接取得。當基本特徵本身不含波動率資訊時，同一欄位的排名就會更高。
6. **檢查每個函式庫表達式讀取的輸入。** 上述目錄中有一半的表達式讀取價格，並在內部計算差分；若將報酬率欄位交給它們，會產生看似合理的數字，卻不會報錯。
