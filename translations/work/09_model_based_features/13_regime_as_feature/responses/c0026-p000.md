### 不必逐一寫出的交互作用

`regime_conditional_features` 將一項特徵乘上市場狀態欄位各個值的指示變數，因此每個輸出欄位都只在一種市場狀態下保留該特徵，在其他狀態下為零。如此一來，線性模型無須分支就能為各狀態擬合不同係數；樹模型也能取得已建立的交互作用欄位，不必再透過兩次分割自行找出。

下方的市場狀態值是 `market_regime_classifier` 輸出的三種值，沒有任何一種表示方向：一代表有趨勢的市場，零代表過渡狀態，負一代表區間震盪或反覆波動的市場。分類器讀取趨勢強度指標與盤整程度指標，兩者都沒有正負方向，因此無論市場強勢下跌或強勢上漲，都會回傳一。

`regime_conditional_features` 根據負一、零、一這三個值，將輸出欄位命名為 `feat_bear`、`feat_neutral` 和 `feat_bull`。這套名稱適用於狀態具有方向性的分類器；對此分類器而言，名稱是錯的，只有數值有意義。因此，下方會明確列出並檢查對應關係。
