此處接近零的重要性，並不表示市場狀態沒有資訊量。它表示在這組特徵下，這個模型發現市場狀態可供分割的資訊很少超出 `volatility` 已提供的資訊，而 `volatility` 是用來擬合隱馬可夫模型的兩個序列之一。市場狀態機率是相同資訊的非線性摘要，另帶有持續性假設；若樹已能根據原始序列分割，就能直接取得其中大部分資訊。

由此可得兩點。若基本特徵不包含市場狀態模型讀取的資訊，同一欄位的重要性排名可能高得多；第 16 章的案例研究將市場狀態特徵與本身不含波動率資訊的橫斷面訊號一起使用。此外，兩個相關欄位的重要性會任意分配在兩者之間，因此相關欄位之一的數值偏低，不能作為判斷任一欄位的證據。
