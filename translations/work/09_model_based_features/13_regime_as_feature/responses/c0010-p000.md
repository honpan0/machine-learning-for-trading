## 三種設計，同一個迴圈

每種設計都使用相同的折疊、相同的特徵，以及相同的折疊內市場狀態特徵。差別只在於如何使用這項特徵。

- **基準模型**只以 `BASE_FEATURES` 擬合一個模型，完全不使用市場狀態。
- **將市場狀態作為特徵**：以 `BASE_FEATURES` 加上高波動狀態的濾波機率，擬合一個模型。
- **專家混合模型**：僅以 `BASE_FEATURES` 為每個硬性狀態各擬合一個模型，按照訓練區塊的狀態拆分訓練資料列，並將每個測試交易日送往其所屬狀態的模型。若某個狀態的訓練資料列少於 `MINIMUM_REGIME_SESSIONS`，便不為它建立專屬模型，該狀態的測試交易日改由另一個模型處理。

每個折疊的縮放器都重新以訓練區塊擬合，再套用到測試區塊。這一點比乍看之下更重要：若縮放器以整個樣本擬合，測試區塊的平均值與變異數便會悄悄滲入訓練資料。
