# HAR 與粗糙波動率

**第 9 章 | 第 9.3 節**

**Docker 映像檔**：`ml4t`

上一份 Notebook 的 GARCH 模型只有一種記憶：用單一衰減率決定衝擊持續多久。本 Notebook 討論這種記憶無法表達的兩件事。**HAR** 以每日、每週和每月三種時間尺度取代單一衰減，其理由是依這三種節奏交易的是不同群人。**粗糙性**則問完全不同的問題：不是波動率能記住多久，而是其路徑有多鋸齒不平；真實市場的答案，比過去三十年標準模型所假設的粗糙得多。

兩者都需要先有波動率的測量值，因此如何正確測量，是本 Notebook 前三分之一的主題。

**學習目標**

- 從交易時段內資料計算波動率，並據此檢查僅憑每日價格資料可得的估計器究竟在衡量什麼。
- 擬合跨越三種時間尺度的波動率模型，將係數解讀為哪個時間尺度主導目前水準的資訊。
- 修正擬合的標準誤，以處理其解釋變數自身包含的重疊部分。
- 估計序列隨時間變化有多不平滑，分別套用於報酬率與波動率，並將兩個答案視為不同事物解讀。
