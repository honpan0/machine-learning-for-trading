# 第三部分：路徑有多粗糙

**Hurst 指數** $H$ 描述序列變動幅度如何隨測量區間長度縮放。對隨機漫步而言，走過的距離隨區間長度的平方根增加，即 $H = 1/2$。高於二分之一時，序列具有持續性：一次變動之後，更可能繼續朝同一方向變動，因此路徑走得比隨機漫步更遠。低於二分之一時，序列具有反持續性，或稱**粗糙**：變動傾向反轉，所以路徑呈鋸齒狀，走過的淨距離較短。

估計前應區分兩種用途。套用於**報酬率**時，$H$ 表示價格是在趨勢延續，還是向均值回歸；對流動性高的市場而言，結果接近二分之一，因為其他結果會形成可交易規律。套用於**對數波動率**時，它表示波動率路徑有多鋸齒不平。Gatheral、Jaisson 與 Rosenbaum（2018）發現，對其測量的每類資產，結果都接近十分之一，遠低於標準波動率模型數十年來所假設的二分之一。
