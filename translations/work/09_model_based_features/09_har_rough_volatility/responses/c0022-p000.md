# 第二部分：以三種時間尺度取代一種

**異質自迴歸**模型（Corsi，2009）以截至今日的三種波動率平均值，預測明日波動率：昨日、過去一週及過去一個月。

$$RV_{t+1} = c + \beta_d\,RV^{(d)}_t + \beta_w\,RV^{(w)}_t + \beta_m\,RV^{(m)}_t + \varepsilon_{t+1}$$

採用這種形式的理由來自經濟行為，而非統計。不同交易頻率的交易者關注不同時間尺度的波動率，並依所見採取行動，因此市場波動率是其反應的疊加，而非單一衰減。模型本身是線性迴歸，比 GARCH 更易擬合，也更易解讀：每個係數就是一個時間尺度的權重。

解釋變數使用區間型估計器建構，原因如第一部分所述；每個變數都設有落後期，確保迴歸右側沒有任何資料的已知時間晚於其預測所依據的交易日。
