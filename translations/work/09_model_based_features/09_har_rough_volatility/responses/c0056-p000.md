## 本 Notebook 產生的特徵

| 欄位 | 內容 | 具因果性 |
|---|---|---|
| `daily`、`weekly`、`monthly` | 三種時間尺度的區間型波動率落後平均值 | 是 |
| HAR 係數 | 各時間尺度的權重，在移動視窗上重新擬合 | 是，以過去視窗重新擬合 |
| 期限結構比率 | 短時間尺度除以長時間尺度 | 是 |
| 報酬率指數 | 在移動視窗上，價格過去傾向趨勢延續或均值回歸的程度 | 是 |
| 對數波動率指數 | 波動率路徑過去有多鋸齒不平 | 是 |

分鐘價格資料測得的已實現波動率未列入表中，因為它只涵蓋兩個標的、兩年資料；第一部分的目的，是確認哪種每日估計器可作為其替代。
