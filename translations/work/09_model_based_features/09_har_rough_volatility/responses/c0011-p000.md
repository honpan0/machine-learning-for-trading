## 第二個陷阱：一個交易時段並不等於一整天

收盤至收盤報酬率，恰好等於隔夜變動加上隨後的交易時段變動，因為兩者都是對數。因此，下列恆等式逐項成立，無須近似：

$$\mathbb{E}[r_{cc}^2] = \mathbb{E}[r_{on}^2] + \mathbb{E}[r_{oc}^2]
  + 2\,\mathbb{E}[r_{on} r_{oc}]$$

其中 $r_{oc}$ 是交易時段開盤至收盤的**總報酬率**。這與由分鐘價格資料測量的已實現變異數不是同一個量：已實現變異數是每分鐘報酬率平方的總和；總報酬率的平方則是先加總每分鐘報酬率再平方，因此兩者相差所有分鐘之間的交叉乘積。下方會分別報告兩者，因為它們回答不同問題；若將它們混為一談，就可能讓實際上不精確的分解看似完全成立。
