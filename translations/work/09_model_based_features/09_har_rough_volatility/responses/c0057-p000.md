## 重點摘要

1. **只要可行，就以實際測量值檢查估計器。** 收盤至收盤報酬率的平方，會漏掉一個先變動又回到原點的交易時段；區間型估計器能看見它。與分鐘價格資料測得的波動率比較，才能知道各估計器偏差的幅度與方向。
2. **HAR 是線性迴歸，而這正是它的優勢。** 三種落後平均值追蹤已實現波動率的能力，與擬合後的 GARCH 大致相當；而且與 GARCH 不同，每個係數都能解讀為某個時間尺度的權重。
3. **解釋變數重疊是放寬標準誤假設的理由，卻不能證明殘差相關。** 即使解釋變數是滾動平均，正確設置的模型仍可有獨立創新項。若要解讀放寬某項假設的代價，就只改變該假設：以相同 Newey-West 估計器分別使用零落後期與模型最長時間尺度，兩者只在視窗不同；跨兩種不同共變異數估計器的比較，無法做到這點。
4. **預測不同測量目標的兩個模型，不能用誤差大小排名。** 應將各模型的平均預測值列在目標平均值旁邊，並解讀不受水準差異影響的相關性。
5. **粗糙性是市場研究發現，卻是不佳特徵。** 整組資產中，每個標的的對數波動率指數都遠低於二分之一；這說明標準模型為何錯誤，也說明持有該指數的欄位無法區分標的。報酬率指數則在二分之一兩側穿越，值得保留。
