# Tail-GAN：學習產生保留尾端風險的情境

**第五章：合成資料生成**
**章節參照**：第 5.5 節（金融時間序列的 GAN）

**Docker 映像檔**：`ml4t-gpu`

> **建議使用 GPU**：本 Notebook 使用 PyTorch/CUDA 訓練模型。也能以 CPU 執行，但訓練可能非常緩慢。若要使用 GPU 加速：
> ```bash
> docker compose run --rm ml4t-gpu python 05_synthetic_data/02_tailgan_tail_risk.py

## 目的

本 Notebook 實作 **Tail-GAN**（Cont、Xu 與 Zhang，2022），這種 GAN 架構使用可微分排序，在合成金融情境中保留尾端風險特徵（VaR、ES）。

## 學習目標

- 理解可微分排序如何讓梯度流經分位數計算（VaR／ES）
- 實作約束投影，以強制滿足關係 $W \cdot VaR \leq ES$
- 產生保留尾端風險結構的投資組合損益情境
- 使用 VaR／ES 相對誤差評估生成品質

## 書籍參照

第 5.5 節討論 Tail-GAN 如何以特定風險指標為目標，而非一般性的分布匹配，以填補 TimeGAN 留下的缺口。

## 先備條件

需要 ETF 資料。產生器將輸出箝制於 [-1, 1]，因此將報酬率除以其最大絕對值，使完整尾端維持在箝制範圍內而不發生飽和。
