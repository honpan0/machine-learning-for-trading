## 核心概念

1. **序列化**：將表格列轉為自然語言句子
2. **微調**：在序列化金融資料上訓練 GPT-2
3. **生成**：LLM 產生新「句子」，再解析回表格列
4. **混合型別**：自然處理類別、數值與文字特徵

## 為何用 LLM 處理表格資料？

- 透過注意力捕捉複雜的特徵相依性
- 無須明確的分布假設
- 自然處理混合資料型別
- 預訓練的語言理解能力有助於理解特徵名稱
