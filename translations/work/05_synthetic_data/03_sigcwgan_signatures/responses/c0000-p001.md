TimeGAN（2019）引入嵌入空間與逐步監督，但其判別器仍使用二元分類器區分真偽，無法為產生器訓練提供平滑的梯度地景。

Sig-CWGAN（2020→2024）引入兩項創新：

1. **簽章距離**：使用**期望簽章**描述時間序列分布，取代經訓練的判別器。簽章是一組通用特徵，可唯一識別路徑空間上的機率測度。
2. **條件式 W1 度量**（論文的完整方法）：學習條件分布 P(future | past)，而非無條件分布；這對金融更有用（給定昨天發生的事，明天可能發生什麼？）。本 Notebook 實作無條件 Sig-W1 核心；條件式度量僅在此描述，留作擴充。

## 什麼是路徑簽章？

路徑的簽章是迭代積分的無限級數，可在忽略重新參數化差異的意義下，完整刻畫路徑：

```
Sig(X)_t = (1, ∫dX_s, ∫∫dX_s⊗dX_u, ∫∫∫dX_s⊗dX_u⊗dX_v, ...)
```

**主要性質**：
- **唯一性**：期望簽章 E[Sig(X)] 唯一決定隨機過程 X 的分布（在溫和條件下）
- **通用性**：任何路徑的連續函數，都可由簽章的線性函數近似
- **可計算性**：截斷簽章的計算可實際處理

## 架構概覽

Sig-CWGAN 包含三個主要元件：
1. **路徑增強**：將原始報酬率轉成可計算簽章的路徑
2. **簽章計算**：計算截斷路徑簽章
3. **AR-FNN 產生器**：以過去資料為條件的自迴歸前饋網路
