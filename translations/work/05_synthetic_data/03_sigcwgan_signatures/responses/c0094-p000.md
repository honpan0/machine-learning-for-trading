## 重點

**Sig-WGAN 的優點**：

1. **無須對抗式訓練**：「判別器」就是期望簽章，消除了模式崩潰與訓練不穩定
2. **有理論依據的距離**：路徑簽章提供數學上嚴謹的時間序列分布比較方法
3. **階乘正規化**：將簽章各層級重新縮放至可比較的量級，是穩定訓練與有意義損失值的關鍵

**遵循論文**（Ni 等人，Mathematical Finance，2024）。下方每項數值設定都在開頭附近的 `CONFIG` 儲存格中宣告，該處是唯一修改位置：

1. **產生器**：以布朗運動雜訊驅動的 LSTM；高斯增量以 `BROWNIAN_NOISE_SCALE` 縮放，再累積成路徑
2. **增強**：依序套用 Scale → AddTime → LeadLag → VisiTrans("I")。VisiTrans 改變路徑形狀，因此 Notebook 前面的維度檢查會同時印出預期與實際簽章大小
3. **階乘正規化**：第 *k* 層級的項乘以 *k*!，使各層級達到可比較的量級；否則較高層級太小，無法影響損失
4. **損失**：期望簽章差異的 RMSE，是 L2 範數而非平方誤差
