# 第五章：Sig-WGAN——以簽章為基礎的 Wasserstein GAN

**第五章：合成資料生成**
**章節參照**：第 5.5 節（金融時間序列的 GAN）

**Docker 映像檔**：`ml4t-gpu`

> **必須使用 Docker**：本 Notebook 使用 `signatory` 與 `esig`，這些僅支援 x86 的套件未包含在預設環境中。執行方式：
> ```bash
> docker compose --profile py312 run --rm py312 python 05_synthetic_data/03_sigcwgan_signatures.py

## 目的

本 Notebook 實作**無條件 Sig-Wasserstein GAN**，即 Sig-CWGAN（Ni 等人，Mathematical Finance，2024）的核心；它使用**路徑簽章**作為有理論依據的距離度量，比較時間序列分布。我們建構並訓練無條件版本；條件擴充 P(future | past) 會在概念上說明，但未在此實作。

## 學習目標

完成本 Notebook 後，你將能夠：
- 使用 `signatory` 函式庫，將金融時間序列轉換為路徑簽章
- 實作符合期望簽章的（無條件）Sig-Wasserstein GAN
- 使用期望簽章（Sig-W1）作為訓練目標，取代經訓練的判別器
- **理解條件式 Sig-CWGAN 如何以蒙地卡羅期望簽章目標擴充此方法**（論文的關鍵洞見；本 Notebook 描述條件式流程，但不建構它）
- 使用簽章指標與 TSTR 評估生成保真度
