## 資料完整性與 TSTR 方法

**關鍵**：本 Notebook 實作適當的訓練／保留切分，以進行無偏的合成資料訓練、真實資料測試（TSTR）評估。

### 正規化：保留正負號（關鍵）

**重要**：我們使用 z 分數正規化（平均值 0、標準差 1），而非將數值最小值－最大值縮放至 [0,1]。

為什麼？路徑簽章使用累加和。若報酬率映射至 [0,1]，每個座標都會單調遞增，路徑只能「向上」。這會破壞報酬率的正負號結構，而該結構對有意義的金融路徑與簽章至關重要。

```
WRONG:  returns ∈ [0,1] → cumsum always increases → no "down" moves
RIGHT:  returns ∈ ℝ (centered) → cumsum goes up and down → realistic paths
```
