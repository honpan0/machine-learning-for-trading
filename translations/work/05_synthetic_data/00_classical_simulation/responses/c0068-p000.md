## 區塊自助抽樣

重新抽取固定長度的**連續區塊**，以保留局部相依性。

### 演算法（移動區塊自助抽樣）

```
Choose block length b
For each bootstrap sample of length T:
    While sample length < T:
        Draw start index i uniformly from {1, ..., N-b+1}
        Append block (r_i, r_{i+1}, ..., r_{i+b-1})
    Trim to length T
```

### 區塊長度選擇

- 經驗法則：$b \approx T^{1/3}$
- 金融應用：常用約 22 天（一個月）
- 最佳選擇：以樣本外統計量進行交叉驗證
