# 第一部分：連續時間價格模型

這些模型以隨機微分方程式（SDE）描述價格動態。各模型捕捉不同的市場現象：

| 模型 | 主要特徵 | 最適用途 |
|-------|-------------|----------|
| **GBM** | 對數常態價格、固定波動率 | 選擇權定價、基準 |
| **跳躍擴散** | 罕見的極端變動 | 崩盤情境、尾端風險 |
| **均值回歸** | 價格向均衡水準漂移 | 價差、大宗商品、利率 |
| **Heston** | 隨機波動率 | 波動率曲面、槓桿效果 |

我們使用區域 RNG 從零實作各模型以確保可重現性，再示範等效的函式庫呼叫。
