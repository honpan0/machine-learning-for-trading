# 第二部分：離散時間波動率模型（GARCH）

不同於上述連續時間 SDE，GARCH 是描述條件變異數的**離散時間模型**。它根據過去的衝擊，建立報酬率波動率演變的模型。

## GARCH(1,1)

$$r_t = \mu + \sigma_t \varepsilon_t, \quad \varepsilon_t \sim N(0,1)$$
$$\sigma^2_t = \omega + \alpha (r_{t-1} - \mu)^2 + \beta \sigma^2_{t-1}$$

其中：
- $\mu$ = 無條件平均報酬率（漂移）
- $\omega$ = 基礎變異數（截距）
- $\alpha$ = 對近期衝擊的反應（消息影響）
- $\beta$ = 過去變異數的持續性（記憶）
- 平穩性要求 $\alpha + \beta < 1$

### 主要性質

- **波動率分群**：$\beta > 0$ 表示波動率具有持續性
- **厚尾**：源於隨時間變動的波動率
- **均值回歸的波動率**：無條件變異數 = $\omega / (1 - \alpha - \beta)$
- **槓桿效果**：需要非對稱擴充（GJR-GARCH、EGARCH）

### GARCH 與 Heston 比較

| 面向 | GARCH | Heston |
|--------|-------|--------|
| 時間 | 離散 | 連續 |
| 槓桿效果 | 需要擴充 | 內建（$\rho$） |
| 校準 | 以資料進行 MLE | 選擇權曲面 |
| 解析性 | 有限 | 半封閉形式 |

## 校準：將 GARCH 擬合至資料

SDE 由我們**選擇**參數（漂移、波動率）；相較之下，GARCH 通常透過最大概似估計**擬合**歷史資料。
