# 第五章：傳統模擬方法

**Docker 映像檔**：`ml4t`

**目的**：實作並比較用於產生合成金融資料的傳統蒙地卡羅方法，為後續透過學習建立的生成模型奠定基礎。

本 Notebook 說明運用既有蒙地卡羅方法產生合成金融資料的**運作機制**。我們涵蓋其數學原理與實務實作，再示範正式環境可用的函式庫捷徑。

## 為何要模擬？

歷史市場資料只提供無限可能空間中的**一條路徑**。模擬可為下列用途產生其他情境：

1. **風險管理**：VaR、壓力測試、尾端風險評估
2. **回測**：驗證策略在歷史經驗之外的表現
3. **資料增強**：擴大用於訓練機器學習模型的資料集
4. **隱私**：分享合成資料，同時避免暴露專有訊號
