## IID 自助抽樣

最簡單的重抽樣方法：以**放回抽樣**方式抽取個別報酬率。

### 演算法

```
For each bootstrap sample of length T:
    For t = 1 to T:
        Draw index i uniformly from {1, ..., N}
        Set r*_t = r_i  (original return i)
    Return r* = (r*_1, ..., r*_T)
```

### 性質

- **保留邊際分布**：與原始資料有相同的直方圖
- **破壞自相關**：每次抽樣皆獨立
- **快速簡單**：無須調整參數
