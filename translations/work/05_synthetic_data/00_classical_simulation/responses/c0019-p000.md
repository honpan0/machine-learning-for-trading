## 均值回歸（Ornstein-Uhlenbeck）

價格趨向長期均衡水準 $\theta$：

$$d(\log S) = \kappa(\theta - \log S) \, dt + \sigma \, dW$$

其中：
- $\kappa$ = 均值回歸速度
- $\theta$ = 長期均值（對數價格水準）
- 半衰期：$t_{1/2} = \ln(2) / \kappa$

### 主要性質

- **平穩性**：價格在均衡水準附近波動
- **無趨勢**：無法捕捉多頭／空頭市場
- **負自相關**：今日的變動在明日部分反轉

### 離散化選項

**Euler-Maruyama**（近似）：
$$X_{t+\Delta t} = X_t + \kappa(\theta - X_t)\Delta t + \sigma\sqrt{\Delta t} Z$$

**精確轉移**（OU 的封閉解）：
$$X_{t+\Delta t} = \theta + (X_t - \theta)e^{-\kappa\Delta t}
  + \sigma\sqrt{\frac{1 - e^{-2\kappa\Delta t}}{2\kappa}} Z$$

我們實作兩者以比較離散化誤差。
