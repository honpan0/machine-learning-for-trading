# 第四部分：模型比較總結

## 各方法捕捉的性質

厚尾與波動率分群是不同性質，上方分別衡量：參數模型使用 `N_PATHS` 條路徑的超額峰度，重抽樣方法則使用 `N_BOOTSTRAP_REPLICATES` 次重複中保留的報酬率平方自相關。「超出歷史」問的是方法能否產生大於所有輸入值的數值。

| 方法 | 超過高斯分布的超額峰度 | 波動率分群 | 超出歷史 |
|--------|-------------------------------|-----------------------|----------------|
| GBM | 無，由建構方式決定 | 無；本列是解讀這兩欄的虛無基準 | 是 |
| 跳躍擴散 | 有，此處實測最厚 | 無；跳躍獨立到達 | 是 |
| 均值回歸 | 無 | 無；其相依性是報酬率的負自相關，而非報酬率平方的自相關 | 是 |
| Heston | 有，低於 GARCH | 有，多數路徑皆有，源於均值回歸的變異數 | 是 |
| GARCH | 有，高於 Heston | 有，每條路徑皆有，且實測最強 | 是 |
| IID 自助抽樣 | 承襲樣本的性質 | 完全未保留 | 否 |
| 區塊自助抽樣 | 承襲樣本的性質 | 保留約三分之二 | 否 |
| 平穩自助抽樣 | 承襲樣本的性質 | 保留約三分之二，略多於固定區塊 | 否 |
