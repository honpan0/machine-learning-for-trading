## 核心概念

1. **差分隱私**：提供隱私保證的數學框架
2. **DP-SGD**：逐樣本梯度裁剪加上雜訊（而非批次層級）
3. **隱私預算（ε）**：隱私與效用之間的取捨
4. **隱私會計器**：追蹤訓練期間累積的隱私成本

## 為何使用 Opacus？

正確實作 DP-SGD 需要：
- **逐樣本梯度**：標準 PyTorch 未提供
- **正確裁剪**：在彙總之前，而非之後
- **隱私會計**：透過動差會計器準確計算 ε

Opacus 會正確處理這些工作。手動實作容易出錯。
