## 重點

1. **隱私與效用確實存在取捨，但嚴格隱私設定的效應最突出**：更緊的預算會在梯度注入更多雜訊，使合成資料更粗糙。此次掃描中，最緊預算的成本大且明確，較寬鬆者則落在狹窄範圍內，沒有清楚排序。每個預算僅一次短期執行，無法辨識單調曲線，因此可辯護的解讀是：極緊預算代價高昂，而中等預算在此尚未區分；要區分它們，需要各自執行數次並取平均。
2. **透過 Opacus 計算逐樣本梯度至關重要**：標準 PyTorch 裁剪的是*批次*梯度，無法限制任何個別樣本的貢獻。Opacus 使用 `functorch` 計算逐樣本梯度，將各自獨立裁剪至 `max_grad_norm`，再加入經校準的雜訊。手動實作素來容易出錯；Opacus 透過其建構方式確保正確性。
3. **Epsilon 衡量累積資訊洩漏**：每個訓練步驟都消耗隱私預算的一部分。隱私會計器（Rényi DP）精確追蹤此過程。epsilon 用完後，若不削弱保證，就無法繼續訓練。因此 `make_private_with_epsilon` 會校準雜訊，將預算均勻分配至各訓練週期。
4. **架構約束很重要**：BatchNorm 跨批次計算統計量，洩漏其他樣本資訊，因此違反差分隱私。GroupNorm 與 LayerNorm 是符合差分隱私的替代方案。訓練前使用 `ModuleValidator` 檢查相容性。
