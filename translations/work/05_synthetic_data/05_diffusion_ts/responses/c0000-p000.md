# Diffusion-TS：具條件式生成能力的可解釋擴散模型

**第五章：合成資料生成**
**章節參照**：第 5.6 節（金融時間序列的擴散模型）

**Docker 映像檔**：`ml4t-gpu`

> **建議使用 GPU**：本 Notebook 使用 PyTorch/CUDA 訓練模型。也能以 CPU 執行，但訓練可能非常緩慢。若要使用 GPU 加速：
> ```bash
> docker compose run --rm ml4t-gpu python 05_synthetic_data/05_diffusion_ts.py

## 目的

本 Notebook 實作 **Diffusion-TS**（Yuan 與 Qiao，ICLR 2024），將去雜訊預測分解為**趨勢**（多項式迴歸）與**季節性**（傅立葉基底）成分的擴散模型。此可解釋結構鼓勵模型將緩慢漂移與週期模式分離，類似傳統 STL 分解，但在擴散框架中以端到端方式學習。

一般擴散模型預測雜訊 $\varepsilon$，Diffusion-TS 則直接預測 $x_0$。傅立葉域損失進一步對頻譜保真度施加正規化，這對保留金融報酬率的自相關結構至關重要。

## 學習目標

完成本 Notebook 後，你將能夠：
- 實作具有**可解釋趨勢與季節性分解**的擴散模型
- 使用結合**時域與傅立葉域**的損失進行訓練
- 使用 **DDIM** 快速抽樣，將生成所需的反向步驟從 500 降至 50
- 在加雜訊資料上建構**市場狀態分類器**，並套用**分類器引導**，產生以市場狀態為條件的合成報酬率
- 評估無條件與條件式生成品質
