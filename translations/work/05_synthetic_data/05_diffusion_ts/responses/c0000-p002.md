1. **不使用 clamp(-1, 1)**：原始程式碼針對類影像資料，將預測的 $x_0$ 箝制於 [-1, 1]。金融報酬率經 StandardScaler 正規化後仍無界，因此我們完全移除箝制。
2. **預測 $x_0$**（而非雜訊）：模型輸出 $\hat{x}_0 = \text{trend} +
   \text{season}$，再以解析方式推導雜訊。這與分解自然契合。
3. **保留傅立葉損失**：頻域正規化項使頻譜性質匹配，這對報酬率的自相關保真度至關重要。
4. **分類器引導**：在加雜訊序列上訓練獨立的 Transformer 分類器，使抽樣時能進行以市場狀態為條件的生成。
