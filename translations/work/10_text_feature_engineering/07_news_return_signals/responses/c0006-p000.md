## 新聞語料

FNSPID 將橫跨二十多年的金融新聞文章，與各篇提及的股票代號和刊登日期配對。預設下載的是樣本，而非完整資料集；其規模足以示範此處的建構過程，也能在合理時間內計算嵌入向量。

```bash
python data/text/fnspid_download.py              # the default sample
python data/text/fnspid_download.py --sample 0   # the complete dataset
```

參考資料：[HuggingFace 上的 FNSPID](https://huggingface.co/datasets/Zihan1004/FNSPID)
