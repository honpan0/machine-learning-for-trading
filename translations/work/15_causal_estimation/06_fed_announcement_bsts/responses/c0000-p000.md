# 使用 BSTS 研究聯準會公告事件

**第 15 章：因果機器學習**
**Docker 映像檔**：`ml4t-py312`
**章節參照**：BSTS 理論與事件研究方法見第 15.5 節

> **需要 `ml4t-py312` 映像檔。** `tfcausalimpact`（TensorFlow Probability 的 BSTS 套件）不支援主要 `ml4t` 映像檔所使用的 Python 版本，因此本 Notebook 改在 `py312` 映像檔中執行：
>
> ```bash
> docker compose --profile py312 run --rm py312 \
>     /opt/bsts/bin/python 15_causal_estimation/06_fed_announcement_bsts.py
> ```

## 目的
本 Notebook 實作**貝氏結構式時間序列（BSTS）**事件研究，以衡量聯邦準備理事會公告對債券 ETF 的因果影響。我們示範反事實建構、控制序列選擇與安慰劑檢定驗證，涵蓋完整的事件研究流程。

## 學習目標
完成本 Notebook 後，你將能夠：
- LO1：使用 BSTS 模型建立由資料驅動的反事實
- LO2：選擇適當的控制序列，避免外溢效應污染
- LO3：衡量累積效應並解讀後驗可信區間
- LO4：使用安慰劑檢定驗證事件研究結果
