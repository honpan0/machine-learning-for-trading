## 10. 兩種結果的差異所在

兩項分析使用相同的估計器、調整變數集合與樣本。差別在於處置與結果之間還隔著多少市場因素，而診斷結果反映的正是這點。

### 未來報酬率
```
market_sentiment -> { premium, returns }   (backdoor path, unmeasured)
          premium -> returns               (causal path, indirect)
```
投機需求、槓桿與風險偏好，同時影響資金費溢價與後續報酬率，形成調整變數集合必須阻斷的後門路徑。`return_24h` 與 `volatility_24h` 只能代理其中一部分，無法涵蓋其餘因素，因此該路徑仍部分開放。負向控制在處置前報酬率上發現的殘餘關聯，就是直接證據。

### 溢價回歸
```
premium -> funding pressure -> arbitrage -> premium reversion   (causal path, direct)
```
溢價高時，資金費使永續合約多頭的持有成本提高，產生賣出永續合約、買入現貨的誘因，進而壓縮溢價。這條路徑夠短，使相同的未測量情緒較少機會在處置之外獨立影響結果；但也短到部分關係可能是機械性的，因為處置與結果都來自同一溢價序列。
