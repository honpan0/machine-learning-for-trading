## 5. 選擇指南

第 15.1 節以表格整理選擇方式，此處重現該表。首先要問因果圖是否已知，因為這決定問題屬於效應估計或結構發現。

| 因果圖已知？ | 處置類型 | 方法 | 函式庫 |
|---|---|---|---|
| 是 | 二元或連續 | 後門調整 | DoWhy |
| 是 | 連續 | DML | EconML |
| 是 | 特定時點的二元介入 | BSTS | tfp-causalimpact |
| 是 | 二元或離散，增益效果 | 元學習器 | CausalML |
| 否 | 不適用 | PCMCI | Tigramite |
| 否 | 不適用 | VAR-LiNGAM | causal-learn |
| 否 | 不適用 | NOTEARS | 在 `08_neural_causal_discovery` 中實作 |

上半部的解讀：DoWhy 與 EconML 都需要能識別效應的調整變數集合，差別在於提供方式。DoWhy 接受因果圖並據此推導調整變數集合；EconML 直接接受控制變數，再以機器學習模型擬合。兩者都無法迴避識別假設。因此，「沒有因果圖」是應先進行結構發現的理由，而非偏好其中一種估計器的理由。

下半部的區分是同期結構與落後期結構，而非橫斷面資料與時間序列資料。PCMCI 和 VAR-LiNGAM 都會讀取跨期相依性，且 `08_neural_causal_discovery` 將兩者應用於同一投資範圍；NOTEARS 則針對單一橫斷面內的結構。
