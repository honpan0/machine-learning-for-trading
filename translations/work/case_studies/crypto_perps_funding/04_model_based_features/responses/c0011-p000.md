保留測試切分不在其資料上擬合，只讓先前擬合的模型在全部保留測試資料上向前推進，遵循與驗證切分相同、而非較寬鬆的準則。此處兩種模型都屬非監督式，只讀取價格與資金費率，從不讀取標籤，因此估計視窗在保留測試期間前結束的擬合，可在其中向前推進，不會看到不應看到的資訊；保留測試切分的估計視窗，在保留測試開始前三次結算就結束。

本 Notebook 過去在開發期間的切分後就停止，並明確說明這一點。現在可以看出代價：產出檔沒有任何保留測試日期的模型特徵，所以保留測試重訓時，可能合併切分 0 的特徵，其擬合視窗早在數年前結束；也可能完全找不到特徵。兩種失敗都不會報錯。

圖中呈現估計邊界的依據；經過此次改寫後，依據是時程，而非切分。頂端長條是資金費率歷史資料：先是一段不產生數值的暖身期，接著是依既定頻率重新估計參數的期間，最後是保留測試期間，其間固定使用進入保留測試前最後一次估計的參數。下方長條是供參考的切分視窗：它們仍決定建模 Notebook 用哪些資料列訓練與驗證，但不再決定各列的特徵值。切分編號按時間倒序，因為 `generate_cv_splits` 從最近的開發資料向外編號，所以切分 1 的驗證年度早於切分 0。
