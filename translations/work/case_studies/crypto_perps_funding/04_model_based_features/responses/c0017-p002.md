$$h_t = \omega + \alpha \varepsilon_{t-1}^2 + \gamma \varepsilon_{t-1}^2
  \mathbb{1}[\varepsilon_{t-1} < 0] + \beta h_{t-1}$$

其中 $\varepsilon_t$ 是報酬率，$\alpha$ 表示一般衝擊傳遞多少影響，$\gamma$ 表示向下衝擊額外傳遞多少影響，$\beta$ 則表示昨天的變異數有多少延續到今天。創新項採用 Student-t 分布而非常態分布，因為加密貨幣的八小時報酬率，極端觀測值遠多於常態分布所容許；若以常態分布擬合，模型會用提高每根 K 線的 $\omega$ 來補償。
