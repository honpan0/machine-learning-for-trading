# 加密貨幣永續合約：由模型輸出形成的特徵

到目前為止，本個案研究建立的所有特徵，都是對過去 K 線進行算術計算。資金費率的歷史滾動 z 分數、溢價百分位數、已實現波動率，每一項都能用一欄數值手算公式求得。本 Notebook 建立另一類特徵：它在每個交叉驗證切分的歷史資料內**擬合統計模型**，再輸出擬合後的模型對較晚 K 線的判斷。

選用兩種模型，因為它們能回答單純算術計算無法回答的問題：

- 針對每份永續合約的 **GJR-GARCH(1,1)** 波動率模型。它估計報酬率衝擊如何影響隔日變異數，並另行估計向下衝擊會額外造成多少影響；歷史滾動標準差會把這種不對稱性平均掉。其輸出是每根 K 線的下一期條件波動率。
- 在整體市場的已實現資金費用結算橫斷面上擬合的**雙狀態高斯隱藏馬可夫模型**。它估計兩種資金費率市場狀態及兩者間轉換的機率，並在每次結算輸出市場處於壓力狀態的機率。

**資金費用**是本 Notebook 的核心：永續合約永不到期，交易所每八小時讓合約的一方向另一方支付小額費用，以使合約價格接近現貨價格。該次支付依據的費率就是已結算資金費率，市場狀態模型讀取的是這些費率的橫斷面。

**讀取資料**：`features/financial.parquet`，即 [`03_financial_features`](03_financial_features.ipynb) 建立的特徵矩陣，市場狀態模型依其中的資金費率欄位擬合；`labels/fwd_ret_8h.parquet`，由 [`02_labels`](02_labels.ipynb) 產生，僅供最後的評估使用；以及原始八小時永續合約 K 線。
