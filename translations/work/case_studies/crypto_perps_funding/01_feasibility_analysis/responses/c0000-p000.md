# 加密貨幣永續合約資金費率：可行性分析

在建立交易策略之前，值得先問資料是否足以支撐這項策略。
本 Notebook 只做這件事：不擬合模型，也不進行預測。

這裡檢查的策略記載於 `config/setup.yaml`。它在幣安交易永續合約，每八小時依目前持有各合約多頭的成本排序，買進排序的一端，同時賣出另一端。該檔案規定交易哪些合約、何時可以調整部位、假設每筆交易的成本，以及如何將歷史資料劃分為策略設計與測試期間。本 Notebook 逐一用資料檢查這些假設，並報告結果。

## 學習目標

完成本 Notebook 後，你將能夠：

- 在策略允許交易的時點，計算各個標的起始日期不同的面板資料中有多少合約，並將此數量與策略想持有的部位數比較
- 從一張圖讀出有多少比例的價格變動幅度大於為掌握該變動所支付的手續費
- 衡量各合約的一項數值能持續描述同一合約多久：在每份合約內計算相關性，而非把不同合約串成一條序列後計算
- 將這種持續性換算成樣本中的獨立觀測值數量；它會小於資料列數
- 檢查歷史資料的滾動向前切分是否符合可用樣本，並讓測試期間保持未經檢視
