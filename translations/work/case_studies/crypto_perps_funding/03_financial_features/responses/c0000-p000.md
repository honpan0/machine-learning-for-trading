# 加密貨幣永續合約資金費率：特徵工程

永續合約沒有到期日，因此將其價格與現貨價格連結起來的，只有持有人之間的款項移轉。這筆款項依資金費率計算，費率的正負號決定誰向誰支付：費率為正時，多頭持有人向空頭持有人付款；為負時，支付方向相反。正負號主要取決於合約交易價格與現貨價格的差距，但並非只取決於此：交易所會加入小幅利息項，所以合約價格即使略低於現貨，多頭仍可能須付款。資金費用通常每八小時結算一次，但交易所可以縮短個別合約的結算間隔；第 B 節會計算此處發生過多少次。

交易所計算資金費率所依據的是**溢價指數**，亦即交易所公布、衡量合約價格相對於所追蹤現貨價格差距的指標。有兩種數值都使用這個名稱，而本 Notebook 只使用其中一種：資金費率公式取結算前一段期間的溢價指數時間加權平均，再加入利息項並套用上限；下列特徵則讀取 `premium_index_close`，亦即每根八小時 K 線收盤時的指數值。所有用於比較合約排名的特徵，都是此序列與已結算資金費率的轉換；另有少數特徵描述排序形成時的環境，來源各不相同：合約自身價格提供波動率，時間戳記指出資料列屬於每日三次結算中的哪一次，設定檔則決定其手續費等級。每個特徵首先必須回答的問題不是能否預測，而是能否在當時得知：在一次結算時，哪些觀測值已經公布，特徵如何利用它們？
