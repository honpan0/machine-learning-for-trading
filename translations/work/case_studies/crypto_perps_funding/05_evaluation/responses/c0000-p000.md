# 特徵評估：加密貨幣永續合約資金費率

永續合約沒有到期日，因此它不會在到期結算時收斂至現貨價格，而是透過多空部位之間定期支付的現金款項，也就是**資金費用**，使價格趨向現貨。幣安每八小時結算一次。前兩份 Notebook 建立的特徵，描述這筆付款有多高、合約交易價格離現貨指數有多遠，以及兩者過去有多大波動。本 Notebook 在以特徵訓練模型前，先問最基本的問題：單獨看每項特徵，它是否能透露合約接下來八小時的報酬率？

方法是單變量篩查。每項特徵單獨評分，再因搜尋了許多特徵而修正分數，結果形成逐特徵紀錄。此處刻意不執行特徵選擇：不會從建模 Notebook 的訓練資料中移除任何欄位。

**讀取** `features/financial.parquet`（Notebook 03）、`features/model_based.parquet`（Notebook 04）與 `labels/fwd_ret_8h.parquet`（Notebook 02）。
**寫入** `evaluation/triage_ledger.parquet`，每項特徵一列，包含證據及判定；另寫入 `evaluation/ic_timeseries.parquet`，即登錄表所彙總的評分序列。
