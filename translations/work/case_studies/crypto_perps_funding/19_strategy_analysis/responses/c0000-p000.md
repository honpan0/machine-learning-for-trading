# 加密貨幣永續合約：這場搜尋實際找到了什麼

四份 Notebook 逐步縮小候選範圍。[`13_backtest`](13_backtest.ipynb) 以等權重執行每一組預測，[`14_portfolio_management`](14_portfolio_management.ipynb) 以六種方式決定留存者的部位規模，[`15_risk_management`](15_risk_management.ipynb) 嘗試十四種提前平倉方式，而 [`16_costs`](16_costs.ipynb) 詢問最終留存者能承受多少摩擦成本。本 Notebook 做出本案例研究所要做的唯一一次選擇，再說明這項選擇能支持多高的信心。

**後半部分才是關鍵。** 在同一段驗證期間對數百次回測排名的篩選流程，總會產生一個最高數值。該數值能否作為證據，取決於它是從多少候選者中脫穎而出、自身的信賴區間有多寬，以及修正被選中所造成的偏差後還剩多少。若只回報選定資料列，卻不呈現這三項資訊，正是本 Notebook 旨在避免的錯誤。

**學習目標。** 完成本 Notebook 後，你將能夠：

- 跨標籤選擇一項配置，並說明為何標籤屬於配置的一部分，而非另一個獨立的選擇軸。
- 將夏普比率解讀為區間而非單點，並說明該區間涵蓋什麼。
- 套用選擇偏誤修正，並說明原始數值已為負時，修正後的數值代表什麼。
- 區分永續期貨策略從價格變動與資金費各自取得的收益。
