# 加密貨幣永續合約：兩個驗證年度中的 400 個候選模型

[`06_linear`](06_linear.ipynb) 檢視懲罰項對一組特徵的影響；這組特徵是以多種方式衡量同一經濟量，即永續合約價格相對於現貨的溢價。L1 路徑縮減到只剩一欄，排名也不再變動。梯度提升模型以不同限制處理相同特徵集：樹不對欄位賦予權重，而是依欄位分割；面對近乎重複的欄位區塊，它可以接連根據不同的溢價測量進行分割。這樣即使未增加任何資訊，也能非常細緻地描述訓練視窗。

有三個調整項決定模型能走多遠，本 Notebook 三者都會變動：

- **容量**，由 `num_leaves` 設定：單棵樹可將特徵空間劃分成多少區域。
- **損失函數**，決定「預測錯誤」如何衡量。平方誤差依誤差平方對觀測值加權，絕對誤差與 Huber 損失則不如此。加密貨幣八小時報酬率的尾部夠厚，使此選擇確實重要，而非形式上的差別。
- **停止時點**，由樹的數量設定。提升模型在每次迭代都有可評分的狀態，因此本 Notebook 在每種設定自身訓練過程中的十個檢查點評分。
