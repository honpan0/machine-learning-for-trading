# 已擬合模型能告訴我們哪些資金費率資訊，又有哪些不能

Notebook 06 至 11 各自擬合了一個模型家族，並發布其驗證集預測。本篇將這些結果放在一起檢視，探討它們說明了什麼，以及同樣重要的：它們無法支持哪些結論。

**這裡出現三項指標，但沒有任何一項用來選擇策略。**

**資訊係數**是每次結算時，預測值與其後報酬之間的等級相關係數，再對各次結算取平均。它問的是模型是否正確排列永續合約。它不反映差距有多大：若一個模型完美排序，卻只把最高與最低者區分出一個基點，得分會與區分出一個百分點的模型相同。

**AUC**用於兩類方向標籤，而非報酬。它表示隨機選出的兩次結算中，模型評分較高者後續上漲，而評分較低者未上漲的機率。0.5 相當於擲硬幣。它衡量的也是排序，因此不反映機率校準情形；即使模型給出的機率全都接近 0.5，只要順序正確，仍能取得高分。

**對數損失**則把機率當成機率來評估。它對自信卻預測錯誤的懲罰遠重於猶豫不決，因此模型可能因排序改善而提高 AUC，卻因過度自信而使對數損失惡化。
