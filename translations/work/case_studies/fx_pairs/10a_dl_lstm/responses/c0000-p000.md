# LSTM——外匯貨幣對

LSTM 會將隱藏狀態沿回看視窗向前傳遞，並在每次觀測時更新，因此它能從歷史資料運用的資訊，不像 NLinear 扣除最後水準那樣事先固定，也不像 TCN 的膨脹卷積堆疊那樣受限於感受野。它是本案例研究 `deep_learning` 選單所宣告三種架構中的循環式成員。本 Notebook 只建立 LSTM 請求；與 NLinear、TCN、TabM、樹模型及線性模型的比較，留待 `12_model_analysis` 進行，屆時完整登記的模型集合即可使用。

**學習目標**

- 在擬合前解析 LSTM 的回看長度、隱藏層大小、深度與檢查點時程表。
- 使用共用、可安全處理缺口的序列適用資格判定，而非依資料列位置建立視窗。
- 證明每個已宣告的訓練週期都能重新載入權重，並交接至目錄。
