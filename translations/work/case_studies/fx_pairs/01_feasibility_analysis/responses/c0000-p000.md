# 外匯貨幣對：可行性分析

在建立交易策略之前，值得先問資料是否足以支援這項策略。
本 Notebook 只做這件事：不擬合模型，也不做預測。

待檢驗的策略記載於 `config/setup.yaml`。它交易二十個貨幣對，每天排序一次，買入排名靠前的貨幣對，賣出排名靠後的貨幣對。該檔案列出交易的貨幣對、每天做決策的時點、假設的交易成本，以及如何將歷史資料分成策略設計與測試兩部分。本 Notebook 會用資料檢查每項假設，並報告結果。

## 學習目標

完成本 Notebook 後，你將能夠：

- 將從不休市的價格資料劃分為交易日，並選出每天在截止時點做出決策後實際可能成交的那一根價格棒
- 計算策略每次調整部位的日期有多少工具提供報價，並將此數量與需要建立的部位數比較
- 當多項工具暴露於同一風險時，區分投資範圍內的工具數量與其中獨立押注的數量
- 從一張圖表讀出價格變動幅度超過交易成本的比例
- 衡量某一天的報酬有多少延續到隔天，並在各個工具內計算相關性，而不是把整個投資範圍堆疊成單一序列後計算
- 檢查歷史資料的逐步向前切分是否符合可用樣本，並讓測試期間保持未經檢視
