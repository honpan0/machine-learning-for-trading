# 外匯貨幣對：特徵工程

二十個貨幣對，每天在紐約時間下午 5 點收盤時做出一次決策。下方每個欄位都回答一個問題：在決定部位的當下，哪些價格棒已經出現，而特徵如何利用它們？

## 學習目標

- 在撰寫程式碼之前，先說明特徵向前回看多遠，以及其輸入資料發布需要多久
- 依決策日曆彙整日內價格棒，讓每日特徵止於做決策時的下午 5 點收盤，而不延伸到之後
- 證明即使不提供較晚日期的資料，既有的每個數值仍保持不變，以區分過去視窗統計量與全樣本擬合統計量
- 在任何模型讀取特徵集之前，先檢視其尺度、離散程度、重複資訊與衰退情況

## 書籍參考、先備知識與產出檔案

第 8 章，第 8.2–8.4 節，也是唯一的先備知識：本 Notebook 透過 `load_fx_pairs()` 讀取 OANDA 四小時現貨價格棒，並從 `config/setup.yaml` 讀取設定，不讀取其他 Notebook 寫出的檔案。它會寫入 `features/financial.parquet`，並在旁邊放置 `.digest.json` 附屬檔案。[`05_evaluation`](05_evaluation.ipynb) 會讀取該 Parquet 檔案，逐折檢驗各欄位是否有預測能力；[`12_model_analysis`](12_model_analysis.ipynb) 也會讀取它，以歸因擬合模型使用的資訊。從 [`06_linear`](06_linear.ipynb) 到 [`11_causal_dml`](11_causal_dml.ipynb) 的六份建模 Notebook，則透過共用載入器 `utils.modeling.load_modeling_dataset` 取得它；該載入器將它與標籤，以及 [`04_model_based_features`](04_model_based_features.ipynb) 從相同價格建構、具有折別資訊的特徵合併。
