# 模型分析——外匯貨幣對

本 Notebook 讀取完整登記的驗證預測模型集合。它比較模型系列、檢查點、驗證折穩定性、預測一致性與不確定性，但不選擇部署模型。每個確切的模型配置都會進入等權重回測；之後才依驗證期回測夏普比率進行選擇。

**學習目標**

- 依標籤、模型系列、配置與檢查點，稽核完整的預測模型集合。
- 比較預測診斷指標，但不將其作為選擇準則。
- 根據標準預測產出資料，評估穩定性與依時間順序計算的共形預測覆蓋率。
- 將因果估計與預測模型系列的證據分開。
