# 交易成本敏感度——外匯貨幣對

本 Notebook 從等權重、配置與風險覆蓋模型集合中，為每種標籤選出一個驗證期策略，之後只改變其百分比交易成本。敏感度網格不參與後續模型或策略選擇。

成本放在最後掃描，因為成本曲線只有針對實際將交易的策略才有參考價值，而在衡量風險控制前，該策略尚未確定。若在風險覆蓋規則之前掃描成本，就會以後續可能捨棄的配置來計算成本網格。

這是擾動分析，不是選擇。它問的是：若成本模型有誤，已確定的策略會發生什麼事；這與「該交易哪種策略」是不同問題。兩者必須分開，原因很直接：若允許策略以自身的成本假設參與競爭，勝出的會是假設成本消失的策略，而排序回報的會是最樂觀假設，而非最佳策略。

**為何在此使用基點。**外匯買賣價差以點（pips）報價，這是匯率本身的一個比例，因此摩擦成本實際上以比例費率表示——沒有可按每股或每份契約計費的單位。名目價格穩定，或價差直接從報價資料衡量的案例研究，則使用每股費用；若對匯率套用固定的每單位收費，便會假設價差隨匯率水準變動，但事實並非如此。設定的網格範圍是每個交易部位 0 至 50 個基點，對照主要貨幣對約 1 至 3 個基點、交叉貨幣對約 3 至 8 個基點的實際報價區間，因此網格大部分刻意設在合理範圍之外。
