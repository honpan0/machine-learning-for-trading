# 外匯貨幣對：由擬合模型建構的特徵

**第 9 章：時間序列分析**

第 8 章的特徵是對過去價格進行算術運算：移動平均、二十個交易時段的報酬率，或兩者的比率。本 Notebook 建構的是另一種類型。這裡每個特徵都是模型的輸出，而模型參數本身也是由價格歷史估計，因此參數所依據的視窗，也是特徵所知資訊的一部分。共擬合三種模型，每節一種：將現貨匯率拆分為緩慢變動的水準與周圍報價雜訊的狀態空間模型、辨識美元何時平靜與何時劇烈波動的雙狀態模型，以及一種短記憶報酬率模型，其預測誤差會成為意外程度的衡量指標。

**學習目標**：
- 擬合模型，將貨幣對價格拆成緩慢變動的水準與周圍雜訊。模型將水準視為隱藏狀態，將每筆觀測價格視為帶有雜訊的讀數，且只使用所描述交易時段之前的資料擬合。
- 使用僅能讀取截至當日交易時段資料的雙狀態模型，估計美元在每個交易時段處於劇烈波動狀態的機率。
- 保留一步向前報酬率預測未能捕捉的部分，將其轉換成特徵，使特徵衡量意外程度而非方向。
- 依宣告時程更新各模型參數，而不是每個交叉驗證折只更新一次，讓任何交易時段的特徵值都不會包含根據其未來資料估計的參數。
- 刪除序列尾端後重新執行相同遞迴計算，並檢查較早的數值是否不變，以證明特徵沒有前瞻資訊。
