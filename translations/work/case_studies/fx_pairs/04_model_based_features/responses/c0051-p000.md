期望最大化法會走向最接近起點的最佳值，因此從多個起點重複擬合，保留概似值最高的結果。如果某次執行的最後一步*降低*概似值，代表尚未收斂，應予丟棄，而非悄悄使用。

只固定起點，仍不足以使擬合結果可重現；這個差異很重要，因為特徵檔案是依數值摘要識別的。初始狀態的平均值來自對訓練樣本的 k-means 分組，而 k-means 會平行加總樣本。浮點數加法不具結合律，因此總和取決於工作如何分配到各處理器執行緒；期望最大化法會將這項差異傳遞到轉移矩陣，以及模型報告的每個機率。隨機種子固定的是選取哪些起點，不是算術運算如何排程。限制為單一執行緒，也就固定了排程；此處序列只是一欄每日數值，代價僅是數秒。對此 Notebook 的擬合執行三次測量：使用預設執行緒池時，每次得到的轉移矩陣都不同；限制為單一執行緒時，每次都相同。另外兩種模型也以相同方式檢查，已能在多次執行間重現。
