## 4. 價格水準在哪裡，以及移動速度有多快

第一種模型把讀者觀察到的價格，視為某個無法直接觀測的量的不完美讀數。有一個真實水準，以某種速度漂移，而報價印在其附近。因此，每個交易時段有兩種變動來源爭相提供解釋：真實水準確實移動了，或報價偏離一個未移動的水準。**局部線性趨勢**模型是分離兩者的標準方法；它是一種狀態空間模型，也就是以演化中的隱藏狀態及其帶雜訊觀測值表示的模型。

隱藏狀態有兩個成分：水準與斜率；觀測值是水準加上雜訊：

**狀態**：$\mathbf{x}_t = [\text{level}_t, \text{slope}_t]^\top$

**轉移**：$\mathbf{x}_t = \mathbf{F}\mathbf{x}_{t-1} + \mathbf{w}_t$

**觀測**：$y_t = [1, 0]\mathbf{x}_t + v_t$

如何拆分，完全由兩種雜訊項的相對大小決定：$R$ 描述報價偏離水準多遠；$Q$ 描述水準與斜率自身移動多遠。它們就是參數，會在每個訓練視窗以最大概似法估計，即找出使訓練價格最可能由模型產生的數值。擬合完成後參數保持固定，遞迴運算不重新估計，直接向前通過驗證資料。

模型讀取價格的對數，而非價格本身。日圓貨幣對交易價格接近 100，歐元貨幣對接近 1，因此固定的 $R$ 對兩者有不同意義；取對數後，兩者都處於報酬率的尺度，水準、斜率、預測誤差與不確定性便能在投資範圍內跨貨幣對比較。
