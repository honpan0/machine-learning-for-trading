# CME 期貨：保留樣本回測

**第 20 章——樣本外評估**

[`17_holdout_predictions`](17_holdout_predictions.ipynb) 使用保留樣本期間之前的歷史資料，重新擬合選定設定，並產生該期間的預測。本 Notebook 會依本案例研究其他部分採用的部位規模與成本假設交易這些預測，並登錄結果。

此處不做任何選擇。預測、配置方法、集中度、再平衡頻率與成本都已由先前的 Notebook 固定；本 Notebook 唯一決定的是原樣套用它們。這正是整體設計：保留樣本結果的價值，取決於看過結果後沒有再做任何決策；此處每個尚可調整的參數，都會變成一項決策。

此處會列印與驗證期的比較，但不加以解讀。兩年的每週決策大約有一百次觀察值，比每月資料多，但仍少到使估計夏普比率的區間相當寬。如何根據結果得出結論，是
[`19_strategy_analysis`](19_strategy_analysis.ipynb) 要討論的主題，並會使用區間來說明。

**先決條件：**[`17_holdout_predictions`](17_holdout_predictions.ipynb)。
