### 執行自訂設定

已發布的執行紀錄是唯讀的。若要新增執行結果，應以工作區開啟研究；工作區有自己的登錄表與產出檔案，但讀取相同標籤與特徵：

```python
study = open_study("cme_futures", workspace="~/ml4t-experiments")
configs = load_model_configs(
    study, "gbm", labels=["fwd_ret_5d"], config_names=["leaves_15_huber", "leaves_31_huber"]
)
requests = model_requests(study, configs)
resolved = tuple(request.resolve() for request in requests)
execution, population = run_model_population(study, resolved, population_name="my-gbm-v1")
```

`CONFIG_NAMES` 擬合選單已宣告設定的子集。若要擬合新設定，在 `case_studies/config/lgb/leaves_127_huber.yaml` 新增預設檔，並將 `leaves_127_huber` 列於該標籤選單的 `gbm:` 下。編輯既有預設檔會改變設定身分，因此結果會登錄為舊列旁的新列，而非取代舊列。[`RUN_LOG.md`](../RUN_LOG.md#running-your-own-configurations) 說明其他步驟。
