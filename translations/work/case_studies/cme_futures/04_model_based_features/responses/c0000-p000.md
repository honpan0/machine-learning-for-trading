# CME 期貨：本身就是模型輸出的特徵

到目前為止，每個特徵都是對過去價格套用的公式。本 Notebook 建立第二種特徵：先由過去價格估計統計模型，再將模型對每個交易時段的判斷輸出為特徵。三種模型都從同一數值出發，也就是期貨商品的**持有收益（carry）**：最先到期的合約與下一個到期合約之間的價差；交易者每次將部位從前者展期至後者時，便會取得或支付這項差額。

1. **ARIMA** 根據持有收益近期的變化路徑，預測下一個交易時段的持有收益；每種商品、每個時段各有一個預測值。
2. **滾動傅立葉轉換**衡量過去一年中，商品持有收益主要按哪些週期長度波動。
3. **雙狀態隱藏馬可夫模型**每個時段讀取一個數值，即整個商品組合的平均持有收益，並推斷商品組合處於兩種市場狀態中的哪一種。

它讀取 CME 原始結算價及 [`02_labels`](02_labels.ipynb) 寫出的未來報酬率標籤，並寫出一份產出檔案：`features/model_based.parquet`。
