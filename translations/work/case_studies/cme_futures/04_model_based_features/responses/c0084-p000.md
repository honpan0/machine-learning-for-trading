### 檔案及其旁邊寫入的指紋

寫入檔案時也會建立小型附屬檔案，記錄四件事：特徵數值的**內容指紋**、資料列數、組成鍵值的欄位，以及用來建立特徵的價格資料指紋。

指紋讓紀錄具有實際用途，而非裝飾。若登錄表只記錄模型訓練時使用了哪些特徵*名稱*，當兩次訓練的名稱相同、數值不同時，就無法區分；計算特徵的程式碼改變後，正會出現這種情況。即使資料列數與欄名相同，只要兩次執行的數值不同，就會得到不同指紋，使下游訓練可記錄讀取了哪個特徵版本。

上游指紋根據原始結算價計算，因為 C 節會由它們重新計算持有收益。本 Notebook 不從其他案例研究檔案讀取特徵值，紀錄會明確反映這點。

另行記錄的是估計時程，這是讀者理解輸出數值含義所需的資訊。若改放各折幾何結構，只能回答「期間 3 是哪個視窗」，但此檔案並不提出這個問題。
