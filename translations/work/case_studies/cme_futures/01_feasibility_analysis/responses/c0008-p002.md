**原始保證金**及其帶來的槓桿。持有合約不需要支付整筆合約價值，只須向結算所存入保證金；隨價格變動，每天都會結算增減。保證金僅占合約價值的幾個百分點，兩者的比值就是部位承受的槓桿：下方的 2 年期美國公債期貨，控制約 $206,000 的公債，所需保證金約為 $1,300。這個比率並非部位風險積極程度的衡量指標。交易所根據合約價格變動幅度設定保證金，因此變動最小的合約反而具有最高槓桿；若以每日風險衡量，158 倍槓桿的 2 年期公債，與 8 倍槓桿的白銀，比這兩個比率所暗示的更接近。對本策略而言，這表示需要提供的資本是保證金的倍數，而非所排序合約價值的倍數。

此處使用的保證金率來自 CME 公布的費率表，並記載於本案例研究 README 的「Margin Model」一節，其中也說明了採用近似值的地方：四種股票指數合約共用一個費率，四種能源合約也共用另一個費率，因此這些列顯示相同的槓桿。這些數值足以呈現持有部位所需成本的數量級，但並非券商的報價。
