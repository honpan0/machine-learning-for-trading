# CME 期貨：可行性分析

在建立交易策略之前，值得先確認資料究竟能否支撐這項策略。本 Notebook 只做這件事：不擬合模型，也不進行預測。

要檢查的策略描述於 `config/setup.yaml`。它交易芝加哥商品交易所（CME）的期貨合約，每週排序一次，買進排名最高的合約，並賣出排名最低的合約。該檔案列明交易哪些商品、多久調整一次部位、假設的交易成本，以及如何將歷史資料劃分為模型擬合與測試期間。本 Notebook 逐項對照資料檢查這些假設，並報告結果。

## 學習目標

完成本 Notebook 後，你將能夠：

- 計算策略每個再平衡日有多少合約提供報價，並將此數量與多空兩側各自需要建立的部位數比較
- 使用交易所公布的各合約最小價格跳動單位，而非從價格推估的數值，估計跨越買賣價差的成本
- 從單一圖表讀出價格變動幅度大於交易成本的比例
- 衡量訊號維持資訊價值的時間，據以判斷每週再平衡是否足以及時利用訊號
- 確認歷史資料的滾動向前切分符合可用樣本範圍，並讓測試期間保持未經檢視
