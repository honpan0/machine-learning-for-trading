# CME 期貨：特徵工程

期貨追蹤資料提供股票追蹤資料所沒有的資訊：同一商品在數個不同交割日期的價格，並列報價。這組價格稱為**期限結構**；最近的合約，也就是**近月合約**，與其後一份合約之間的價差，則是**持有收益（carry）**。在決定部位的當下就能知道持有收益，無須從過去報酬率推估。本 Notebook 建立此特徵，以及用來對照它的動能、波動率與日曆特徵類別，列明各自使用的視窗與延遲，並證明它們都不會讀取日期等於或晚於決策時點的結算價。

## 學習目標

- 由同一天報價的兩份與三份合約建立持有收益及曲線形狀，並理解為何價差需要交易所實際結算價格，而同一 Notebook 中的所有報酬率都需要經展期調整的價格
- 在撰寫計算程式碼前，先列明每類特徵讀取過去多少交易時段，以及等待輸入資料公布多久
- 在同一決策日期**及**同一合約序位內替商品排名，使近月合約的持有收益絕不與較遠月合約比較
- 保留較晚交易時段不使用，重新建立整個特徵矩陣，並確認每個數值一致，以此區分尾隨統計量與使用完整樣本擬合的統計量
