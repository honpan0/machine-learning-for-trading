# 特徵評估：CME 期貨

本 Notebook 對上游兩份 Notebook 建立的每個候選特徵，只進行一次篩選，對照案例研究試圖預測的未來報酬率。對每項特徵依序提出三個問題：作出決策的當下，其數值是否可信？它對下週報酬率的排序，是否優於隨機機會？這種排序能力是否在滾動向前測試的每一年都存在，還是只來自某一段表現良好的期間？

答案形成每項特徵一筆紀錄。本 Notebook 不選擇特徵：不擬合模型，不決定訓練 Notebook 使用的特徵集，也不判斷依這些特徵建立的策略能否賺錢。第 7 章明確指出，逐項篩選特徵是必要但不充分的條件。

**讀取內容**：`features/financial.parquet`（由 `03_financial_features` 建立）、`features/model_based.parquet`（由 `04_model_based_features` 建立）、`labels/` 下的未來報酬率標籤（由 `02_labels` 建立），以及 `config/setup.yaml`，用於取得標籤名稱、滾動向前切分結構及留出期間起始日期。

**寫出內容**：`evaluation/triage_ledger.parquet`，每項特徵各占一列，包含決策與依據；以及 `evaluation/ic_timeseries.parquet`，即此處圖表所依據的逐日期相關性時間序列。
