# ETF：特徵工程

此處每個模型都透過這個矩陣觀察世界，因此現在能計算什麼，就限制了日後能學到什麼。每項特徵都回答一個問題：在決定部位的當下，哪些觀測值已經可見？特徵又如何運用它們？

## 學習目標

- 在撰寫計算特徵的程式碼之前，先說明特徵的時間約定：回溯期間與資訊延遲
- 計算只讀取決策時間戳之前觀測值的歷史與橫斷面統計量，並對決策當下尚不可得的輸入宣告延遲
- 證明排除較晚日期後，每個特徵值都維持不變；這是歷史統計量與使用整個樣本擬合的統計量之間的區別
- 在任何模型讀取特徵集之前，檢視其尺度、離散程度、重複性及衰減情形
