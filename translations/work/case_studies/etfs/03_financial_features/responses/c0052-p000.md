## G. 輸出

矩陣寫入 parquet 檔，旁邊另有一個小型 JSON 檔記錄所寫內容。其目的在於讓後續階段無須重讀整個檔案，就能判斷目前讀取的矩陣是否為先前測試的版本：檔案記錄數值的摘要值、資料列數、鍵值欄位，以及本 Notebook 所讀取每項輸入的摘要值。

摘要值是由內容計算出的簡短字串，因此內容數值相同的兩個檔案會得到相同字串，任何數值變更則會得到不同字串。依數值而非檔案位元組計算，正是它在此處可用的原因：若以不同資料列順序或壓縮方式重新寫出 parquet，摘要值不變；只要修正一個特徵值，摘要值就會改變。把輸入資料的摘要值一併記錄，便形成可追溯的鏈：下游階段不只能看出矩陣變了，也能看出是否因輸入改變而變。
