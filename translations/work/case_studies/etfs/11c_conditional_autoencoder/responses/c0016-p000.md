第二次執行本 Notebook 時不會訓練任何模型。所有識別資訊都從輸入重新推導；登錄系統已有相符資料列及儲存的權重，因此執行器會回傳儲存的結果，而非重新訓練。所以在內容不變時重跑，只需讀取資料的時間。與線性及提升式模型家族不同，潛在因子執行器不會分別報告各折是新擬合還是重用，因此上述計數代表模型群持有的內容，而非本次執行實際計算的內容。

### 執行自己的設定

已發布的執行記錄為唯讀。若要新增執行，請在工作區中開啟此研究；工作區有自己的登錄系統與成品，並讀取相同的標籤及特徵：

```python
study = open_study("etfs", workspace="~/ml4t-experiments")
configs = load_model_configs(study, "latent_factors", labels=["fwd_ret_5d"], config_names=["cae"])
requests = model_requests(study, configs, overrides={"device": "cuda"})

```

若要變更架構或時程，請編輯 `case_studies/config/cae/cae.yaml`。這會改變此設定的識別資訊，因此結果會作為新資料列登錄在舊資料列旁，而非取代舊資料列；這也包括決定模型群成員數的 `n_epochs` 與 `checkpoint_interval`。請為這次執行指定自己的 `population_name`：一個名稱會永久對應一組成員，用於不同集合就會拋出錯誤。[`RUN_LOG.md`](../RUN_LOG.md#running-your-own-configurations) 說明其餘事項。
