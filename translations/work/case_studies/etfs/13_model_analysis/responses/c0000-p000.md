# ETF 模型比較：哪些訊號是真實的

已有七份 Notebook 針對此面板擬合模型，涵蓋五個家族及兩種標籤預測期間。每份都依各自宣告的選單報告結果。**但都無法說明自己與其他模型相比如何**，因為當時沒有其他模型的結果可供對照。

這正是本 Notebook 的用途。它讀取此個案研究登錄的所有預測集，在同一尺度上呈現各家族及其不確定性，並提出三個問題：訊號有多強、在滾動向前的各折間是否一致、各家族找到的是相同還是不同的訊號。

**這是跨資產面板，會改變此處「訊號」的意義。** 資產範圍混合產業股票基金、國家基金、債券基金、商品基金及貨幣基金，因此模型需要排序的不是哪家公司定價錯誤，而是目前哪種總體經濟曝險得到報酬。這些工具本身已分散投資，所以此面板的橫斷面資訊係數，相較個股橫斷面的標準較小：可供模型發現的特有變異較少。

**本 Notebook 不選擇任何模型。** 選擇依據是最佳驗證回測夏普比率，會在 [`14_backtest`](14_backtest.ipynb) 對本 Notebook 描述的模型群進行。此處每個數字都來自個案研究進行至此時已反覆檢視的驗證折；保留樣本只會在 [`20_strategy_analysis`](20_strategy_analysis.ipynb) 開啟一次。
