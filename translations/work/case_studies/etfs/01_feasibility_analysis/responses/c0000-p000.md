# ETF：可行性分析

在建立交易策略之前，值得先問資料是否足以支撐這項策略。
本 Notebook 只做這件事：不擬合模型，也不進行預測。

受檢驗的策略詳述於 `config/setup.yaml`。它交易交易所交易基金（ETF），每月為基金排序一次，並持有排名最高的基金。該檔案說明策略交易哪些基金、哪些基金的流動性足以納入持有範圍、多久調整一次部位、假設的交易成本，以及如何將歷史資料劃分為模型擬合期與測試期。本 Notebook 依據資料檢查每項假設，並報告結果。

## 學習目標

讀完本 Notebook，你將能夠：

- 僅根據某日期之前已存在的資訊，判定策略在該日可以持有哪些基金，並計算每個調整部位日剩下多少檔基金
- 將以每股美分報價的佣金換算成可比較不同價格基金的成本
- 從一張圖讀出價格變動幅度大於交易成本的比例
- 衡量某個月的報酬率延續到下個月的程度；在每檔基金內計算相關性，而非將一百檔基金堆疊成單一序列後計算
- 檢查歷史資料的滾動向前切分是否符合可用樣本，並讓測試期維持未經檢視
