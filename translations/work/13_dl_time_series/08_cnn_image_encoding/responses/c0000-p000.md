# 將視窗轉成圖片：GAF 與 MTF 編碼

**Docker 映像檔**：`ml4t-gpu`

本節目前為止的每種架構，都將視窗保留為序列，並探討如何建立位置之間的關係：注意力機制、擴張卷積、混合或循環狀態。本 Notebook 採取不同方法：將每段視窗轉為雙通道影像，交給一般影像 CNN 處理，讓為圖片建立的整套機制可以原樣套用。

重點在編碼方式。**格拉姆角場**（GAF）將視窗重新縮放至 $[-1, 1]$，把每個數值視為角度，並在儲存格 $(i, j)$ 填入兩個角度的函數。因此，影像是一張列出每對位置關係的表格；對它執行卷積，讀取的是位置配對之間的關係，而非數值之間的關係。**馬可夫轉移場**（MTF）將視窗按分位數分箱，並在儲存格 $(i, j)$ 填入序列從這兩個位置所屬分箱之間移動的頻率。

轉換丟失了什麼，與建立了什麼同樣重要；下方兩種編碼都丟失相同資訊：它們在每段視窗內正規化，因此在 CNN 看見資料之前，報酬率的水準與範圍就已消失。兩段形狀相同但波動率不同的視窗，會變成同一張圖片。
