## 比較表

每一列都以相同資料（SPY 收盤價）為起點，表格收錄實際成功執行的方法。嘗試的六種程式庫示範中，能在此環境完成的有原始 PyTorch、sktime 的 PatchTST 與 Chronos，以及 Darts；sktime 的 NeuralForecast 封裝器因 Python 3.14 上的 `ray` 而受阻，PyTorch Forecasting 封裝器則遇到上游 API 不相容。最近值基準模型完全不需要程式庫。

**可跨列比較 `Lines` 與 `Fit + Predict (s)`，不可跨列比較 `mse`。** `Target Scale` 與 `Evaluation Points` 欄說明原因：原始 PyTorch 與基準模型擬合的是*正規化後*的目標，並在數百個滾動視窗上評分；sktime 與 Darts 則處理原始價格水準，並根據單次 `HORIZON` 步預測評分。光是尺度差距就能讓數值相差數個數量級；即使尺度一致，五個評估點也不足以支持比較。

唯一*可直接比較*的一對是基準模型與原始 PyTorch：尺度與測試樣本都相同。這是本 Notebook 唯一能支持的準確度比較，值得在閱讀表格其他部分前先看。
