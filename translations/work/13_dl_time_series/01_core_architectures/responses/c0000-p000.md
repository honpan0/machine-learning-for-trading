# 時間序列的核心深度學習架構

**Docker 映像檔**：`ml4t-gpu`

四種神經網路讀取相同的輸入，也就是某檔指數股票型基金最近六十天的每日報酬率，並各自預測該基金次日的報酬率。它們的差別只在於處理這段視窗的方式。全連接網路將視窗攤平成一個長向量。一維卷積沿著視窗滑動小型濾波器。LSTM 和 GRU 則逐日讀取，並將持續更新的摘要往後傳遞。本 Notebook 衡量的正是後一種做法：逐步走過視窗所需的運算量會隨視窗長度增加；這是否換來更高準確度，是本章其餘部分要探討的問題。

**學習目標**：
- 在 PyTorch 中，以相同輸入建立全連接網路、一維卷積網路、LSTM 和 GRU，讓架構成為它們之間唯一的差異。
- 對照訓練損失曲線與同一網路在未參與訓練的日期所產生的誤差，以免將下降的訓練曲線誤認為預測變好。
- 以毫秒為單位測量各網路單次訓練步驟的時間，並與各自達到的誤差並列比較。
- 觀察輸入視窗加長時成本如何變化，理解逐步走過視窗的網路與一次讀取整個視窗的網路為何有不同的擴展特性。

**書籍參考**：第 13 章第 13.1 節（循環網路及其限制）。LSTM 的原始形式請參閱 Hochreiter 和 Schmidhuber（1997）。
