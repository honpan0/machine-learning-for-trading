# 使用 N-BEATS 進行可解釋的預測

**Docker 映像檔**：`ml4t-gpu`

`01_core_architectures` 以一項成本作結：逐步走過視窗的網路必須付出循序處理的成本，而在該份資料上，這項成本沒有換來任何收益。N-BEATS 是本章提出的第一種解法。它不會逐步走過視窗，而是透過堆疊的全連接區塊一次讀取整段視窗，並限制每個區塊可以表達的內容，使預測結果一開始就分成緩慢變化的趨勢與重複出現的週期，而非一個不透明的數值。

本 Notebook 從各個組件建立架構，以 SPY 收盤價擬合，接著進行兩項這種架構適合做的分析。首先，分別從已擬合的模型讀取趨勢與週期，這是限制區塊後得到的好處。其次，將預測與最簡單的規則，也就是沿用今天的價格，比較評分。靈活的架構必須先勝過這項比較，其結構才算帶來價值。

**學習目標**：
- 建立 N-BEATS 區塊：由全連接層堆疊而成，同時輸出兩個向量，一個重建輸入，一個預測未來；理解從輸入扣除前者，為何能讓多個區塊堆疊運作。
- 將區塊輸出限制為多項式或正弦波總和，並將預測解讀為可分別繪製的趨勢部分與週期部分。
- 在相同資料上擬合受限制與不受限制的版本，說明限制付出的代價與帶來的好處。
- 將兩者與沿用最後價格的規則比較評分，並衡量有趨勢的價格序列，會讓待預測日期超出其訓練範圍多遠。
