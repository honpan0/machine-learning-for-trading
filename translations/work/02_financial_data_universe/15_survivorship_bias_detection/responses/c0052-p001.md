1. **面板只記錄最後幾年的退出。** 如 §1 圖表所示，一個始於 1960 年代的面板，其所有退出都發生於 2014 年之後。企業在更早之前也曾退出，只是蒐集流程未記錄。這是缺乏證據，而非不存在的證據，也無法還原缺漏內容。
2. **調整後價格仍帶有未調整的公司行動。** 反向分割，以及破產後沿用交易代號的重整，會在單一交易時段呈現兩個數量級的跳升，根本不是報酬率，而 `split_ratio` 欄位對它們完全沒有紀錄。它們占資料列的比例，只是百分之一中的一小部分；§3 已列出並計數。
3. **這些資料列決定答案的正負號。** 未修正時，僅含存活者的投資組合看似*落後於*完整標的集合。修復後則高估，方向與文獻一致。存活者檢查不能先於公司行動檢查。
4. **最終報酬率模型是估計中影響最小的部分。** 將每個最終報酬率設為零，對實證情境偏誤的影響遠低於一個百分點。偏誤來自退出交易代號*已觀測到*的報酬率，而非它們之後支付的價值。假設風險（選擇哪個情境）比抽樣風險（蒙地卡羅區間）高出一個數量級。
5. **無偏誤不等於完整。** 面板在 2014 年後幾乎沒有新增上市標的，§10 衡量它涵蓋多少市場。資料集可以記錄每次下市，卻仍漏掉每次 IPO。
