## 5. 驗證彙總結果

每日資料框架中有兩個值得衡量的項目，而它們分別能確認不同的事情。

每個交易時段的價格資料筆數確實具有資訊價值：它代表每筆每日價格資料由多少筆每小時價格資料彙總而成，而其分布可以顯示哪些交易時段較短，以及造成這種情況的原因。

OHLC 不變條件則不然。這裡的每個每日價格都是從某個每小時價格中選取，而不是由多個價格計算得出：開盤價是該交易時段第一筆資料的開盤價，收盤價是最後一筆資料的收盤價，最高價是所有每小時最高價中的最大值，最低價則是所有每小時最低價中的最小值。

因此，只要每筆每小時價格資料都符合「最低價 ≤ 開盤價、收盤價 ≤ 最高價」，每日價格資料也會繼承這個條件——交易時段內的最低值必定小於或等於第一筆價格資料本身的最低價，而該最低價又必定小於或等於其開盤價。

所以下方的檢查無法偵測錯誤的彙總作業。它能偵測的是原本就有問題的每小時價格資料，或後續修改時將選取價格的操作改成算術運算的情況。由於這個關係是精確的，而非近似的，因此任何違反條件的情況都代表發現了問題。
