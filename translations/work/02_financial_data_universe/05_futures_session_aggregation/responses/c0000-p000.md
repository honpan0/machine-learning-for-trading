# 期貨交易時段彙總：從小時資料到日資料

Docker 映像檔：`ml4t`

目的：將每小時的連續期貨價格資料（Databento，UTC）轉換為依交易時段劃分的每日價格資料，遵循 CME 美國中部時間下午 4:00 的交易時段分界，並套用比率反向調整，以消除轉倉造成的價格跳空。

學習目標：

- 了解為什麼 CME 交易時段日期與 UTC 日曆日期不同，以及週日晚間的價格資料如何計入週一的交易時段。
- 對連續價格序列套用比率（乘法）反向調整，使跨轉倉期間的百分比報酬率得以保留。
- 將所有 30 種商品及三種到期期別（近月、第一遠月、第二遠月）的每小時價格資料，依正確交易時段彙總為每日 OHLCV 資料。

書籍參考章節：§2.2「各資產類別的市場資料概況」中的期貨部分。`06_futures_continuous` 比較不同的調整方法。

先備條件：`data` 套件已加入 `PYTHONPATH`；每小時連續期貨資料的 parquet 檔案已存放於 `ML4T_DATA_PATH/futures/market/continuous/`。關於比率調整與 Panama 調整的教學說明，請參閱 `06_futures_continuous`。
