## 1. CME 交易時段分界

### 交易時段定義

CME Globex 交易時段遵循以下時間表：

- 交易時段開始：週日下午 5:00 CT（屬於週一交易時段）
- 交易時段結束：下午 4:00 CT（用來定義交易時段日期）
- 每日系統維護：下午 4:00–5:00 CT（休市 1 小時）

### 為什麼這很重要

如果我們依日曆日（UTC 午夜）進行彙總，就會將單一交易時段拆分到兩個不同日期，產生錯誤的每日價格資料：

| 方法           | 週日晚上 11 點 UTC | 週一下午 3 點 UTC |
| ------------ | ------------- | ------------ |
| 日曆日（錯誤）      | 週日            | 週一           |
| CME 交易時段（正確） | 週一            | 週一           |

這兩筆價格資料都屬於週一的交易時段，而該交易時段於週一下午 4 點 CT 結束。
