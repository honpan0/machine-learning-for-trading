# 資料管理：從下載到正式環境流程

**Docker 映像**：`ml4t`

**第 2 章：金融資料全貌**

前面的 Notebook 已擷取並驗證資料。本 Notebook 示範如何使用 ml4t-data 的正式環境功能，大規模**管理**資料：

- **DataManager**：擷取、儲存與更新的統一入口
- **Universe**：預先定義的代號清單（S&P 500、NASDAQ 100 等）
- **HiveStorage**：分割區 Parquet，支援快速查詢與增量寫入
- **增量更新**：維持資料新鮮度，無需重新下載歷史資料
- **CLI**：供指令碼工作流程使用的命令列介面

## 學習目標

完成本 Notebook 後，你將能夠：
1. 使用 `DataManager` 作為所有資料操作的單一入口
2. 使用 `Universe` 類別載入預先定義的標的池
3. 使用 Hive 分割區 Parquet 儲存與查詢資料
4. 執行增量更新並偵測缺漏
5. 使用 `ml4t-data` CLI 進行指令碼工作流程

## 重要性

教學只下載一次資料即可。交易系統則需要：
- **每日更新**，只擷取新資料（速度為完整重新整理的 10 倍）
- **分割區儲存**，支援快速日期範圍查詢
- **缺漏偵測**，確保回測前資料完整
- **中繼資料追蹤**，讓你掌握已有資料及更新時間

> **ml4t-data 文件**：完整參考資料請見[增量更新指南](https://ml4trading.io/docs/data/user-guide/incremental-updates/)
> 與[儲存指南](https://ml4trading.io/docs/data/user-guide/storage/)。
