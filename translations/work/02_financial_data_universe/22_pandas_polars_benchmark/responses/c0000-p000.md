# pandas 與 Polars：DataFrame 函式庫效能評測

**Docker 映像**：`ml4t`

**目的**：比較 pandas 與 Polars 在交易機器學習流程常見金融資料操作上的表現。本頁每個數值都取決於產生它的兩個函式庫版本，因此環境設定儲存格會印出兩者版本，以及該次執行環境是否啟用較新的 pandas 效能功能。此處不預先斷言版本為何：印出的值才是紀錄。

**學習目標**：
- 了解各函式庫在不同操作上的效能特性
- 依操作類型與資料規模，判斷何時使用 pandas 或 Polars
- 認識寫入時複製（Copy-on-Write）與以 PyArrow 為後端的字串會帶來哪些改變，並查看執行中的 pandas 是否已啟用這些功能
- 量測大型金融資料集的記憶體使用效率

**書籍參照**：第 2 章，第 2.4 節（儲存資料）——與檔案及資料庫效能評測並列的引擎選擇取捨。

**先備條件**：熟悉 pandas／Polars 基礎；已有的儲存效能評測。

## 主要測試類別

| 類別 | 操作 | 金融使用情境 |
|----------|-----------|-------------------|
| A：滾動計算 | SMA、EMA、滾動標準差、夏普比率 | 時間序列特徵 |
| B：分組彙總 | OHLCV 重新取樣、橫斷面統計 | K 棒建構 |
| C：視窗 | Z 分數、百分位排名、落後值 | 標準化特徵 |
| D：篩選 | 多條件述詞 | 選擇權鏈篩選 |
| E：連接 | ASOF（成交與報價）、反連接 | 逐筆資料配對 |
| F：延遲／串流 | Parquet 掃描、述詞下推 | 大型檔案處理 |
| G：記憶體 | 峰值用量、配置模式 | 資源限制 |
| H：字串 | 包含、擷取、取代 | 股票代號處理 |
