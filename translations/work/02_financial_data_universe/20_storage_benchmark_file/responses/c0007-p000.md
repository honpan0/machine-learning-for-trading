## 計時規則

下方每個數值都遵循同一套規則，四種格式一體適用。若比較時對不同對象混用規則，就失去比較意義，因此先在此明訂，而非留在各呼叫位置中：

- **寫入**（`time_write`）——單次執行，不先暖機。寫入追蹤資料是每個資料集只做一次的操作，因此量測的就是這次操作。
- **讀取**（`time_read`）——先進行一次不計時的暖機，再取 `TIMING_RUNS` 次執行的平均值。**這些是暖快取數據。** 檔案剛寫入，又被反覆讀取，因此已位於作業系統的頁面快取中。

暖快取讀取如實描述了研究迴圈實際具有的*重複存取*模式，但它會讓記憶體映射格式顯得格外有利：Feather 映射的是已駐留的頁面，因此下方的讀取數值接近最佳情況。首次從磁碟讀取未快取檔案時，與 Parquet 的差距會縮小；在網路或物件儲存上，壓縮格式通常會直接勝出，因為傳輸的位元組較少。此處排名適用於暖快取、本機、重複讀取；這也是 §2.4 對這些數據附加的適用限制。
