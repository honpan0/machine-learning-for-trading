# 增量更新：維持市場資料新鮮度

**Docker 映像**：`ml4t`

**目的**：逐步介紹更新生命週期——初始載入、每日增量、缺漏偵測及小型健康狀態儀表板——讓 `data/download_all.py --update` 中執行的同一套流程，能以端到端方式清楚呈現。

**學習目標**：
1. 比較完整重新整理與增量更新的成本。
2. 使用 `DataManager.update(..., fill_gaps=False)` 執行每日增量更新，並了解為何預設的 `fill_gaps=True` 對 OHLCV 資料並不安全。
3. 使用 `GapDetector(exclude_weekends=True)` 驗證完整性。
4. 繪製三面板健康狀態儀表板（資料量、新鮮度、問題）。

**書籍參照**：§2.4（儲存資料）——與第 20、21 份 Notebook 的儲存效能評測相對應的維運實務。

**先備條件**：已安裝 ml4t-data；可連線至網路以即時存取 Yahoo Finance。

**為何採用增量更新**：完整重新整理會重新擷取某個代號歷來的每一列資料，增量執行則只擷取上次執行後的交易時段。對具有十年歷史、數百個代號的標的池而言，前者每天需要數百萬列，後者每天只需數百列。第 1 節會在示範標的池上量測兩者的比率。
