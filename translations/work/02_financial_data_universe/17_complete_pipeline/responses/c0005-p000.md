## 1. 流程架構

正式環境流程分為三個階段：

| 階段 | 輸入 | 輸出 |
|-------|--------|---------|
| **擷取** | Yahoo Finance、WikiPrices、Binance | 各來源的原始 OHLCV |
| **處理** | 原始 OHLCV | 已驗證、標準化並加上標記的資料框 |
| **儲存** | 已加上標記的資料框 | 以代號／日期為鍵的分割區 Parquet |

以下四項設計原則貫穿本 Notebook 的其餘內容：

1. **供應商獨立性**——協調器不應需要知道每列來自哪個來源。
2. **在邊界驗證**——每個進入／離開點都檢查 OHLC 不變條件、缺漏門檻及重複時間戳記。
3. **來源標記**——每列都帶有 `source` 欄位，讓下游除錯保持容易處理。
4. **增量更新**——重新執行時只擷取新資料（第 §5 節的 `DataManager` API 會自動處理，使用者無需介入）。
