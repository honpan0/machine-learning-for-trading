## 第 8 節：使用 FREDProvider 取得經濟資料

為了偵測總體經濟狀態及管理風險，FRED（聯準會經濟資料）提供超過 800,000 個經濟時間序列。交易相關的主要序列包括：

| 序列 | 說明 | 頻率 |
|--------|-------------|-----------|
| VIXCLS | VIX 波動率指數 | 每日 |
| DGS10 | 10 年期美國公債殖利率 | 每日 |
| T10Y2Y | 殖利率曲線斜率 | 每日 |
| UNRATE | 失業率 | 每月 |
| ICSA | 初次申請失業救濟金人數 | 每週 |

**取得免費 API 金鑰**：https://fred.stlouisfed.org/docs/api/api_key.html
