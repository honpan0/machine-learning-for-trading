# 資料供應商比較：多來源資料擷取

**Docker 映像**：`ml4t`

## 目的
示範 `ml4t.data.providers` 在 YahooFinance、WikiPrices 與 FRED 之間統一的 `fetch_ohlcv()` 介面，接著建立備援策略與價格層級的供應商比較報告。本 Notebook 建立後續 ETF 案例研究所使用的 ETF 輪動標的池。

## 學習目標
- 以同一個呼叫簽章，從多個供應商擷取 OHLCV。
- 建立依優先順序嘗試的備援擷取器，提升正式環境的韌性。
- 量化供應商之間的差異（資料列數、價格差異統計），讓多來源資料拼接可供稽核。
- 使用 FRED（可識別資料版本）取得總體經濟序列，作為風險調整層。

## 書籍參照
第 2 章，§2.3（多來源資料拼接）。此處實體化的 ETF 標的池會供 `case_studies/etfs/` 流程使用。

## 先備條件
- 可連線至網路，以即時呼叫 YahooFinance 與 FRED（本 Notebook 示範供應商資料擷取；這些是出版驗證流程中唯一刻意進行即時 API 呼叫的地方）。
- 歷史資料部分需有位於 `ML4T_DATA_PATH/equities/market/us_equities/us_equities.parquet` 的 WikiPrices parquet。
- 第 §8 節需設定 `FRED_API_KEY`（可免費註冊）。
