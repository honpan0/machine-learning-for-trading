# 時點一致性（PIT）資料驗證

**Docker 映像檔**：`ml4t`

## 目的
以真實 ETF 與總體經濟資料，示範避免回測出現前瞻偏誤所需的實務檢查。本 Notebook 貫穿三條主線：特徵時間與決策時間的對齊、以相關性抓出明顯特徵洩漏的啟發式方法，以及透過 FRED 供應器檢視總體資料的雙時間（歷史版本）觀點。

## 學習目標
- 區分*事件時間*（事情何時發生）與*知悉時間*（我們何時得知），以及總體資料發布的雙時間軸。
- 說明為何置中移動平均會洩漏未來資訊，以及為何水準值與報酬率的相關性啟發式方法會漏掉它。
- 建立修正後、不受尺度影響的啟發式方法（特徵報酬率對未來報酬率），使其確實能標記 `close.pct_change(-1)` 特徵。
- 透過測量確定總體面板資料時間戳記的意義，以及當它們是期間標記時，向前填補會付出什麼代價。
- 使用 `vintage_date` 查詢 FRED，觀察 GDP 初步估計值與修訂值的差異。

## 先備條件
- 已在 `ML4T_DATA_PATH` 下建立 ETF parquet 檔案。
- 已在 `ML4T_DATA_PATH` 下建立總體經濟 parquet（FRED 快照），或可透過 `data.load_macro` 載入。
- 即時歷史版本查詢需要 `FRED_API_KEY` 環境變數；該查詢安排在最後一節，因此之前所有內容都能在沒有金鑰時執行（免費金鑰可於 https://fred.stlouisfed.org/docs/api/api_key.html 取得）。
