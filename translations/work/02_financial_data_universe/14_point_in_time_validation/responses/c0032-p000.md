兩個由未來資料建立的特徵都被標記，兩個落後平均則沒有，符合本節要產生的區分。必須清楚說明這能確立與不能確立的事。驗證器是對狀態已事先知曉的特徵執行，因此測試的是驗證器，而非特徵。若對未經任何人稽核的特徵矩陣執行，它會抓到與下一期報酬率呈現相關性的洩漏，卻抓不到不呈現這種相關性的洩漏：若特徵使用的是*被評估價格以外*某事物的未來值，就會原封不動通過此檢查。

## 8. 透過 FRED `vintage_date` 取得雙時間 GDP

總體資料會修訂。FRED API 的 `realtime_start` / `realtime_end` 參數會傳回**截至**所選歷史日期**當時已知**的數值。`FREDProvider.fetch_ohlcv` 透過 `vintage_date` 提供此功能。

下方儲存格需要 `FRED_API_KEY`（免費註冊）；若缺少金鑰，擷取會明確報錯，而非改用合成範例。
