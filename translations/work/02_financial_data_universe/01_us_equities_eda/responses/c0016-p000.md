## 4. 退出紀錄實際顯示了什麼

從 1962 年開始，股票代碼持續加入資料集，但退出情形並非如此：這份追蹤資料沒有記錄任何股票代碼在 2014 年以前退出。

顯然，2014 年以前確實有公司退出市場——有些被收購，有些破產，也有些轉為私人公司。安隆（Enron）於 2002 年下市。因此，圖表顯示的並不是股票市場的事實，而是這份檔案本身的事實：直到大約 2014 年以前，退出資訊都沒有被蒐集，而從那時左右才開始記錄。

這就是使用免費、由社群維護資料所必須付出的代價。這份追蹤資料是根據專案運作時仍然存在的股票代碼建立，再將各股票的歷史資料回填至其各自的 IPO 時點。當時已經消失的股票代碼從未被加入，因此它們的消失也從未被記錄。自 2014 年起，追蹤資料開始即時蒐集，因此股票代碼退出資料集的情況\*確實會\*被記錄。隨後，隨著貢獻者逐漸離開，加入與退出的數量都開始減少，直到資料來源於 2018 年 3 月停止更新。

這對回測意味著：

- 2014 年以前，這份追蹤資料只包含存活至 2014 年的公司。使用這份資料進行 1990 年代的回測，將完全看不到任何一家倒閉的公司，因為資料中根本沒有這些公司。
- 從 2014 年開始，這份追蹤資料確實會記錄股票退出，因此能夠支援考量存活者偏誤的研究。
- 2014 年以前沒有退出紀錄，代表的是缺乏證據，而不是有證據證明沒有任何股票退出。我們不知道哪些股票曾經退出。這份追蹤資料無法告訴我們。
