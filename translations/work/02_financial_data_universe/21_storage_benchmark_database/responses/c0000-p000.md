# 儲存效能評測：資料庫引擎

**Docker 映像**：`benchmark`

> **需要 Docker**：本 Notebook 仰賴 `benchmark` 環境及資料庫服務。執行方式如下：
> ```bash
> docker compose --profile benchmark up -d timescaledb clickhouse questdb influxdb
> docker compose --profile benchmark run --rm benchmark python 02_financial_data_universe/21_storage_benchmark_database.py
> ```

**重點**：適用於金融時間序列、具備查詢能力的資料庫

## 資料庫類別

| 類別 | 範例 | 特性 |
|----------|----------|-----------------|
| **嵌入式** | SQLite、DuckDB、ArcticDB | 在行程內執行，無需伺服器 |
| **時間序列伺服器** | ClickHouse、QuestDB、TimescaleDB | 正式環境規模，需要 Docker |
| **通用型** | PostgreSQL、InfluxDB | 作為比較基準 |
| **高頻交易專用** | kdb+/PyKX | 交易業界標準 |

## 效能評測操作

1. **寫入**——大量插入效能
2. **讀取**——全表掃描
3. **範圍查詢**——7 天時間視窗（回測工作流程）
4. **OHLCV 彙總**——將分鐘 K 棒重新取樣為日 K 棒
5. **ASOF 連接**——成交與報價對齊（對市場微觀結構至關重要）
