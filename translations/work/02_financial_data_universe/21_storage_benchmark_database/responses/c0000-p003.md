`db-benchmark` 額外依賴群組也包含 ArcticDB，而它既未發布 Linux ARM64 wheel，也未發布原始碼發行套件。在 ARM64 上，安裝會在 Notebook 執行前失敗，因此選用匯入的防護機制根本沒有機會略過它：請使用上方的 Docker 方式，其 `benchmark` 映像包含伺服器用戶端，但不含 ArcticDB。

規模由下方的 `BENCHMARK_SCALE` 參數決定，而非環境變數：參數儲存格之後的儲存格，會將參數寫回環境，供 `utils.storage_benchmarks` 讀取，因此命令列上的 `BENCHMARK_SCALE=...` 前綴，在任何程式讀取之前就會被覆寫。請編輯參數以變更規模，或像 CI 一樣透過 Papermill 注入參數。

不論哪些引擎有回應，接近底部的涵蓋情況報告，都會列出哪些引擎產生了本頁數據，哪些沒有。
