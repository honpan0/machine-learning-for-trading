# 建構連續期貨合約

Docker 映像檔：`ml4t`

目的：逐步說明如何從個別到期的期貨合約建構連續期貨價格序列：偵測轉倉、比較調整方法（原始價格、Panama／加法式向後調整、比率／乘法式向後調整），並與資料供應商建構的連續序列進行驗證。

學習目標：

- 利用成交量判定近月合約，偵測轉倉日期（並加入禁止回滾的限制，以避免不必要的切換）。
- 應用 Panama（加法式）向後調整，在轉倉時保留以美元計價的損益（P&L）。
- 應用比率（乘法式）向後調整，在轉倉時保留百分比報酬率。
- 將自行建構的連續價格與 Databento 預先建構的連續序列交叉比對，並量化兩者之間的差異。

書籍參考章節：§2.2〈各資產類別的市場資料概況〉中的期貨部分。此處對不同方法的比較，是該章節在工程設計上決定同時儲存原始合約歷史資料及一種或多種連續序列版本的基礎。

先備條件：`PYTHONPATH` 上的 `data` 套件；位於 `ML4T_DATA_PATH/futures/market/individual/ES/data.parquet` 的個別 ES 合約 Parquet 檔案，以及位於 `ML4T_DATA_PATH/futures/market/contract_definitions.parquet` 的合約定義 Parquet 檔案。
