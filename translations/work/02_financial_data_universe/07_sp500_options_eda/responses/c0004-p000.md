## 1. 機器學習實務工作者的選擇權入門

在深入研究資料之前，先建立幾個關鍵概念，了解選擇權資料與現貨市場資料有何不同，以及兩者如何互補。

### 什麼是選擇權？

選擇權是一種衍生性金融契約，賦予持有人在指定日期（到期日）之前，以指定價格（履約價）買入或賣出標的資產的權利（但沒有義務）。

| 類型       | 權利     | 獲利情況         |
| -------- | ------ | ------------ |
| 買權（Call） | 以履約價買入 | 標的價格上漲至履約價之上 |
| 賣權（Put）  | 以履約價賣出 | 標的價格下跌至履約價之下 |

### 為什麼選擇權資料對機器學習很重要

選擇權價格包含現貨價格所沒有的前瞻性資訊：

1. 隱含波動率（Implied Volatility, IV） — 市場對未來波動率的預期
2. 隱含波動率偏斜（IV Skew） — 市場對下跌風險保護與上漲風險保護的相對需求
3. 期限結構（Term Structure） — 市場預期如何隨不同時間跨度而變化
4. 希臘字母（Greeks） — 用來量化風險曝險的敏感度指標

這些資訊可以用來預測：

- 未來已實現波動率
- 標的資產的價格變動（透過委託單流量／部位配置）
- 尾端風險事件（透過波動率偏斜）

### 價內外程度：價內、價平與價外

價內外程度（Moneyness）描述選擇權履約價與目前現貨價格之間的關係：

| 價內外程度   | 買權（履約價相對於現貨價格） | 賣權（履約價相對於現貨價格） | 特性      |
| ------- | -------------- | -------------- | ------- |
| ITM（價內） | 履約價 < 現貨價格     | 履約價 > 現貨價格     | 具有內含價值  |
| ATM（價平） | 履約價 ≈ 現貨價格     | 履約價 ≈ 現貨價格     | 時間價值最高  |
| OTM（價外） | 履約價 > 現貨價格     | 履約價 < 現貨價格     | 僅具有時間價值 |
