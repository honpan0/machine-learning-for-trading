## 2. 資料集概覽

### 資料結構

| 欄位                 | 型別      | 說明                          |
| ------------------ | ------- | --------------------------- |
| 識別欄位               |         |                             |
| `timestamp`        | Date    | 交易日期（觀測日期、日終快照）             |
| `symbol`           | String  | 標的股票代號（例如 "AAPL"、"MSFT"）    |
| `expiration`       | Date    | 選擇權到期日                      |
| `strike`           | Float64 | 以美元計價的履約價                   |
| `call_put`         | String  | "C" 代表買權，"P" 代表賣權           |
| 價格                 |         |                             |
| `bid`              | Float64 | 收盤時的最佳買價                    |
| `ask`              | Float64 | 收盤時的最佳賣價                    |
| `mid_price`        | Float64 | 買賣價中間價：(bid + ask) / 2      |
| `underlying_price` | Float64 | 標的股票收盤價                     |
| 時間                 |         |                             |
| `days_to_maturity` | Int32   | 距離到期日的日曆天數                  |
| 希臘字母               |         |                             |
| `delta`            | Float64 | ∂V/∂S — 價格對標的資產價格的敏感度       |
| `gamma`            | Float64 | ∂²V/∂S² — Delta 對標的資產價格的敏感度 |
| `theta`            | Float64 | ∂V/∂t — 時間價值耗損（美元／天，通常為負值）  |
| `vega`             | Float64 | ∂V/∂σ — 對波動率的敏感度            |
| `rho`              | Float64 | ∂V/∂r — 對利率的敏感度             |
| 波動率                |         |                             |
| `implied_vol`      | Float64 | Black-Scholes 隱含波動率         |
| `iv_convergence`   | String  | 隱含波動率求解器狀態（品質指標）            |

### 隱含波動率收斂代碼

`iv_convergence` 記錄資料供應商的求解器如何取得每筆隱含波動率，也是決定哪些資料列可供使用的欄位。這個代碼由兩個部分組成：求解器接收到的輸入情況（`Converged` 代表一般報價、`SmallBid` 代表接近零的買價、`IntrVal` 代表價格等於內含價值、`Failed` 代表完全無法求解），以及當直接求解失敗時，改用何種方式產生數值（`FlatExtrapol`、`LinInterp`，或透過買賣權平價關係取得的 `PutCallPair`）。
