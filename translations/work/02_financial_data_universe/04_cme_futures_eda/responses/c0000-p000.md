# CME 期貨 — 探索性資料分析

Docker 映像檔：`ml4t`

目的：分析包含 30 種商品的 CME 期貨資料集（Databento，2011–2025 年，每小時資料）的特性，並呈現後續 Notebook 所依賴的契約與連續序列結構。

學習目標：

- 理解期貨資料的階層結構：商品 → 契約 → 連續序列。
- 透過 `load_cme_futures` 載入個別契約與連續（轉倉後串接）序列，並檢查標準的 `timestamp` / `product` 資料結構。
- 彙整各商品的資料涵蓋範圍，並依資產類別將商品分組。
- 在具代表性的連續序列上驗證 OHLC 不變條件。

書籍參考章節：§2.2〈資產類別市場資料概況〉中的期貨部分。

先備條件：`PYTHONPATH` 中須包含 `data` 套件；CME parquet 檔案須位於 `ML4T_DATA_PATH/futures/`。若缺少資料，請執行 `python data/futures/market/download.py`（需要 Databento API 金鑰）。
