# 公司行動：針對股票分割與股利進行調整

Docker 映像檔：`ml4t`

目的：示範未調整的價格時間序列為何會錯誤呈現股票分割與現金股利期間的報酬率，推導業界標準的向後調整方法，並以預先調整的 Quandl WIKI 時間序列為基準，驗證 `ml4t.data.adjustments.apply_corporate_actions` 的實作。

學習目標：

- 辨識股票分割與股利如何破壞原始價格的連續性。
- 套用股票分割與股利的向後調整公式。
- 使用 `apply_corporate_actions` 產生經調整的 OHLCV 資料面板。
- 以可信賴的參考時間序列驗證調整後價格。
- 依據特定策略的投資期間選擇正確的價格表示方式。

書籍參考章節：§2.3「資料來源的盡職調查架構」，以及 §2.2「各資產類別的市場資料概況」。

先備條件：磁碟上已有 Wiki Prices 美國股票的 parquet 資料（`load_us_equities` 會透過 `ML4T_DATA_PATH` 找到該資料）；已安裝 `ml4t-data` 函式庫。
