## 8. 對機器學習交易的實務影響

| 使用情境        | 價格類型      | 原因                   |
| ----------- | --------- | -------------------- |
| 特徵工程        | 總報酬調整後價格  | 報酬率必須具有經濟意義          |
| 長期回測        | 總報酬調整後價格  | 涵蓋股利現金流與股票分割造成的不連續變化 |
| 訂單執行模擬      | 原始價格      | 與交易所實際價格一致           |
| 日內交易（< 1 天） | 股票分割調整後價格 | 在高頻交易下，股利影響可忽略       |
| 因子研究        | 總報酬調整後價格  | 學術文獻中的標準做法           |
