## 第 5 節：資金費率估計

資金費率正是溢價指數的*用途*：市場的一方每八小時支付給另一方，而費率由指數計算而得。Binance 的公式為

$$F = P + \operatorname{clamp}\!\left(I - P,\ -c,\ +c\right)$$

其中 $P$ 為溢價指數、$I$ 為利率，$c$ 為夾限半寬。這兩個常數都是 Binance 公布的合約條款，並在參數儲存格中宣告為 `INTEREST_RATE` 與 `FUNDING_CLAMP`，因此下方運算與讀者看到的是相同數值。

**夾限作用於差值，而非溢價本身**，這會使結果產生性質上的改變，而非些微差異。當 $|I - P|$ 位於夾限範圍內時，夾限不會改變它，運算式便化簡為 $F = P + (I - P) = I$；不論溢價原本位於何處，資金費率都*恰好*等於利率。只有在此區間之外，溢價才會影響資金費率。

因此資金費率也有自己的死區，與第 1 節的溢價指數模式相同：在某段輸入範圍內，公式輸出固定為常數。改將夾限作用於 $P$，也就是 $\operatorname{clamp}(P) + I$，是一種容易出現的誤讀；它會完全消除死區，使資金費率序列在實際費率平坦之處仍然變動。

**年化：** $\text{APY} = F \times 3 \times 365$，每天結算三次。
