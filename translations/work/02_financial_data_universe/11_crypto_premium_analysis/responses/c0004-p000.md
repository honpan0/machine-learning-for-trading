## 第 1 節：認識溢價指數

### 什麼是溢價指數？

**溢價指數**衡量永續合約成交價格偏離標的指數的程度。簡單說，可以先理解為永續合約與現貨的相對價差，但交易所的定義並非如此：

$$\text{Premium Index} = \frac{\max(0,\ \text{Impact Bid} - \text{Price Index}) - \max(0,\ \text{Price Index} - \text{Impact Ask})}{\text{Price Index}}$$

衝擊買價與衝擊賣價，是固定名目金額的委託分別在買賣兩側成交時的價格，因此分子衡量的是永續合約的*可成交*報價超出指數的程度。只要指數落在兩者之間，兩個項目都為零，這表示溢價指數存在一個寬度等於衝擊買賣價差的**死區**，在此區間內恰好為零。

這並非無關緊要的技術細節。它解釋了為何此欄位有很大比例恰好為零、為何流動性不足合約的零值比例遠高於 BTC，以及為何將這些零值當作遺漏資料會是錯誤——`10_crypto_perps_eda` 衡量了這三點。

### 主要性質

1. **正溢價**：衝擊買價高於指數——永續合約的可成交報價偏高
2. **負溢價**：衝擊賣價低於指數——可成交報價偏低
3. **恰好為零**：指數落在衝擊買賣價差之內
4. **資金費率**：由溢價指數推導，Binance 每 8 小時結算一次
