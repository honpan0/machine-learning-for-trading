### 夾限並未限制資金費率的範圍

很容易將夾限理解為費率上限：每次結算以利率為中心，上下各五個基點，因此 APY 上限大概是數十個百分點。這是從另一個方向誤讀同一個公式。在死區之外，夾限達到邊界值，運算式變為 $F = P \mp c$，其中夾限半寬為 $c$；不論溢價如何變動，它都會隨之變動。夾限限制的是資金費率*偏離*溢價的程度，而非資金費率本身的大小。

在檢驗之前，值得先寫下誤讀版本本身的界限，因為它們並不對稱：$\operatorname{clamp}(P) + I$ 的範圍從 $I - c$ 到 $I + c$，利率使此範圍偏離以零為中心的位置。若只用上界檢驗 $|F|$，就會漏掉所有低於下界的違反情況。

實際序列能釐清這點，而且答案並非僅有些微差異。
