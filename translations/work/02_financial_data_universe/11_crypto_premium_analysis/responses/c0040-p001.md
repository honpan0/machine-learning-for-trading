4. **同一標籤下的兩種不同計數。** APY 超過所選門檻的結算比例，與夾限達到邊界的比例，是不同的量；推論只有單向成立：超過門檻需要夾限達到邊界，但夾限經常在幾乎不影響 APY 的溢價水準就已達到邊界。兩者皆已列於上方，差距達數十個百分點。

5. **估計值是替代值，且已明確說明。** Binance 使用區間內溢價的時間加權平均計算資金費率；本 Notebook 只有八小時 K 棒，因此使用收盤值。它是此處可用替代值中最準確的，但仍非精確值。若有實際序列，應使用實際序列；個案研究就是如此。

6. **整個合約集合的溢價波動率相差超過一個數量級**，而這種離散程度是階段性出現，並非穩定持續：波動範圍最寬的合約，其標準差主要來自少數幾次價格失衡。為資金費率策略選擇合約，就是選擇承擔哪一種尾端風險；上方逐交易代號的表格，正是作出這項選擇的依據。
