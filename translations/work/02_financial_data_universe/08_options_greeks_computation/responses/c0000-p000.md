# 選擇權希臘字母：從理論到計算

Docker 映像檔：`ml4t`

## 目的

從基本原理推導 Black-Scholes 定價公式與希臘字母，透過求根法實作隱含波動率計算，並使用 AlgoSeek 選擇權資料集中供應商提供的數值驗證計算結果。

## 學習目標

- 實作 Black-Scholes 買權／賣權定價，並驗證買賣權平價關係。
- 使用 Brent 法以數值方法求解隱含波動率。
- 撰寫五種希臘字母（Delta、Gamma、Vega、Theta、Rho）的計算程式，並視覺化其在不同價內外程度與距到期時間下的變化。
- 量化自行計算與供應商計算的希臘字母之間的殘差，並解釋殘差來源。

## 書籍參考章節

§2.2〈各資產類別的市場資料概況〉中的衍生性金融商品部分。
