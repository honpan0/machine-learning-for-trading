\## 5. 使用 AlgoSeek 資料進行驗證\
\
將上述 Greeks（希臘字母風險指標）與資料供應商針對相同選擇權合約預先計算的數值進行比較。\
有兩項選擇會決定這項比較是否具有意義，而且這兩項都很容易因為設定錯誤，而讓結果看起來比實際更好。\
\
\*\*利率必須隨時間變動。\*\* Black-Scholes 模型需要使用無風險利率，而 2020 年並不適合只選用單一數值：一年期美國公債殖利率在這十二個月內下降超過一個百分點，下方的儲存格會印出其年初與年末的數值。如果使用樣本期間開始時選定的固定利率，在一月時大致正確，但在當年其餘時間，誤差就會反映出這段期間的大部分利率降幅。因此，這裡改為依照各個日期，從總體經濟資料面板（macro panel）讀取對應利率，並實際衡量使用固定利率所造成的影響，而不是直接假設其影響程度。\
\
該資料面板提供的最短到期期限為一年，而這些選擇權距離到期僅剩二十至九十天，因此這裡使用的是最接近且可取得的利率，而非到期期限完全匹配的利率。這確實是一項限制，因此在此明確指出，而不是將其掩蓋。\
\
\*\*樣本必須具有抽樣代表性。\*\* 經過篩選的 DataFrame 已依序排序，因此最前面的資料列全部來自最早的日期。如果直接讀取前幾列資料，就等於只使用少數幾個交易日的資料來驗證模型，卻將結果呈現得彷彿涵蓋了整個年度。下方的樣本採用隨機抽樣方式取得，而儲存格會印出每種抽樣方式實際涵蓋的交易日數量。\
