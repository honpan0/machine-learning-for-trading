## 7. 實務考量

### Black-Scholes 模型失效的情況

| 情境            | 問題           | 替代方法                 |
| ------------- | ------------ | -------------------- |
| 深度價外（OTM）選擇權  | 對數常態分布低估尾部風險 | 使用跳躍擴散模型或局部波動率模型     |
| 短天期平價（ATM）選擇權 | Gamma 急遽上升   | 使用已實現波動率，而非隱含波動率（IV） |
| 配息股票          | 遠期價格不正確      | 使用經股利調整的模型           |
| 美式選擇權         | 提前履約價值       | 使用二項樹模型或近似方法         |
| 波動率叢聚         | 固定波動率假設      | 使用 GARCH 或隨機波動率模型    |

### Greeks（選擇權希臘字母）在實務上的應用

避險方面：

- 透過交易標的股票進行 Delta 避險
- Gamma 可用來判斷需要多頻繁地重新平衡部位
- 波動率變動所帶來的 Vega 風險暴露往往占主導地位

交易方面：

- Greeks 有助於辨識相對價值
- 高 Gamma 加上低權利金 = 潛在的錯誤定價
- Theta/Vega 比率對波動率交易很有用

風險管理方面：

- 彙總投資組合的 Greeks
- 在極端情境下進行壓力測試
- Greeks 屬於局部近似估計，大幅度的價格變動需要進行完整的重新定價
