## 3. 希臘字母：衡量選擇權的敏感度

希臘字母用來衡量選擇權價格相對於各種輸入變數的變化。它們對以下用途至關重要：

- 避險：中和不希望承擔的風險暴露
- 風險管理：了解投資組合的敏感度
- 交易：辨識定價錯誤的選擇權

### 希臘字母總覽

| 希臘字母  | 符號         | 衡量項目    | 公式                |
| ----- | ---------- | ------- | ----------------- |
| Delta | $\Delta$   | ∂V/∂S   | 價格對標的資產價格的敏感度     |
| Gamma | $\Gamma$   | ∂²V/∂S² | Delta 對標的資產價格的敏感度 |
| Vega  | $\mathcal$ | ∂V/∂σ   | 價格對波動率的敏感度        |
| Theta | $\Theta$   | ∂V/∂t   | 價格對時間的敏感度（時間價值耗損） |
| Rho   | $\rho$     | ∂V/∂r   | 價格對利率的敏感度         |
