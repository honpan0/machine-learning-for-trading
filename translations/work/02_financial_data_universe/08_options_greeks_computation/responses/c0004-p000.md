## 1. Black-Scholes 架構

Black-Scholes 模型（1973 年）在特定假設下，提供歐式選擇權價格的封閉形式解。理解這些假設對實務工作者至關重要，因為模型的限制可以解釋許多現實世界中的定價現象。

### 模型假設

| 假設          | 現實情況         | 影響             |
| ----------- | ------------ | -------------- |
| 報酬率服從對數常態分布 | 存在厚尾現象       | 低估尾端風險         |
| 波動率固定       | 波動率會隨時間變化    | 需要重新估計 σ       |
| 無股利         | 股票會發放股利      | 使用經股利調整的模型     |
| 無交易成本       | 交易成本確實存在     | 希臘字母對小部位的實用性較低 |
| 連續交易        | 市場會休市        | 週末／隔夜的價格跳空     |
| 歐式履約        | 許多選擇權屬於美式選擇權 | 未考慮提前履約溢價      |
| 無風險利率固定     | 利率會變動        | 使用與期限相符的利率     |

儘管存在這些限制，Black-Scholes 仍然是業界用於波動率報價與計算希臘字母的標準模型。對大多數實務應用而言，模型在計算與分析上的便利性，勝過其理論上的不足。
