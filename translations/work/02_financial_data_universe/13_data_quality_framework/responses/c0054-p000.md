## 重點整理

1. **驗證器即使通過，在看過錯誤資料之前，也沒有告訴你任何事。** 此處每個交易代號都通過，關閉所有檢查的驗證器也會得到相同結果。每種類型注入一個錯誤，再確認觸發哪項檢查，才能區分兩者，而設定只需三行。

2. **三種方法共用一個門檻，代表三個不同的判定界限。** MAD、Z 分數與 IQR 各自將門檻乘上自己的尺度估計值，因此在以資料本身的單位列出界限之前，標記數量無法直接比較。上方已列出這些界限，標記數量的排序也對應界限的排序。

3. **MAD 標記更多，是因為它忽略尾部，而非看見尾部。** 它的尺度估計值是偏差的中位數，極端日期無法撼動它，因此在厚尾序列上遠低於標準差，以它建立的區間也相應較窄。直覺解釋常朝相反方向推論，將機制顛倒。

4. **PSI 的大部分可能來自一個並非占十分之一的分箱。** 分位數邊界無法切開點質量，而每日報酬率在零點就有一個，因此相鄰兩個分箱失衡，較大的偏差落在同值群組旁，而非尾部。只有閱讀各分箱貢獻才能看出這點，總體數值無法顯示。同值群組為何縮小是另一個問題，上方的逐年計數排除了直覺答案，卻未提供另一個答案。
