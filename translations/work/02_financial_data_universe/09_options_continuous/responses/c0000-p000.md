# 建構連續選擇權序列

Docker 映像檔：`ml4t`

## 目的

示範為何「固定到期期限」選擇權序列會將不同合約串接在一起、在每次轉倉時產生虛假的價格跳躍，並污染標籤的建構。實作兩種不受此問題影響的替代方法：同一合約持有期間報酬率（正確的標籤），以及將轉倉日報酬歸零後重建的連續序列（可用於回測的逐市計價）。

## 學習目標

- 偵測 30 天期平價跨式選擇權（ATM straddle）時間序列中的合約轉倉，並量化其相對於非轉倉日報酬率所造成的偏差。
- 透過在原始選擇權鏈中查找進場時所持合約的出場價格，計算同一合約的持有期間報酬率。
- 建立適合回測的連續價格序列，並衡量轉倉日報酬率的處理方式對該序列的影響。
- 區分標籤所需的建構方式與逐市計價序列所需的建構方式。
