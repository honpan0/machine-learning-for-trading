## 4. 建立用於回測的連續序列

為了進行回測，我們需要一個價格序列，其每日報酬率能反映實際損益（P&L），而且不會在轉倉時出現虛假的價格跳躍。期貨每季轉倉一次，適合使用巴拿馬調整法（Panama adjustment）；跨式選擇權則在大多數交易日都會重新選取合約，因此必須採用以報酬率為基礎的調整方式：

1. 在非轉倉日，每日報酬率就是所持有合約本身的價格變動所產生的報酬率。這一點沒有爭議。
2. 在轉倉日，一個看似直觀的答案是將報酬率設為零，理由是轉倉屬於交易行為，而不是報酬。
3. 根據你所選擇的報酬率重建價格：$P_{adj,t} = P_0 \prod (1 + r_i)$。

步驟 2 是錯誤的，而本節將衡量其錯誤程度。 在轉倉日，你確實持有一個部位：也就是從昨天收盤一直持有到今天的昨日合約。該合約的價格會隨市場變動，而這種變動所產生的損益是真實的。將報酬率歸零，不只是移除虛假的價格跳躍，也同時移除了當天真正產生的報酬。

轉倉日的正確報酬率，應該是\*原本持有\*合約的報酬率：使用昨天的履約價與到期日，分別取得該合約昨天和今天的價格。第 3 節已經建立了從原始選擇權鏈查找價格的方法，因此只需要執行查找，就能取得這項資料。

下方會計算這兩種方式，並呈現兩者的差異。轉倉成本，也就是切換合約時實際支付的買賣價差，則是另一回事，並會在第 18 章中以交易成本的形式建模。
