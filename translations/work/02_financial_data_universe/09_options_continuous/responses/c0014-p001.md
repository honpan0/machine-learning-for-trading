期貨市場中對應的概念是轉倉收益率（roll yield），兩者的差異起初只是程度上的不同，但當程度擴大後，就會形成性質上的差異。每季轉倉一次的期貨，每年只會產生四次小幅調整。然而，這個序列在大多數交易日都會重新選取合約，因此虛假報酬成分不再只是對原本合理的報酬率序列偶爾進行的修正，而是構成整個報酬率序列的一大部分。

關於正負號的說明，因為下文的一切都取決於此。 本 Notebook 中的每一項報酬率，都是該金融工具本身的報酬率：今日價格除以昨日價格，再減去一。正值代表跨式選擇權的價格上漲。

這是多頭報酬率的慣例，而且本文毫無例外地將其套用至所有序列，因為價格序列及其報酬率在每個章節中都應具有一致的意義。本 Notebook 所支援的案例研究採取的是賣出跨式選擇權，而不是買進。對賣方而言，在\*單一\*期間內、尚未扣除成本且持有數量固定的損益（P&L），就是下方列出的多頭報酬率取負值。

但這個關係不能直接延伸到累積報酬率，而且兩者的差異並不小。將每一期報酬率取負值後再進行複利累積，與先將報酬率複利累積、再對結果取負值，會得到不同的序列：一個多頭序列先出現 $+10\%$、接著出現 $-10\%$，複利累積後得到 $-1\%$；而將每一期報酬率分別取負值後，也會得到相同的複利累積結果。只有在明確定義部位規模的設定方式後，才能定義空頭的累積報酬率，也就是必須先決定整個期間的持有數量是否固定，或是每天依照權益重新調整。因此，本 Notebook 會列出多頭序列，並在需要空頭數值的地方說明所採用的慣例。
