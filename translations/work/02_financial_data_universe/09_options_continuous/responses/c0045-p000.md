## 5. 總結：三種方法的比較

| 方法           | 運作機制                          | 適用用途              |
| ------------ | ----------------------------- | ----------------- |
| 天真方法（鏈接法）    | 在固定到期期間序列上使用 `shift(-h)` | 不適用於任何用途。它會污染標籤   |
| 相同合約法        | 查找 h 天後進場時所選合約的價格             | 標籤，因為標籤代表逐筆交易的損益  |
| 連續序列（持有合約法）  | 轉倉日採用原持有合約的報酬率                | 回測中的逐市評價          |
| 連續序列（轉倉日歸零法） | 轉倉日的報酬率設為零                    | 不適用於任何用途。它會刪除真實損益 |

四種方法中有三種需要原始選擇權鏈資料；只有轉倉日歸零法不需要，而這也正是它唯一的吸引力。對於每季才重新選擇合約的序列而言，這種捷徑尚有合理性。但對於大多數交易日都會重新選擇合約的序列而言，它會犧牲樣本中大部分的報酬。前一節已對此進行量化衡量，而不只是提出論述。
