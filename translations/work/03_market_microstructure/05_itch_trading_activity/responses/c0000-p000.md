# 交易活動概覽：NASDAQ 市場結構

**第三章：市場微觀結構**

**Docker 映像檔**：`ml4t`

## 目的

提供本章涵蓋整體市場的 ITCH 背景：彙總訊息類型組成、各股票代碼之間的成交金額集中度，以及供 `06_itch_intraday_patterns` 與 `07_itch_stylized_facts` 重複使用、已補充資訊的標準成交 Parquet 檔案。

## 學習目標

完成本 Notebook 後，你將能夠：
- 統計多日樣本中的 ITCH 訊息類型，並比較新增／取消／成交執行的頻率比例。
- 將 `E`／`C`／`X` 訊息，聯結至以 `R` 為基礎的 `stock_locate → stock` 目錄，以及 `A`／`F` 新增委託屬性（納入 `U` 替換沿革），建立可歸屬至股票的成交表。
- 量化整個股票池的成交金額集中度（Pareto 式分析）。

## 書籍對照

第 §3.3 節，〈從原始訊息到限價委託簿〉，其中整體市場統計段落引用本 Notebook。

## 先備條件

- 位於 `data/equities/market/microstructure/nasdaq_itch/messages/` 的已解析 ITCH 訊息 Parquet 檔案
  （由 `01_itch_parser` 或 Rust 解析器輸出）。
- Notebook 06 與 07 讀取本 Notebook 寫入 `03_market_microstructure/output/nasdaq_itch/trading_activity/` 下的標準成交表。
