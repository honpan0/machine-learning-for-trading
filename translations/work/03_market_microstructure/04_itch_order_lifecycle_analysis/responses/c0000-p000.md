# 委託生命週期分析：從提交到取消或成交執行

**第三章：市場微觀結構**

**Docker 映像檔**：`ml4t`

## 目的

追蹤 NASDAQ 個別限價委託，從提交到首次終止事件（刪除、部分取消或替換），以及到首次成交執行的過程，並量化 ITCH 樣本中由此得到的取消率與成交執行率分布。

## 學習目標

完成本 Notebook 後，你將能夠：
- 從新增（`A`／`F`）、刪除（`D`）、部分取消（`X`）、替換（`U`）及成交執行（`E`／`C`）ITCH 訊息重建委託生命週期。
- 衡量委託以取消或成交告終的頻率，並說明為何這兩個比率加總不等於一。
- 衡量委託在各種結果發生前的存續時間，並使用能在同一張圖呈現微秒到數小時的尺度。
- 區分樣本結束時仍在掛單的委託，以及成交後被刪除的委託，避免對任何結果重複計數。

## 書籍對照

第 §3.3 節，〈從原始訊息到限價委託簿〉，其中關於取消率、取消所需時間及成交執行所需時間的實證發現。

  （由 `01_itch_parser` 或 Rust 解析器輸出）。
