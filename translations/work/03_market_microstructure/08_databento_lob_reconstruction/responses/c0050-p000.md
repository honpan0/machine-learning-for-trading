## 重點整理

### MBO 訊息語意

| 動作 | 意義 | 更新委託簿 |
|--------|---------|-------------|
| **A** | 新增委託 | 是 |
| **M** | 修改委託（價格／數量） | 是 |
| **C** | 取消（部分或全部） | 是 |
| **F** | 成交執行（減少簿上委託數量） | 是 |
| **T** | 成交紀錄（資訊用途） | 否 |
| **R** | 重設／清空委託簿 | 是（全部清空） |

### TOB 處理（IEXG、NYSE National）

部分交易場所只提供最佳買賣報價資料。當 `flags & F_TOB` 時：
- **新增**：以新的最佳報價取代該側全部內容
- **UNDEF_PRICE**：清空該側全部內容（無深度）

### 計算的特徵

| 特徵 | 說明 |
|---------|-------------|
| `spread_bps` | 以基點表示的買賣價差 |
| `depth_imbalance` | （買盤深度 − 賣盤深度）／總深度 |
| `bid_size_N`、`ask_size_N` | 第 N 個最佳價位的深度 |

### 效能說明

- **陣列迭代**比 `to_dicts()` 快 5–10 倍
- **整數奈秒**避免日期時間轉換的額外負擔
- **以 Counter 記錄價位**可在 O(1) 時間新增／移除，僅在查詢時排序
