第 1 章，第 1.4 節，「因應不斷變化的市場狀態」。macro_regimes 是配套的 Notebook，改以總體經濟指標估計市場狀態。
先備知識
- 月報酬時間序列與標準化（減去平均值，再除以標準差），使不同尺度的時間序列在距離計算中具有可比較的貢獻。
- AQR Century of Factor Premia 資料集，AQRFactorProvider 會從 ML4T_DATA_PATH 下的 data/factors/aqr 讀取此資料集。若資料集不存在，請使用 uv run python data/factors/aqr_download.py 取得。
本 Notebook 能夠證明什麼，以及不能證明什麼
模型使用完整的歷史資料進行擬合，再將標籤指派回同一段歷史資料。其產出是對因子空間如何劃分的描述，以及觀察具有明確日期的事件落在這些劃分中何處的一種方法。每個月份的標籤都受到其他所有月份（包括其後月份）的資訊影響，因此這些標籤是在描述樣本，而不是進行預測。若要建立交易策略在當時實際能夠據以採取行動的市場狀態標籤，就必須使用每個時間點當時可取得的資訊，進行滾動向前擬合（walk-forward fitting）；第 6 章起將介紹這套方法，並在個案研究章節中加以應用。
