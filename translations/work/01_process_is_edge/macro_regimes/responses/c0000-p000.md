# 基於總體經濟的市場狀態偵測

第 1 章 · §1.4 因應不斷變化的市場狀態

Docker 映像檔：`ml4t`

`factor_regimes` 根據因子本身所產生的報酬來估計市場狀態。本 Notebook 探討是否能利用市場以外的資訊，重現相同的分群結果。所使用的是聖路易聯邦準備銀行透過 FRED 資料庫發布的總體經濟時間序列，包括失業率、政策利率、殖利率曲線的形狀，以及通貨膨脹率。

總體經濟輸入變數的吸引力在於，它們並非報酬率。根據報酬率估計的市場狀態，可能只是重述模型擬合時所依據的波動率；而根據勞動市場與利率環境估計的市場狀態，則是對經濟情況的描述，接著便能將其與股票市場的實際表現進行對照。這項檢驗是本 Notebook 的後半部分，也是區分市場狀態模型究竟發現了有意義的現象，還是僅僅將時間區間切分開來的關鍵。
