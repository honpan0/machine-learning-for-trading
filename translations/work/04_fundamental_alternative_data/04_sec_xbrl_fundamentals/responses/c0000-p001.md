`02_sec_filing_explorer.py` Notebook 示範如何使用 edgartools 函式庫進行**個別公司分析**：探索申報文件、擷取財務報表及解析 13F 持股。edgartools 非常適合深入研究特定公司。

本 Notebook 採取不同方式：使用 SEC 的 XBRL Frames API **批次取得資料**，一次請求即可取得跨所有申報者的彙總資料。對建立橫斷面基本面資料集而言，這更有效率。

| 使用情境 | 最佳工具 |
|----------|-----------|
| 分析單一公司的申報文件 | `02_sec_filing_explorer.py` |
| 為 20 檔以上股票建立因子資料集 | 本 Notebook（XBRL Frames API） |
| 解析複雜申報文件 | `02_sec_filing_explorer.py` |
| 取得全市場季度彙總資料 | 本 Notebook（XBRL Frames API） |

## 時點（PIT）正確性

**關鍵**：回測使用的基本面資料，必須僅反映各歷史日期當時可得的資訊。使用會計季度截止日會造成前瞻偏誤，因為申報文件在 30–60 天後才發布。

下載器將 SEC Submissions API 的**申報日**連接至 XBRL frames，因此每列同時包含 `fiscal_quarter_end`（有效時間）與 `announcement_date`（知悉時間）：

| 日期類型 | 用途 |
|-----------|-------|
| `fiscal_quarter_end` | 資料描述的期間（例如 2024-03-31） |
| `announcement_date` | 向 SEC 提交申報文件的時間（例如 2024-05-02） |

回測時，使用 `announcement_date` 作為資料開始可得的時點。
