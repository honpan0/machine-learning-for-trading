一列由數次 Frames 呼叫填入，其事實資料可能來自不同申報文件，因此 `announcement_date` 是該列所含**最後一項**事實資料的申報日——也就是其中所有內容都已公開的日期。將該列定在任何更早日期，都會讓回測在數值尚未存在前就取得它。

## 資料來源

下載器使用兩個免費、公開的 SEC EDGAR API（無須訂閱供應商）：

1. **XBRL Frames API**——跨所有申報者的彙總財務資料：
   `https://data.sec.gov/api/xbrl/frames/{taxonomy}/{concept}/{unit}/{period}.json`

   **CY 與 FY Frames**：API 使用 **CY**（曆年）季度，而非會計年度。這是刻意的設計：CY frames 提供所有公司報導相同曆年期間的橫斷面快照，讓比較基準一致。會計年度與曆年不同的公司（例如 MSFT 於 6 月 30 日結束年度），其資料會映射至適當的 CY 季度。

2. **Submissions API**——各公司的申報中繼資料，首次取得時依 CIK 快取，讓重跑時不會再次呼叫端點：
   `https://data.sec.gov/submissions/CIK{cik}.json`

## 下載器

```bash
# 20 large-cap US equities × 2022-2024 × 11 standard concepts (~2-3 min)
uv run python data/equities/fundamentals/xbrl_download.py

# Custom year range or CIK list

uv run python data/equities/fundamentals/xbrl_download.py --ciks 320193
```
