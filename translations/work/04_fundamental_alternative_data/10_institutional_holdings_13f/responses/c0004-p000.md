## 1. 封存檔

下載程式會解析一次 SEC 的季度 zip 檔，並為每季寫出一個 parquet 檔。每一列代表一份申報中的一筆部位。

| 欄位 | 意義 |
| --- | --- |
| `cik` | 管理機構的中央索引碼（Central Index Key），可永久識別申報者 |
| `accession_no` | 申報本身的識別碼；同一申報期間內，一家管理機構可能有數份申報 |
| `cusip` | 證券識別碼，也是持股唯一可靠的鍵值 |
| `issuer` | **該申報者輸入的**公司名稱 |
| `value_thousands` | 該部位申報的美元價值 |
| `shares` | 申報股數 |
| `filing_date` | 申報送達 EDGAR 的日期 |
| `company_name` | 封面所列的管理機構名稱 |
