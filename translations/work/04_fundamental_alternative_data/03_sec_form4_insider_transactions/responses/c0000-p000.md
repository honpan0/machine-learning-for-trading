# SEC Form 4：內部人交易分析

**第 4 章：基本面與另類資料**
**Docker 映像檔**：`ml4t`
**參照章節**：第 4.1 節（時點資料管線）

## 目的

公司主管、董事或持股百分之十的股東交易該公司股票時，須申報 Form 4，期限為交易後兩個營業日內。此期限夠短，使申報文件在資訊仍具時效時到達，這也是該表單值得解析的原因。前一份 Notebook 透過已完成解析的函式庫讀取 Form 4。本份直接處理 SEC 發布的 XML，因為依內部人活動建立的特徵，其可信度取決於產生它的讀取程式，而失敗模式就藏在解析過程中。

## 學習目標

完成本 Notebook 後，你將能夠：

- 讀取 Form 4 XML 文件，指出承載發行人、申報內部人及每筆個別交易的元素。
- 每筆交易擷取一列，包含交易代碼、日期、股數、價格及方向，並將每個欄位維持在其所屬交易上。
- 將擷取列與原始檔案中的交易核對，並交代每筆未保留的交易。
- 使用交易代碼，區分反映買賣決策的交易，以及構成大多數交易量的薪酬事件。
- 將有價格的交易彙總為各內部人的美元總額，避免未定價的列悄悄混入。

## 先備條件

本 Notebook 讀取以下指令下載的 Form 4 申報文件：
```bash
uv run python data/equities/positioning/form4_download.py --ticker TSLA --count 20
```
