## 1. 兩個交易場所

兩者都掛牌價格可解讀為機率的二元合約。除此之外，其他方面都不同，差異可分成兩組。

| | Polymarket | Kalshi |
|---|---|---|
| 監管機關 | 無 | 美國商品期貨交易委員會 |
| 結算資產 | USDC，一種美元穩定幣 | 美元 |
| 部位限額 | 無 | 每份合約二萬五千美元 |
| 對美國人士開放 | 否 | 是 |
| 掛牌方式 | 使用者提案，範圍廣 | 交易所決定，範圍較窄 |

前四列涉及**誰能交易，以及能交易多少**，並決定價格彙整的是誰的看法。一個不對美國人士開放的交易場所，對美國利率決策的定價，採用的是除了最接近此事的人以外所有人的意見；這是選擇效應，而非缺陷，但在將任一價格視為市場看法前，必須記住這一點。

最後一列涉及**哪些合約得以掛牌**，決定資料究竟能回答哪些問題。這也是最常被誇大的一項差異，第三部分會加以說明。
