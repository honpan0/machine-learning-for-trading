## 重要重點

1. EDGAR 免費、完整，並以 CIK 為鍵。以股票代號建立的管線在第一次改名時就會失效；以 CIK 建立的管線則不會。
2. EdgarTools 傳回物件而非文件，使單一公司的分析很快：一次呼叫即可取得已解析的損益表、Form 4 交易表格或 13F 持股資料框。大量橫斷面作業是另一類問題，應使用 Frames API 或 SEC 的批次封存資料。
3. 報表項目依申報者選用的顯示標籤存取，而各申報者的標籤不一致。需要跨公司一致運作的處理，應改以 XBRL 標籤為鍵。
4. Form 4 的資訊性取決於交易代碼，因為表單中大多數內容屬於薪酬，而非買賣決策。
5. 13F 以最長四十五天的延遲申報應申報美國證券的多頭部位。它不含空頭及海外上市證券；它包含交易所交易選擇權，且記錄其控制的標的價值，因此集中度指標必須將選擇權與股票分開。應將它解讀為已揭露內容的描述，而非管理機構當下持倉的描述。
6. 申報文件的兩個日期皆可取得，但只有申報日可作為回測中截至當時可得的時間戳記。
