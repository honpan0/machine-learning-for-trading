## 第 7 部分：申報文件本身

在解析後物件的底層，申報內容是一組文件，而文字正是本書後續 NLP Notebook 處理的材料。申報文件透過四種方式提供內容：

| 呼叫 | 傳回內容 |
|------|---------|
| `filing.text()` | 純文字形式的申報文件 |
| `filing.html()` | HTML 形式的申報文件 |
| `filing.open()` | 在瀏覽器中顯示申報文件 |
| `filing.attachments` | 附件、XBRL 執行個體與綱要檔案 |

一份 10-K 長達數十萬字元，大部分是制式文字，因此 [`14_text_data_extraction`](14_text_data_extraction.ipynb) 會擷取具名章節，而非處理整份文件。
