# EdgarTools：互動式 SEC 申報文件分析

**第 4 章：基本面與另類資料**
**Docker 映像檔**：`ml4t`
**參照章節**：第 4.1 節（時點資料管線）

## 目的

每家美國上市公司都會向證券交易委員會（SEC）申報財務報表、內部人交易及機構持股，而 SEC 透過名為 EDGAR 的免費介面公開所有資料。原始介面傳回 XML 與 HTML 文件。EdgarTools 是包裝此介面的 Python 函式庫，會傳回物件：一家公司、一份該公司申報文件清單，或已從申報文件 XBRL 標籤解析出的損益表。

本 Notebook 將完整走過這套介面一次，讓本章後續 Notebook 能直接使用所需部分，無須重新介紹函式庫。我們會查詢公司、篩選申報文件、取得三大財務報表、讀取一份 Form 4 內部人交易申報與一份 Form 13F 持股報告，並依表單類型搜尋整個申報索引。

## 學習目標

完成本 Notebook 後，你將能夠：

- 依股票代號或 SEC 指派的中央索引碼（Central Index Key）查詢公司。
- 將公司申報文件篩選為單一表單類型，並讀取最新一份。
- 從 10-K 取得表格形式的損益表、資產負債表及現金流量表。
- 讀取申報公司主管或董事交易的 Form 4，並說明其中記錄的交易。
- 讀取申報大型投資管理機構季度股票持股的 Form 13F，並衡量所申報投資組合的集中度。
- 在指定日期範圍內搜尋整個 EDGAR 索引中某一表單類型的申報文件。
