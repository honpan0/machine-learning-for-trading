## 先備條件

SEC 要求每次請求透過含有姓名與電子郵件地址的 `User-Agent` 標頭識別寄件者，並會拒絕佔位用地址。這不是 API 金鑰，也不需要註冊：啟動 Jupyter 前，請將自己的姓名與電子郵件填入 `EDGAR_IDENTITY` 那一行，該行位於儲存庫根目錄的 `.env` 檔案中。

```
EDGAR_IDENTITY=Jane Doe jane@example.org
```

## 兩個時間戳記，以及回測可使用哪一個

每份申報文件都有兩個日期。**期間截止日**是報表涵蓋的會計日期；**申報日**是文件送達 EDGAR 並公開的日期。10-K 通常在所報導期間結束後一至三個月申報，因此若模型將基本面數值對應至期間截止日，就讀取了當時沒有人能看到的數字。任何將用於回測的資料，都應使用申報日作為截至當時可得的時間戳記。本 Notebook 著重探索，而非建構管線，因此兩個日期都會顯示。
