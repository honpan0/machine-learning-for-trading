# 鏈上基本面：以 DeFi TVL 作為替代資料

**第四章：基本面與替代資料**
**Docker 映像檔**：`ml4t`
**章節參照**：第 4.4 節（認識替代資料）

## 目的

公開區塊鏈記錄每筆交易，因此在其他市場會是商業機密的數值，在這裡卻可直接讀取：各借貸池、交易所與金庫存入多少資金。將一條鏈上各協議的金額加總，就是**總鎖定價值**，也是去中心化金融中最接近基本面的指標。

它也是本章此節核心問題的好範例：重點不是「這個資料集衡量什麼」，而是「它值得整合嗎」。本 Notebook 採用一個直觀假設——資金流入 DeFi 領先以太幣價格上漲——並嘗試量測。結果大部分工作都在確認現有資料究竟能說明的有多少，答案往往很少；這通常是誠實評估替代資料的結果，也是評估必須先於整合的原因。

## 學習目標

完成本 Notebook 後，你將能夠：

- 定義總鎖定價值，並說明它能與不能衡量的內容。
- 載入鏈層級 TVL 歷史及配對價格序列，並識別兩者中哪個限制了可研究的視窗。
- 以真正的總額而非所選子集為基準，呈現組成拆分。
- 將水準轉成動能與狀態特徵，並說明各自的量測視窗。
- 檢驗訊號是否能預測前向報酬率，並修正前向報酬率重疊對檢定的影響。
- 計算結果背後的獨立觀測值數量，並依此判斷結果是否足以據以採取行動。
