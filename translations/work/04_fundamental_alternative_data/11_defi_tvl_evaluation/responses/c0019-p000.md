### 硬性關卡：沒有歷史版本

上方每項檢查都通過了，但有一件未檢查的事仍決定了能否過關。

DeFi Llama 提供的序列反映的是**它目前對資料的理解**。當某個協議納入涵蓋範圍時，該協議的歷史資料也會一併加入；當某個存入代幣的價格來源被修正，過去每個使用該代幣的日期都會重新計算。因此序列會被重編，而 API 沒有提供查詢某個過去日期當時數值的方法。

回測讀取這份資料，讀到的是今日所理解的 2021 年，其中包含 2021 年還沒有人追蹤的協議；由於任何地方都沒有保留較早的版本，也無法衡量差異有多大。前一份 Notebook 能衡量公債殖利率的修訂，是因為存在歷史版本封存；在這裡，同樣的問題卻沒有答案。

因此這是一道硬性關卡，而非僅需留意的限制。以重編歷史資料計算的訊號，無法證明在當時就能計算，訊號再強也無法補救。突破的方法有兩種：從現在開始每天擷取資料快照，建立歷史版本封存，一年後才開始產生可用的歷史資料；或將所有主張限於開始擷取快照之後的期間。
