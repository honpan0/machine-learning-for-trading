## 輔助函式

### 求解器選擇

sklearn 的 `LogisticRegression` 提供數種針對不同懲罰結構最佳化的求解器：

| 求解器 | L1 | L2 | ElasticNet | 多項式分類 | 適用情境 |
|------------|----|----|------------|-------------|----------------------------------------------|
| `lbfgs` | 否 | 是 | 否 | 是 | 預設 L2；快速擬牛頓法 |
| `liblinear` | 是 | 是 | 否 | 否 | 純 L1 二元分類；座標下降法 |
| `saga` | 是 | 是 | 是 | 是 | ElasticNet、大型 $n$、`sample_weight` |

我們使用 `lbfgs` 處理 L2（快速且數值穩定），使用 `liblinear` 處理純 L1 二元分類；只有需要混合 ElasticNet 時才使用 `saga`。
