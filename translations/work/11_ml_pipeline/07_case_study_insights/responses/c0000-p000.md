# 案例研究洞見：線性模型

**Docker 映像檔**：`ml4t`

**目的**：彙整線性模型家族（OLS、Ridge、Lasso、ElasticNet）跨案例研究的觀點。各案例研究的深入分析位於 `case_studies/{cs}/13_model_analysis.py`；本 Notebook 則比較全部九個案例研究。

**學習目標**

- 對每個案例研究，解讀在主要標籤上 IC 最高且結果完整的線性設定，其每日橫斷面 Spearman IC 平均值及 HAC 區間
- 比較各案例研究主要標籤上的正則化模型家族（OLS、Ridge、Lasso、ElasticNet）
- 檢視各折 IC 分布與 ICIR 穩定性診斷
- 將比較擴展至不同標籤（預測期間觀點），以及分類與迴歸指標的對稱性
- 檢視係數正負號一致性、Lasso 稀疏性，以及跨案例研究入選特徵的重疊程度

**書中參考章節**：第 11.6 節〈案例研究洞見〉。

**先備條件**：各案例研究的 `06_linear.py` 流程已將線性模型家族的結果寫入 `run_log/registry.db`。教學 Notebook NB01–NB06 涵蓋相關技術。
