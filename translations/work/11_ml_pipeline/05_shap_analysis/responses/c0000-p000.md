# 線性模型的 SHAP 可解釋性

**Docker 映像檔**：`ml4t`

**目的**：使用 SHAP（SHapley Additive exPlanations）解釋在 ETF 面板上訓練的 Ridge 迴歸模型。對線性模型而言，SHAP 值可以精確分解為 $\phi_j = \beta_j \cdot (x_j - \bar{x}_j)$，使歸因透明且可驗證。

我們示範四個層次的解釋：

1. **整體特徵重要性**：哪些特徵在所有預測中最重要。
2. **單筆預測解釋**：各特徵如何共同形成單筆預測。
3. **與決策相關的分析**：幅度大的預測中，*正確*與*錯誤*預測的 SHAP 輪廓。
4. **穩定性**：跨驗證折的重要性軌跡，以及在單折內對主要特徵平均 $|\phi_j|$ 建立的自助抽樣信賴帶。

**學習目標**

- 計算並驗證 Ridge 的精確線性 SHAP 值
- 透過 SHAP 瀑布圖分解單筆預測
- 比較高信心預測正確與錯誤時的特徵驅動因素
- 建立 SHAP 穩定性圖表與單折內自助抽樣信賴帶
