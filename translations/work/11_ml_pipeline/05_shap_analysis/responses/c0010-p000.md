## 訓練 Ridge 模型並計算 SHAP 值

我們在訓練折上配適 Ridge，並在測試集上計算 SHAP 值。下方儲存格刻意設定較輕的懲罰：這裡的重點是歸因方法；輕度懲罰讓權重分散到更多特徵，使分解結果更容易解讀。它不是在此面板上預測效果最佳的懲罰強度 `02_regularization_paths`；下文的歸因描述的是實際配適的模型，而非會用於交易的模型。
`shap.LinearExplainer` 對線性模型提供**精確**的 SHAP 值，不需近似，也不需抽樣。

**SHAP API 用法**（v0.50+）：建立描述背景分配的 masker，將其傳給 explainer，再以測試資料呼叫 explainer，取得 `Explanation` 物件；其中以單一結構包含 `.values`、`.base_values` 與 `.data`。
