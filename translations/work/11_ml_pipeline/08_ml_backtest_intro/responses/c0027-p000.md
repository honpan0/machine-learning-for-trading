**解讀方式。** 上方兩種排名依據不同，不必然一致。平均 IC 衡量訊號排列下個月報酬的能力。成本後 Sharpe 衡量持有該排名隱含的投資組合，並支付調整成本後，還剩下多少表現。訊號可能排名良好，最後卻落後於完全沒有訊號的規則，因為每次再平衡都要支付執行排名的成本，而排名本身免費。

等權重是有用的對照：它持有所有資產，每月只交易到各資產回復 $1/N$ 所需的偏移量，因此成本前後的 Sharpe 幾乎相同。主動策略每月重新挑選前 N 名，必須支付兩次名單之間全部差異的交易成本。它對年化報酬的拖累等於成本率乘以交易比例，因此報酬拖累與換手率成正比。Sharpe 拖累則是報酬拖累除以策略自身波動率，排序可能不同：若兩種策略的交易量相同，較穩定者損失的比率反而較大。

即使訊號的 IC 接近零或為負，成本後 Sharpe 仍可能不差，而排名並非唯一可能來源。從共同投資範圍建立的只做多前 N 名投資組合，無論排名如何，都會承接該範圍的大部分報酬；已實現波動率較低，也會在報酬不變的情況下提高比率。IC 欄與 Sharpe 欄應視為兩個不同問題的答案，而非同一分數的兩次呈現。對策是採用懲罰換手率的目標函數與交易限制，第 17 與 18 章會進一步介紹。
