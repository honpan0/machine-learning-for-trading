# GBM 函式庫基準測試：sklearn、XGBoost、LightGBM 與 CatBoost

**Docker 映像檔**：`ml4t-gpu`

**第 12 章第 12.2 節**：主力模型——梯度提升機

## 目的
本 Notebook 在 CPU 與 GPU 上對四種梯度提升實作進行基準測試，衡量準確度（IC）、訓練時間與記憶體用量。目標是提供實務工作者選擇函式庫時可依據的具體數據，而非仰賴慣常看法。

## 學習目標
- 比較 sklearn HistGradientBoosting、XGBoost、LightGBM 與 CatBoost
- 在真實金融資料集上衡量 GPU 加速效果
- 了解模型複雜度（輕量、中等、重量級預設組態）如何影響準確度、速度與記憶體之間的取捨
- 示範單調約束與 SHAP 依賴關係分析
