# 集成學習基礎：隨機森林與梯度提升的比較

**Docker 映像檔**：`ml4t`

本 Notebook 使用 Chen-Pelger-Zhu（2020）的公司特徵資料集，比較裝袋法（隨機森林）與提升法（XGBoost、LightGBM、CatBoost）的基準表現。這份資料是由股票與月份的觀測值構成的追蹤資料，包含匿名化特徵及預先定義的時間切分。下方的載入程序會列出各資料切分的列數與特徵數。

## 學習目標
- 在大型橫斷面金融資料集上，比較隨機森林（裝袋法）與 XGBoost、LightGBM、CatBoost（提升法）
- 使用時間保留集的排名 IC 評估模型
- 分析不同集成方法的特徵重要性差異
- 衡量此基準測試中隨機森林與三套 GBM 函式庫之間的 IC 差距

**書籍參考**：第 12.1 節說明從平均化（隨機森林）發展到依序修正誤差（提升法）的動機。本 Notebook 以實證方式比較兩者。

**先決條件**：Chen-Pelger-Zhu 公司特徵資料集（透過 `load_firm_characteristics`）

**跨章節關聯**：結果會提供給第 14 章（潛在因子模型）與第 20 章（模型綜合），以便在同一基準資料集上比較方法。
