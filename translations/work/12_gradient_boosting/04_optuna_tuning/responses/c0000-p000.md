# 使用 Optuna 調校超參數

**Docker 映像檔**：`ml4t`

**第 12 章第 12.4 節**：使用 Optuna 進行進階超參數調校

## 目的
本 Notebook 以 ETF 案例研究，示範如何利用 Optuna 的 TPE 貝葉斯最佳化架構，有效率地進行超參數最佳化。內容先涵蓋具剪枝及提前停止機制的單一折次調校，再延伸至對多個滾動向前驗證折次取平均的超參數最佳化；後者是第 12.4 節對金融資料建議的方法。

## 學習目標
完成本 Notebook 後，你將能夠：
- 運用 Optuna 的 define-by-run API 調校 LightGBM 超參數
- 使用提前停止與 MedianPruner 減少無效運算
- 實作考慮時間序列特性的調校，對滾動向前驗證結果取平均
- 解讀超參數重要性排名
- 比較預設模型與調校後模型在保留資料上的表現
