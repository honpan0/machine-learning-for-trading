## 3. LightGBM 超參數：調校哪些項目

各參數類別及其影響的詳細討論，請參閱第 12.4 節。關鍵見解是：在訊噪比低的情況下，**正則化參數往往對樣本外表現影響最大**。

參數範圍由下方目標函數中的 `suggest_*` 呼叫定義，因此本表說明各參數的作用，而不重複列出可能與程式碼脫節的邊界值。

### 結構

| 參數 | 作用 |
|-----------|--------|
| `num_leaves` | 樹的複雜度：葉節點越多，擬合能力越強，也越早過度擬合 |
| `learning_rate` | 步長；保持較低數值，讓提前停止決定迭代輪數 |
| `max_depth` | 對逐葉生長的另一項限制 |
| `min_child_samples` | 葉節點背後的最少資料列數；數值越高，擬合越平滑 |

### 正則化

| 參數 | 作用 |
|-----------|--------|
| `reg_alpha`（L1） | 葉節點權重的 Lasso 懲罰 |
| `reg_lambda`（L2） | 葉節點權重的 Ridge 懲罰 |
| `subsample` | 每棵樹的資料列取樣 |
| `colsample_bytree` | 每棵樹的欄位取樣 |
