## 重點摘要

### 網格搜尋

| 優點 | 缺點 |
|------|------|
| 簡單、可重現 | 維度增加時，組合數呈指數成長 |
| 完整涵蓋搜尋空間 | 只能使用固定、離散的候選值 |
| 容易平行化 | 在表現不佳的區域浪費評估次數 |

### Optuna（貝葉斯方法）

| 優點 | 缺點 |
|------|------|
| 智慧取樣（TPE） | 設定較複雜 |
| 支援連續搜尋空間 | 結果隨隨機種子而變 |
| 在搜尋過程中調整 | 需要更多試驗才能取得穩定結果 |

### 實務建議

1. **網格搜尋**：適合不超過 4 個參數、每個參數不超過 3 個候選值
2. **Optuna**：較適合超過 4 個參數或連續範圍
3. **預算**：50–100 次試驗是 GBM 調校的常見慣例，但它是一項參數，而非預設答案。應以巢狀或滾動向前驗證選定預算，再對保留集評分一次。第 8 節跨預算觀察保留集，是為了*展示*兩項準則如何分歧；這是事後診斷，而非選擇預算的方法
4. **務必**：在最佳化期間保留完全不接觸的測試集
