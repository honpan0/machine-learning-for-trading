# 跨函式庫超參數最佳化：XGBoost、LightGBM 與 CatBoost

**Docker 映像檔**：`ml4t-gpu`

**第 12 章第 12.4 節**：使用 Optuna 進行進階超參數調校

> **建議使用 GPU**：本 Notebook 使用 PyTorch/CUDA 訓練模型。它也能在 CPU 上執行，
> 但訓練可能非常緩慢。若要使用 GPU 加速：
> ```bash
> docker compose run --rm ml4t-gpu python 12_gradient_boosting/05_cross_library_hpo.py
> ```

## 目的
在 Chen-Pelger-Zhu（2020）公司特徵資料集上，使用 Optuna 對 XGBoost、LightGBM 與 CatBoost 進行超參數最佳化。在各函式庫的研究中，**損失類型是一項超參數**；MSE 與 MAE 的選擇視為可調校的決策，而非固定的先驗假設。

## 學習目標
- 依共同程序，使用 Optuna 調校 XGBoost、LightGBM 與 CatBoost
- 將損失函數選擇視為一級超參數
- 重新建立模型後，比較最佳驗證集與最佳測試集 IC
- 診斷哪些超參數推動雜訊較多的金融目標之表現改善

**先決條件**：需要公司特徵資料集，以及來自 `data/__init__.py` 的輔助載入程序。

## 核心概念
- 為各函式庫設定可調整暖身試驗次數的 TPE
- 使用 MedianPruner 提前終止缺乏潛力的試驗
- 使用 SQLite 持久化儲存，以利重現結果
- 將損失函數設為類別型超參數
- 分析超參數重要性（包括 loss_type）
