**解讀**：同一筆資料列的相關係數較大，但無法據以交易。買盤失衡的資料列通常也是價格上漲的資料列，因此同列數值大多只是換一種方式告訴你這是一筆上漲資料列；使用它的策略等於假設資料列尚未結束，就已知道其結果。兩個數值之間的差距，正是此處前瞻偏誤的影響。

落後一期的相關係數才是策略可能據以行動的數值，而此樣本無法證明它與零不同：其區間跨越零，同列相關係數的區間則沒有。這是誠實的解讀，也無須因此失望。本 Notebook 展示的是特徵建構方式與偏誤大小，兩者在單一交易時段內都能看見。落後一期的訂單流失衡是否具有可交易資訊，需要利用許多交易時段及股票來回答；面對寬廣的區間，正確做法是擴大樣本，而不是只引用點估計值。
