## 總結

### 以交易為基礎的特徵（開高低收與成交量）

| 特徵 | 函式庫函式 | 用途 |
|---------|------------------|----------|
| Kyle λ | `kyle_lambda()` | 價格衝擊估計 |
| Amihud | `amihud_illiquidity()` | 非流動性溢酬 |
| Roll 價差 | `roll_spread_estimator()` | 交易成本代理指標 |
| 訂單流失衡 | `effective_tick_rule()` ＋逐資料列買賣彙總 | 短期預測 |
| 交易強度 | `trade_intensity()` | 交易活動狀態 |

### 關鍵區別

1. **超額報酬訊號與可行性**：訂單流失衡是超額報酬訊號（必須落後使用！）；Kyle λ 是可行性指標（可直接使用）
2. **流量與狀態**：新進交易 ≠ 委託簿狀態；不要從流量計算「價差」
3. **資料需求**：Kyle λ、Amihud 和 Roll 適用於開高低收與成交量資料列；訂單流失衡是需要逐筆交易分類的流量特徵（先對每筆交易套用逐筆價格變動法則，再彙總）；真正的限價委託簿特徵需要委託簿快照

### 整合至策略

- **可行性篩選層**：使用 Kyle λ、Amihud 設定部位規模，並篩除流動性差的股票
- **成本估計**：在交易成本模型中使用 Roll 價差估計量
- **超額報酬訊號**：使用落後一期的訂單流失衡與交易強度進行短期預測
