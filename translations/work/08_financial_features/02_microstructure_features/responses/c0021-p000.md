## 訂單流失衡（OFI）

訂單流失衡衡量一筆資料列內的買賣失衡，作為**淨訂單流**的代理指標：

$$\text{OFI} = \frac{V_{buy} - V_{sell}}{V_{buy} + V_{sell}}$$

**重要**：若交易所未提供買賣方向標籤，我們會使用**逐筆價格變動法則**（Lee-Ready）估計每筆交易的方向，依價格變動的正負判定是買方或賣方發起。這項分類必須在彙總之前，於**逐筆交易**層級完成；因此，`aggregate_to_bars` 會在該層級拆分 `buy_volume`／`sell_volume`。若對*資料列*唯一的收盤價套用此法則，訂單流失衡就會退化成該資料列自身報酬率的正負號（+/-1）；那只是同義反覆，不是流量衡量值。這具體說明訂單流失衡為何是需要逐筆交易資料的**流量**特徵，而非資料列開高低收與成交量特徵，也正是本章強調的流量與狀態之別。
