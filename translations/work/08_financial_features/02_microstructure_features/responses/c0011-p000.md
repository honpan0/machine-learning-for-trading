## 以交易為基礎的流動性特徵

這些特徵只需要廣泛可得的開高低收與成交量資料列。它們是市場流動性與交易成本的代理指標。

| 特徵 | 函式庫在此計算的量 | 解讀 |
|---------|-------------------------------|----------------|
| Kyle λ | 視窗內 \|r\| / (V / V̄) 的平均值 | 每單位*相對*成交量對應的報酬率 |
| Amihud | 視窗內 \|r\| / DollarVol × 10⁶ 的平均值 | 每交易*百萬*美元對應的報酬率 |
| Roll 價差 | 2√(-Cov(ΔP_t, ΔP_{t-1})) | 隱含買賣價差 |

Kyle 這一列需要仔細看。`kyle_lambda` 接受 `method` 參數，其預設值為 `"ratio"`；在已安裝的版本中，`method="regression"` 會引發 `NotImplementedError`。因此，本 Notebook 計算的是上方的比值近似值，而非 Kyle（1985）的迴歸斜率。兩者都稱為 Kyle lambda，但其中只有一個涉及共變異數，而且不是此處執行的版本。
