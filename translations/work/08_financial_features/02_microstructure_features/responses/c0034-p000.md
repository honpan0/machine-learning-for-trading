**解讀**：從任一排名得出結論前，先比較上方列出的兩種排名。在此交易時段，差異不只出現在邊緣；閱讀清單，看看其中多少是重新排序，多少是順序顛倒。若讀者把其中一種衡量方式當作*唯一的*流動性排名，並依此設定部位規模，就可能得到與另一種衡量方式相反的結果。

兩種衡量方式都沒有錯，而此樣本上方列出的五種排名指出分歧從何而來。將 Kyle 排名與絕對報酬率中位數比較，再將 Amihud 排名與每百萬美元絕對報酬率中位數比較。每種估計量的排名，都與這兩種原始數值中的其中一種一致。

這正是分母的作用。Kyle 比值將成交量除以其自身滾動平均值；在典型資料列中，此比值接近 1，因此跨股票排名大致取決於典型報酬率的大小。Amihud 則除以美元成交金額，而不同股票的成交金額可能相差許多倍，因此排名依據是每交易一美元對應的報酬率。若某檔股票的報酬率最大，成交金額也最大，它就可能在一份清單中位於流動性最差的一端，在另一份清單中卻位於流動性最好的一端。這種反轉是本交易時段這三檔股票的特性，並非必然現象；普遍成立的是，兩種估計量依不同數值排名，而上方排名可用來檢查各自依據的是什麼。
