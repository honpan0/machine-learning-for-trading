### Kyle Lambda（價格衝擊）

Kyle λ 越高，表示每單位成交量對應的價格變動越大：市場**流動性越差**，交易的價格衝擊越大。

Kyle（1985）將 λ 定義為報酬率對帶符號訂單流的斜率，也就是迴歸係數：

$$r_t = \lambda \, S_t + \varepsilon_t$$

已安裝的 `ml4t-engineer` 不會擬合該迴歸。其預設的 `method="ratio"` 是將成交量除以自身滾動平均值進行標準化，再對視窗中的每筆資料列比值取平均：

$$\lambda_{\text{ratio}} = \text{mean}_{t}\!\left(\frac{|r_t|}{V_t / \bar{V}_t}\right)$$

閱讀下方圖表時，應依第二個公式解讀，因為圖表是由第二個公式產生的。兩者對「流動性較差」的方向判斷一致，但不是同一種統計量：比值使用絕對報酬率，因此沒有正負號；迴歸斜率則有。
