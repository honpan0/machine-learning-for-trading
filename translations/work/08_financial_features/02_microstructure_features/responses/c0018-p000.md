在本交易時段，兩個相關係數均為負值；上方圖表也直接顯示這一點：Kyle lambda 在下午逐漸下降，Amihud 則上升至中午的峰值後回落。讀者合理預期會一致的兩種衡量方式，卻朝相反方向變動。應注意的是負號，而非相關係數的大小；單一股票的一個交易時段無法確定其大小是否具有一般性。

兩者的分母有一項容易檢驗的差異：若將每筆成交量都乘以同一常數，而報酬率與價格維持不變，會發生什麼事？Kyle 比值會將成交量除以自身滾動平均值，因此常數會相互抵銷。Amihud 的分母是以美元計算的成交金額，因此常數會保留下來。下方單元執行此替換，並列出兩個比值相對於原值的比例。

應按此實驗的實際意義解讀。它證明兩種衡量方式對成交量報價單位的反應不同，但本身無法解釋上方的負相關；負相關來自整個交易時段中報酬率、價格與成交量一起變動。稍後的跨股票章節會進行分解，解釋兩者為何不一致。
