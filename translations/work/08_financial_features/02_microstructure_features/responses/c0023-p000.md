## 特徵的時間安排：超額報酬訊號與可行性

**關鍵區別**：有些市場微觀結構特徵是超額報酬訊號；其他則是可行性／成本狀態變數。

| 特徵 | 類別 | 落後期要求 | 用途 |
|---------|----------|-----------------|----------|
| **訂單流失衡（OFI）** | 超額報酬訊號 | 落後至少 1 筆資料列 | 預測下一筆資料列的報酬率 |
| **Kyle λ** | 可行性 | 可使用同期值 | 交易執行成本估計 |
| **Amihud** | 可行性 | 可使用同期值 | 部位規模設定 |
| **交易強度** | 背景資訊 | 可使用同期值 | 市場狀態偵測 |

### 超額報酬特徵必須落後

將訂單流失衡或類似流量特徵用作**預測變數**時，必須將其往後移，以避免前瞻偏誤：

```python
# WRONG: using contemporaneous OFI to predict same-bar returns
df["signal"] = df["ofi"]  # Look-ahead!

# CORRECT: use lagged OFI
df["signal"] = df["ofi"].shift(1)  # Predicts next bar
```
