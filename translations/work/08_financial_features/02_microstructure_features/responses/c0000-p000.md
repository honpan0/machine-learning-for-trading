# 市場微觀結構特徵

**第 8 章：特徵工程**
**對應章節**：8.2－價格衍生特徵（市場微觀結構）
**Docker 映像檔**：`ml4t`

## 目的

市場微觀結構特徵捕捉每日開高低收與成交量資料中看不到的市場動態。它們可作為**流動性**、**資訊流**及**交易執行品質**的代理指標。

## 學習目標

1. 計算以交易為基礎的流動性特徵（Kyle λ、Amihud、Roll 價差）
2. 了解訂單流失衡及其預測資訊
3. 區分**流量特徵**與**狀態特徵**（這點至關重要！）
4. 了解哪些特徵是超額報酬訊號，哪些是可行性／成本輸入

## 特徵類別

| 類別 | 特徵 | 所需資料 |
|----------|----------|---------------|
| **流動性** | Kyle λ、Amihud、Roll | 開高低收與成交量資料列 |
| **訂單流** | 訂單流失衡、交易強度 | 逐筆交易資料 |
| **委託簿狀態** | 價差、深度 | 限價委託簿快照 |

## 資料政策

使用**真實 NASDAQ ITCH 資料**。若缺少 ITCH 資料，本 Notebook 會明確報錯，不會改用合成的玩具資料面板。
