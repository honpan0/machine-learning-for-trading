**解讀**：
- 平價隱含波動率在市場壓力時期（例如 COVID 崩跌）會飆升，因此是狀態變數
- 風險逆轉為正，表示賣權需求上升（對崩跌的恐懼）
- 期限斜率 > 1 ＝期限結構倒掛（近期事件風險）
- 波動率風險溢酬 > 0 屬於正常現象；極端波動率風險溢酬顯示可能有吸引人的賣出波動率機會

**以未平倉量為基礎的特徵**（交易商 gamma、部位配置）在概念上有價值，但需要本資料集未提供的細粒度未平倉量資料。`22_sp500_equities_option_analytics_features` 中的彙總希臘字母方法提供可行的代理指標。

**波動率曲面穩定性**：若報價選擇規則（delta 慣例、插值方法、到期期限對應方式）在回測期間改變，所有選擇權衍生特徵都會受到污染。應將特徵建構選擇與特徵一起進行版本管理。
