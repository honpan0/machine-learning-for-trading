**解讀**：應閱讀上方列出的比例，而非比較採用四種不同尺度的子圖高度。逆價差表示近月合約價格高於遠月，持有者轉倉時可賺取差額；正價差則相反，持有者須支付成本。表格顯示各商品在此樣本期間位於分界線兩側的頻率。

既有解釋應與數值一起看，而非取代數值。CL 等能源合約出現逆價差，通常解讀為實體供應緊俏，市場願意為今天取得一桶原油支付較高價格。黃金是正價差的標準例子，因為儲存與融資成本居主導地位，沒有便利收益可抵銷。ZN 等債券合約的票息與融資利率相對，其正負號取決於這兩者的利差。ES 則受股利與融資之間的持有成本關係影響。此樣本是否符合上述各項解釋，正是表格要檢驗的事；如此短的樣本無法對任何一項下定論。
