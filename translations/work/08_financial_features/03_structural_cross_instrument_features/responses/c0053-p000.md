# 總結

## 特徵類別

| 類別 | 主要特徵 | 所需資料 | 主要角色 |
|--------|-------------|---------------|-------------|
| **持有收益** | 轉倉收益、資金費率 | 多種到期期限的期貨、永續合約 | 訊號 |
| **期限結構** | 斜率、曲率 | 至少 3 種到期期限 | 訊號／狀態 |
| **跨資產** | 貝他係數、領先落後關係、相對價值 | 多資產價格 | 訊號 |
| **選擇權隱含特徵** | 平價隱含波動率、偏斜、波動率風險溢酬、期限斜率 | 選擇權鏈 | 狀態 |

## 實作規則

1. **持有收益需要配對期限**：缺少遠月合約時，持有收益為 NaN
2. **貝他係數視窗很重要**：21 天適合快速反映市場狀態，63 天適合穩定估計
3. **領先落後關係可能是假的**：驗證領先關係是否只是價格過時造成的假象
4. **選擇權特徵需要波動率曲面規則**：對建構選擇進行版本管理
5. **波動率風險溢酬通常為正**：負值屬於極端情況，具有資訊價值

## 實務重點

1. **持有收益因資產類別而異**：在上方快照中，CL 比 GC 更接近逆價差；列出的比例可能支持這點，也可能不支持。應閱讀比例，而非只看這句話，並將其解讀為單一樣本的表現，而非既有解釋所描述的資產類別通則
2. **殘差動能分離特有報酬**：扣除 $\beta_{t,a} r_{t,m}$ 可從每檔 ETF 的報酬率中移除市場成分。殘差動能的資訊係數是否高於原始動能，會在 `etfs` 案例研究中評估；本 Notebook 只展示其建構方式
3. **選擇權隱含特徵是狀態，而非訊號**：使用它們作為較快速訊號的條件變數
4. **波動率曲面穩定性不可妥協**：在回測期間改變報價慣例，會使所有選擇權特徵失效
