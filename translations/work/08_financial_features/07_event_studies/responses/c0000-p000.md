# 事件研究

## 目的

事件研究衡量特定事件（訊號觸發、總體經濟公告、財報）前後的異常報酬率，以評估其預測能力。這是驗證交易訊號的重要方法。

## 學習目標

1. 了解事件研究方法（MacKinlay，1997）
2. 正確實作異常報酬率計算
3. 計算累積平均異常報酬率（CAAR）及適當的信賴區間帶
4. 使用事件研究驗證訊號
5. 辨識常見陷阱（事件群聚、視窗重疊）

## 核心概念

**事件研究流程**：
1. 定義事件（訊號觸發、公告）
2. 在估計視窗中估計「正常」報酬率
3. 在事件視窗中計算異常報酬率
4. 跨事件彙總（CAAR）
5. 檢驗統計顯著性

## 參考文獻

- MacKinlay, A.C.（1997）。〈Event Studies in Economics and Finance〉
- Boehmer 等人（1991）。事件引起的變異數調整
