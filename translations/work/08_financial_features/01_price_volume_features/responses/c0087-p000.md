## 總結

### 特徵類別選擇指南

| 類別 | 適用時機 | 主要考量 |
|--------|-------------|-------------------|
| **報酬率** | 基礎訊號、動能 | 短期期間略過最近一期 |
| **趨勢** | 順勢交易 | 以波動率縮放，提高可比較性 |
| **波動率** | 風險調整、部位規模設定 | Yang-Zhang 效率最高 |
| **波動率狀態** | 依市場狀態調整 | 百分位數比十分位數更細緻 |
| **市場狀態指標** | 趨勢偵測 | 滾動視窗、無須模型 |
| **成交量** | 流動性、確信程度 | 使用相對值，而非原始值 |
| **風險** | 部位規模設定、尾部風險 | VaR、CVaR、下行偏差 |
| **橫斷面** | 多資產 | 嚴守當時可得資料原則 |
| **機器學習轉換** | 定態性 | 分數差分 |

### 實作規則

1. **載入時排序一次**：`df.sort(["symbol", "timestamp"])`
2. **單次 with_columns 呼叫**：在一次呼叫中完成所有轉換，以利平行處理
3. **以波動率縮放以提高可比較性**：原始特徵會隨價格水準變動
4. **正式應用使用函式庫**：使用 ml4t-engineer 中經過驗證的實作
5. **橫斷面使用當時可得資料**：使用 `.over("timestamp")`
