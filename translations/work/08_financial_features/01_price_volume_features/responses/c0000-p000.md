# 價格與成交量特徵類別

**第 8 章：特徵工程**
**對應章節**：8.2－價格衍生特徵
**Docker 映像檔**：`ml4t`

## 目的

本 Notebook 示範從單一資產的價格與成交量歷史資料衍生的**核心特徵類別**。這些是多數量化策略的基礎特徵，適用於每一種可交易工具。

## 學習目標

1. 了解價格與成交量資料的核心特徵類別
2. 在明確確保時間順序安全的前提下實作特徵（排序、視窗對齊）
3. 針對橫斷面與時間序列用途選擇適當的標準化方法
4. 比較波動率估計量（收盤價對收盤價、Parkinson、Garman-Klass、Yang-Zhang）
5. 建立波動率狀態特徵（波動率比值、百分位數、十分位數）
6. 避免特徵建構中常見的資料洩漏模式

## 涵蓋的特徵類別

| 類別 | 代表性特徵 | 主要用途 |
|--------|------------------------|--------------|
| **報酬率與期間** | 簡單報酬率、對數報酬率、略過最近一期的報酬率、累積報酬率 | 基礎訊號 |
| **趨勢與反轉** | 與移動平均線的距離、迴歸斜率、至移動平均線的距離 | 動能／均值回歸 |
| **波動率** | 收盤價對收盤價、Parkinson、Garman-Klass、Yang-Zhang、波動率的波動率 | 風險調整 |
| **波動率狀態** | 波動率比值、百分位數、十分位數 | 依市場狀態調整 |
| **成交量與流動性** | 成交金額、相對成交量、成交量加權平均價格 | 容量訊號 |
| **風險** | 風險值、條件風險值、尾部比率 | 部位規模設定 |
| **橫斷面** | 排名、z 分數 | 投資標的範圍標準化 |

## 資料政策

所有範例均使用**真實 ETF 資料**（不使用合成資料）。
