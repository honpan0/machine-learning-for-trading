### 資料洩漏警告：嚴守當時可得資料的原則

**常見資料洩漏模式**：

1. **使用未來資料**：以未來數值計算 z 分數
2. **存活者偏誤**：只納入目前的成分標的
3. **排名中的前瞻偏誤**：在資料可取得之前就進行排名

**安全做法**：橫斷面運算一律使用 `.over("timestamp")`；如此可確保每個日期的統計量只使用同一時間點可得的資料：

```python
# WRONG: full-sample z-score includes future data
pl.col("mom").zscore()

# CORRECT: point-in-time cross-sectional z-score
(pl.col("mom") - pl.col("mom").mean().over("timestamp"))
/ pl.col("mom").std().over("timestamp")
```
