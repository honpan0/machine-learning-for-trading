## 主要重點

1. **穩健性是寬度，而非比值**：達到峰值 `ROBUST_THRESHOLD_PCT` 範圍內的參數比例，而非平均值除以標準差
2. **一次只調整一個參數**：改變回溯期間時保持其他條件不變，之後再組合各參數的選擇
3. **依市場狀態進行條件分析需謹慎**：使用預先定義的條件變數，絕不使用由訊號本身衍生的變數；且只有各狀態的資訊係數範圍超過 `REGIME_IC_RANGE_MIN` 時，才進行條件化
4. **修正反覆試探偏誤**：掃描 N 個參數後，套用 RAS，將因資料探勘偏誤而偏高的最大資訊係數調低
5. **交互作用會擴大搜尋範圍**：訊號與狀態的組合必須計入搜尋集合，因為每個組合都是另一項檢定
