# 跨案例研究特徵評估摘要

**第 8 章：特徵工程**
**對應章節**：8.6－組合特徵與控制搜尋
**Docker 映像檔**：`ml4t`

## 目的

本 Notebook 是跨案例研究的特徵清單與呈現層：彙整全部 9 個資產類別的各案例研究所建立的特徵，以及模型登錄庫中各案例最強的資訊係數。它呈現：
- **特徵數與類別**：各案例研究的特徵空間有多大
- **各案例研究的最佳資訊係數**（來自模型登錄庫）：各資產類別中最強特徵類別的預測能力
- **跨資產型態**：哪些特徵類別具有普遍適用性，哪些則屬於特定資產

經 HAC 調整後的顯著性及通過 BH-FDR 的特徵數，已在各案例研究上游的 `13_model_analysis.py` 中計算；本 Notebook 讀取並呈現其結果，不會重新計算。

## 學習目標

1. 比較不同資產類別的特徵預測能力
2. 查看各案例研究在登錄庫中的最佳資訊係數與特徵空間大小
3. 辨識普遍適用與特定資產的特徵類別
4. 了解投資標的範圍的大小（廣度）如何與資訊係數幅度交互作用

## 先決條件

- 案例研究的特徵 Notebook 必須已產生 `data/features/financial.parquet`
- 若某案例研究的 `features/` 目錄尚無資料面板，則顯示「等待中」。若某個程式碼檢出版本根本未連結某案例研究，便無法區分它與空目錄，因此程式會拒絕執行，而不會根據當下可見部分資料報告範圍。
