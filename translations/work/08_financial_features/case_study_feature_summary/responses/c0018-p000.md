閱讀該圖時，應分開解讀兩種視覺編碼，因為它們表達不同的事。

縱軸位置是每次投注的資訊係數，不會隨投資標的範圍擴大而上升。圖中最高的資訊係數來自約一百種交易工具的案例研究，而範圍最廣的兩個投資標的群體遠低於它。此處沒有任何證據支持「交易工具越多，訊號越好」。

標記面積代表估計資訊比率，最大圓點位於橫軸右端。這是本節開頭法則的作用：資訊比率等於資訊係數乘以廣度的平方根。因此，投資標的範圍若擴大一百倍，即使資訊係數縮小十倍，資訊比率仍相同。投資標的範圍較廣的案例研究，即使個別訊號較弱，仍能得到有競爭力的資訊比率。

將其當作研究結果解讀時，須注意兩點。估計資訊比率是將法則套用於圖中的資訊係數，並非從回測測得，因此面積與位置之間的關係有一部分來自算術，而非實證。其次，法則中的廣度指的是*獨立*投注次數；若三千檔股票一起變動，實際提供的獨立投注遠少於三千，而這正是使用該法則時最常忽略的修正。
