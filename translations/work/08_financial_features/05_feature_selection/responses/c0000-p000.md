# 特徵選擇與去重

**第 8 章：特徵工程**
**對應章節**：8.6，組合特徵與控制搜尋

**Docker 映像檔**：`ml4t`

## 目的

特徵工程流程會產生許多候選特徵，包括不同的回溯期間、轉換方式和交互作用變體。本 Notebook 示範如何透過系統性的選擇與去重，將候選集合縮減為精簡且可用於正式應用的特徵集合。

## 學習目標

1. 計算橫斷面資訊係數，並依預測能力排列特徵
2. 套用相關性篩選，移除重複資訊的特徵
3. 將近乎重複的特徵分群，並挑選代表特徵
4. 使用 Benjamini–Hochberg 假發現率方法，控制多重檢定的錯誤發現
5. 透過自助抽樣資訊係數評估特徵穩定性
6. 比較以資訊係數及機器學習（LightGBM）為基礎的重要性排名
