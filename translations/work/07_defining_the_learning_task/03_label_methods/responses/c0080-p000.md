## 選擇方法

| 策略類型 | 建議方法 | 理由 |
|--------------|-------------------|-----------|
| 因子擇時（月頻） | 固定期間 | 簡單、具定態性的目標 |
| 統計套利（日內） | 固定期間二元標籤 | 速度很重要 |
| 橫斷面排名 | **橫斷面百分位** | 類別平衡穩定 |
| 主動交易 | 三重屏障（ATR） | 符合交易機制 |
| 趨勢追蹤 | 趨勢掃描，只取正負號 | 自適應期間；忽略其 t 統計量 |

**關鍵考量**：

1. **錨點對齊**：標籤計算應符合執行時機
2. **橫斷面與時間序列**：多數股票／ETF 策略需要橫斷面方法
3. **路徑依賴性**：若停損屬於策略一部分，使用三重屏障
4. **K 棒解析度**：正式環境應向屏障引擎提供 `high_col`、`low_col` 與 `open_col`；僅看收盤價的測試會以屏障價格記錄每筆出場
5. **波動率適應**：使用 ATR 屏障因應市場環境變化
