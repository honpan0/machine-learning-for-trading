## 機制假設

執行診斷之前，我們先陳述各特徵假定的因果機制，以建立解讀檢查結果的架構。

### 特徵 A：12-1 動能

12-1 動能訊號（從 $t-252$ 到 $t-21$ 的報酬率）被歸因於行為上的反應不足：投資人吸收資訊的速度較慢，因此過去上漲的資產繼續上漲。另一種解釋是，動能只是風險偏好／避險市場狀態的代理變數，而未編碼及時的橫斷面資訊。

```
       Volatility Regime (VIX)
            /        \
           v          v
    12-1 Momentum -->?  Forward Return
```

### 特徵 B：1 日反轉

1 日報酬率取負值。假設的機制是市場微觀結構造成的均值回歸：暫時性的價格偏離會在數日內反轉。在 21 日預測期間，這項機制不應具有預測力，因為效果衰減太快。

```
      Microstructure Friction
            |
            v
      1-day Return  -->?  21-day Forward Return
```
