- **12-1 動能**（過去 12 個月的報酬率，跳過最近一個月）：通過初步篩選，但有實務上需注意的限制。它具有真正的橫斷面資訊（在延遲 0 時最強），不預測美國公債報酬率，但訊號集中於低波動率市場狀態。
- **短期反轉**（1 日報酬率取負值）：未通過初步篩選；在 21 日預測期間沒有顯著 IC，其唯一顯著的儲存格也未通過第 4.1 節的標籤位移檢查。

## 學習目標

1. 執行多特徵、多預測期間的 IC 掃描，找出訊號所在
2. 使用 DAG 術語（混雜因子、中介變數、碰撞點）陳述所提出的機制
3. 實作時間安慰劑檢定（位移特徵並檢視 IC 半衰期）
4. 執行共同驅動因子檢查（不相關的結果應無效果）
5. 評估市場狀態異質性（VIX 市場狀態分組間的 IC 穩定性）
6. 將結果解讀為初步篩選決策（繼續／修訂／停止）
