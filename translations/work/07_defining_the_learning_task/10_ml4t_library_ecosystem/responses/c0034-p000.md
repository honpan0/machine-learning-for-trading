## 重要結論

1. **ml4t-data** 為全部七個資料集提供統一載入器
2. **ml4t-engineer** 透過登錄表 API 提供 120 多個經驗證的特徵
3. **設定驅動**的計算方式（清單、字典、YAML）確保可重現性
4. **ml4t-diagnostic** 透過 `analyze_signal` 評估特徵對遠期報酬率的預測能力；Notebook `05_signal_evaluation` 介紹完整流程
5. **正式環境使用函式庫**，教學及自訂因子使用手動程式碼
6. **Polars 模式**（`.over()`、ASOF 連接、延遲掃描）支援整套流程
