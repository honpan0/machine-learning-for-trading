# ml4t 函式庫生態系

**Docker 映像檔**：`ml4t`

**第 7 章：定義學習任務**
**章節參考**：7.1－資料預處理與編碼

## 目的

本 Notebook 介紹第 7–12 章使用的 **ml4t 函式庫生態系**：資料載入器（`ml4t-data`）、特徵計算（`ml4t-engineer`）與評估工具（`ml4t-diagnostic`）。

## 學習目標

1. 使用統一的 `ml4t-data` 載入器載入資料集
2. 透過 `ml4t-engineer` 登錄表探索及計算特徵
3. 使用清單、字典或 YAML 設定特徵，以利重現結果
4. 對照手動實作驗證函式庫特徵
5. 使用 `ml4t-diagnostic` 預覽特徵評估（完整介紹見 `05_signal_evaluation`）
6. 了解何時使用函式庫、何時使用手動程式碼

## 資料政策

所有範例都使用**真實 ETF 資料**（不使用合成資料）。
