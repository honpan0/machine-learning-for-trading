## 重點整理

1. **索引完整性**是基礎——時間單調性與唯一性必須通過，而且檢查本身必須可能失敗：若先排序資料框，再問它是否已排序，任何輸入都會傳回 True
2. **欄位涵蓋範圍不等於追蹤資料涵蓋範圍**——資料集可能回報所有欄位完整，卻缺少整列資料，因為空值計數只能看見已存在的資料列
3. **違反領域規則**的數值（負價格／成交量）表示資料品質有問題
4. **從記錄事件的欄位偵測事件**——`split_ratio` 直接指出分割，`|return| > 1` 門檻則在設計上只能偵測單側，漏掉幾乎所有正向分割
5. **日曆對齊**對外匯（週末）與加密資產（全天候交易）都很重要
