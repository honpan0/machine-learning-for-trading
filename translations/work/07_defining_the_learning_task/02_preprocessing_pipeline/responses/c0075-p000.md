## 重點整理

1. **前處理必須考慮資料切分**——只在訓練資料上擬合參數
2. **領域篩選條件可抓出明顯錯誤**——負價格、不可能的 OHLC 關係
3. **尖峰偵測可辨識資料假象**——單根 K 棒反轉往往表示錯誤
4. **溫莎化處理離群值**——但界限必須來自訓練資料
5. **類別編碼**必須處理測試時未見過的類別
6. **滾動向前重新擬合**可捕捉不同市場狀態下的參數漂移
7. **跨資料集對齊需要謹慎**——不同頻率應使用截至當時資料連接
