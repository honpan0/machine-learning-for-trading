## 向量化計算 MFE／MAE

我們使用 Polars 的 `max_horizontal` 與 `min_horizontal` 函式，不透過 Python 迴圈計算未來極值。此方法建立 $H$ 個位移欄位——從 $-1$ 位移至 $-H$，排除進場 K 棒——因此運算量及記憶體需求為 $O(n \times H)$。雖然這是向量化運算（沒有 Python 迴圈），記憶體仍隨期間長度增加。對非常長的期間，等價的反向滾動形式為 `high.shift(-1).reverse().rolling_max(H).reverse()`；注意其中的 `shift(-1)`，若缺少它，視窗會從第 $t$ 根 K 棒重新開始，將進場前的極值再次納入。
