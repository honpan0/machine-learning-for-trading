## 摘要

### 訊號評估的主要指標

| 指標 | 衡量內容 | 判讀方式 |
|--------|------------------|----------------|
| **IC** | 橫斷面可預測性 | 相對於自身標準誤；文獻數值區間列於*解讀 IC 的大小* |
| **ICIR** | 風險調整後 IC（平均值／標準差） | 搭配 IC 判讀；ICIR 接近零，表示平均值落在每日離散程度之內 |
| **逐折 ICIR** | 各測試折間的 IC 穩定性 | 同時確認各折實際涵蓋哪些日期 |
| **報酬率差** | 最高與最低分位組的差距 | 先看正負號，再將幅度與成本比較 |
| **單調性** | 分位組排名與平均報酬率的 Spearman rho | 與*單調性解讀*所列區間比較幅度；正負號優先 |
| **周轉率** | 訊號穩定性 | 與上方算出的損益兩平成本比較 |
| **半衰期** | 訊號衰減速度 | 只在期間曲線確實衰減時使用 |

### 依資料折評估（關鍵）

使用滾動向前驗證時，指標一律**逐折**計算：

1. 建立擴展或滾動視窗切分。
2. 在各測試折計算 IC（或 AUC）。
3. 報告逐折指標的**分布**，而非只有合併值。
4. 解讀合併樣本與逐折數值的差距前，先**只在折日期上**重新計算合併統計量。本 Notebook 的分解顯示，整個差距都是時期效果：資料折涵蓋追蹤資料前段一段有利時期，與彙總方式或過度擬合無關。在不同日期計算的兩項統計量之間出現差距，不能視為兩者之一的證據。
