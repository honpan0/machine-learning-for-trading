**ICIR** $= \bar{\text{IC}} / \sigma_{\text{IC}}$ 是訊號層級的資訊比率類比指標：對無序列相關的逐日 IC 使用 $t \approx \text{ICIR} \times \sqrt{T}$；對實際上具有相關性的情況，則使用經 HAC 調整的 $t$。
