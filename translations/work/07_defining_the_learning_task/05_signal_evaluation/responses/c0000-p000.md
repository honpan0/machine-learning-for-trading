# 訊號評估：IC、分位數與報酬率差

**第 7 章：定義學習任務**
**對應章節**：7.3——以特徵與標籤評估進行初步篩選

**Docker 映像檔**：`ml4t`

## 目的

本 Notebook 透過資訊係數（IC）分析、分位組報酬率與報酬率差指標，示範**單因子評估**。我們要回答：「這個因子對橫斷面有預測力嗎？其有效期間是多長？」

## 學習目標

1. 計算橫斷面 IC，了解其時間序列性質
2. 解讀 IC、ICIR 與經 HAC 調整的顯著性
3. 分析分位組報酬率、報酬率差與分位組階梯的單調性
4. 在充分警示重疊問題的前提下比較不同期間
5. 衡量周轉率與訊號半衰期

## 資料政策

所有範例都使用案例研究資料儲存區中的**真實 ETF 資料**。本 Notebook **不使用合成資料**。

## 先備條件

- `02_preprocessing_pipeline`——提供考慮資料切分的前處理概念，是下文**依資料折評估** IC 的基礎。
- `03_label_methods`——提供作為 `y_true` 使用的未來報酬率標籤。
- 熟悉等級相關係數（Spearman）與滾動向前交叉驗證。
