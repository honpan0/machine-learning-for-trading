## HAC（Newey-West）調整

HAC（異質變異與自相關一致）標準誤，會考量 IC 序列的序列相關。

Newey-West 估計量使用自共變異數的加權總和：

$$\hat{\sigma}^2_{HAC} = \hat{\gamma}_0 + 2\sum_{j=1}^{L} w_j \hat{\gamma}_j$$

其中 $w_j = 1 - j/(L+1)$ 是 Bartlett 核，而 $L$ 是截斷落後期數。

**此處不應讓 $L$ 只由樣本數決定。** 常用自動規則 $L = \lfloor 4(T/100)^{2/9} \rfloor$ 只參考 $T$，在這份序列中傳回 9。標籤是 $h$ 日*重疊的*未來報酬率，因此日期 $t$ 與日期 $t+j$，對每個 $j < h$ 都共享一部分結果視窗；訊號又是 21 日動能，其橫斷面排名變化緩慢。用持續性排名衡量重疊結果，會使 IC 在大致一個標籤期間內一起變動。

**上句的兩個條件都不可少，單有重疊並不足夠。** IC 是等級相關係數，而非報酬率：若訊號排名每天獨立重新抽取，不論報酬率視窗重疊多少，IC 仍可能沒有序列相關。因此 $h-1$ 不是重疊標籤的數學定理，而是**針對持續性訊號，保守地考量標籤期間的頻寬**。上圖量得的 ACF 在落後約 16 期前仍處於白噪音區間之外，支持其量級。

不可合理辯護的是 $L = 9$：它由完全未參考標籤或訊號的規則選定。傳入 `label_horizon` 會讓函式庫採用 $L = \max(h-1, \text{auto rule})$；ACF 支持這項選擇，下一節衡量其影響。
