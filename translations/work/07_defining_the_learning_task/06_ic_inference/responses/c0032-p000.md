## 摘要

### 核心概念

| 概念 | 說明 |
|---------|-------------|
| **HAC 標準誤** | 對具自相關 IC 使用 Newey-West 調整 |
| **區塊自助抽樣** | 透過區塊重新抽樣保留相依結構 |
| **有效 N** | 考量自相關後的真實樣本數 |
| **績效紀錄** | 偵測特定 IC 所需的最少觀測值 |

### 最佳實務

1. **一律使用經 HAC 調整的 t 統計量**——直接計算的 t 統計量會高估顯著性
2. **報告區塊自助抽樣信賴區間**——不依賴分布假設且穩健
3. **考量實務顯著性**——IC 必須超過成本造成的拖累
4. **規劃足夠長的績效紀錄**——一至兩年通常不足以偵測微小 IC
5. **檢查有效樣本數**——可能遠小於實際觀測數

### API 參照

```python
from ml4t.diagnostic.metrics import compute_ic_hac_stats

# HAC-adjusted statistics
hac = compute_ic_hac_stats(ic_series, label_horizon=21)
print(f"HAC t-stat: {hac['t_stat']:.2f}")
print(f"HAC p-value: {hac['p_value']:.4f}")

# Block bootstrap (requires arch library)

```
