## 摘要

### 核心概念

| 概念 | 說明 |
|---------|-------------|
| **選擇偏誤** | 測試大量因子時，最佳 IC／夏普比率會被高估 |
| **BH-FDR** | 控制錯誤發現所占比例的期望值 |
| **Holm-Bonferroni** | 控制出現*任何*錯誤發現的機率（FWER） |
| **Rademacher 複雜度** | 對相關假設提供更緊的界限 |
| **折減夏普比率** | 針對從 N 個策略中選出最佳者的偏誤調整夏普比率 |
| **PBO** | 樣本內表現最佳的設定在樣本外退步至後段的機率（第 16 章深入探討） |
| **MinTRL** | 使夏普比率達顯著性的最短績效紀錄 |
| **Harvey 門檻** | 在已發表文獻中宣稱發現因子時提高的 t 統計量門檻 |

### 各種情況適用的方法

| 情況 | 工具 |
|-----------|------|
| 篩選大量因子（IC） | BH-FDR 或 Holm-Bonferroni |
| 彼此相關的因子變體 | Rademacher（RAS）調整 |
| 選擇最佳策略（夏普比率） | 折減夏普比率 |
| 驗證回測結果 | PBO + DSR |
| 規劃資料蒐集 | MinTRL |
