此處應拿來比較的數值是**二分之一，而非零**。策略 0 被賦予很大的樣本內優勢，除此之外沒有任何優勢；在樣本外，它與其他十九個策略一樣，都服從標準常態分布。因此，樣本內選出的策略是根據雜訊選出，其樣本外排名均勻分布：約有一半機會落在中位數以下。對沒有真實優勢的選擇而言，PBO 接近二分之一才是*正確*解讀；上方列出的樣本外排名中位數正好位於所有策略的中間，也以另一種方式說明同一件事。

這就是為何「PBO 高於二分之一代表嚴重過度擬合」這項經驗法則必須審慎使用。二分之一並不是低於它一段安全距離就算通過的門檻。若策略的優勢完全是選擇造成的假象，其 PBO 就位於*二分之一*；以這麼多組合估計 PBO 的抽樣誤差也夠大，使得略低於二分之一的點估計，仍完全可能對應毫無優勢的策略。真正令人放心的結果，應是 PBO 接近零，且策略在樣本內排名第一後，仍維持在樣本外排名的前段。

PBO 是 DSR 的有力補充。DSR 聚焦夏普比率的膨脹，PBO 則直接衡量樣本內績效最佳的設定是否在樣本外*退步*。有關將 PBO 套用至實際 CPCV 回測分割的方法，請參閱第 16 章。
